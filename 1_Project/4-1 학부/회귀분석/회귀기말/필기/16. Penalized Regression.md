### Exam Scope (시험 범위 포함)

### Bias-Variance Trade-off
###### 개념 및 목적
- **목표:** $MSE(\hat{\beta})$ (Mean Squared Error)의 최소화.
    - $MSE$ 관점에서는 Unbiased Estimator가 항상 최적은 아님.
    - Bias(편향)가 약간 생기더라도 Variance가 급격히 줄어들면 전체 MSE 감소 가능.

###### Decompositon (분해 유도)
- **Goal:** $MSE(\hat{\theta}) = E[(\hat{\theta} - \theta)^2] = Var(\hat{\theta}) + [Bias(\hat{\theta})]^2$ 증명
    - $$E[(\hat{\theta} - \theta)^2] = E[(\hat{\theta} - E(\hat{\theta}) + E(\hat{\theta}) - \theta)^2]$$
    - $$= E[(\hat{\theta} - E(\hat{\theta}))^2] + (E(\hat{\theta}) - \theta)^2 + 2(E(\hat{\theta}) - \theta) \underbrace{E[\hat{\theta} - E(\hat{\theta})]}_{=0}$$
    - $$= Var(\hat{\theta}) + [Bias(\hat{\theta})]^2$$
    - hint : $A+B$의 완전제곱식 $(A+B)^2 = A^2 + B^2 + 2AB$ 활용.
    - hint : $E(\hat{\theta}) - \theta$는 상수(Constant) 취급하여 기댓값 밖으로 나옴.

### Multicollinearity (다중공선성)
###### Definition (정의)
- 설명 변수($X$)들 간에 강한 선형 상관관계가 존재하는 경우.
- **증상 (Variance Inflation):**
    - 회귀 계수 $\hat{\beta}$의 **Variance(분산) 폭발**.
    - 수식적 원인: $Var(\hat{\beta}) = \sigma^2 (X^TX)^{-1}$
        - $X'X$의 eigenvalue $\approx 0$ $\implies$ 역행렬의 eigenvalue $\to \infty$.
        - hint : $(X^TX)^{-1}$는 $X^TX$의 고유값의 역수($1/\lambda_i$)를 고유값으로 가짐. $\lambda_{min} \to 0$이면 $Var \to \infty$.

###### Diagnostics (진단)
- **VIF (Variance Inflation Factor):**
    - $$VIF_j = \frac{1}{1 - R_j^2}$$
    - $R_j^2$: $X_j$를 종속변수로, 나머지 $X$들을 설명변수로 했을 때의 결정계수.
    - **유도 의미:** $X_j$가 다른 변수들로 설명이 잘 될수록($R_j^2 \to 1$), 분모가 0에 가까워져 VIF 급등.
    - **기준:** $VIF > 10$ 이면 심각.

### Non-Exam Scope (시험 범위 제외 / 교양)

### Penalized Regression (Regularization)
###### Concept
- **목적 함수:** Minimize $Q = SSE + \lambda \times P(\beta)$ (Penalty term)

###### 1. Ridge Regression ($L_2$ Penalty)
- **식:** $Q(\beta) = (Y - X\beta)'(Y - X\beta) + \lambda \beta'\beta$
- **Derivation (해 유도):** $\frac{\partial Q}{\partial \beta} = 0$
    - $$- 2X'(Y - X\beta) + 2\lambda \beta = 0$$
    - $$- X'Y + X'X\beta + \lambda I \beta = 0$$
    - $$(X'X + \lambda I)\beta = X'Y$$
    - $$\therefore \hat{\beta}_{Ridge} = (X'X + \lambda I)^{-1}X'Y$$
    - hint : 행렬 미분 $\frac{\partial}{\partial \beta}(\beta' A \beta) = 2A\beta$ (A가 대칭일 때). $\frac{\partial}{\partial \beta}(b' \beta) = b$.
    - hint : $\beta$로 묶을 때 상수항 $\lambda$ 뒤에 Identity Matrix ($I$) 붙여야 행렬 연산 가능.
- **특징:**
    - **Singularity 해결:** $X'X$가 역행렬 없어도, $\lambda I$를 더하면(대각성분에 $\lambda$ 추가) 항상 역행렬 존재.
    - **Shrinkage:** $\lambda \to \infty$이면 $\hat{\beta} \to 0$.

###### 2. Lasso Regression ($L_1$ Penalty)
- **식:** $\min \sum (y_i - \hat{y}_i)^2 + \lambda \sum |\beta_j|$
- **특징 (vs Ridge):**
    - 미분 불가능 (절댓값). Closed form solution 없음 (수치해석적 접근 필요).
    - **Variable Selection:** 제약 조건 영역($|\beta_1| + |\beta_2| \le t$)이 마름모 꼴.
    - hint : 등고선이 마름모의 **꼭짓점(Vertex)** 에서 접할 확률이 높음. 꼭짓점은 축 위에 있으므로 해당 좌표 성분이 0이 됨.
