
### Two-Group Mean Comparison Formulation (Regression Approach)

* **Initial Setup (Two Independent Groups):**
    * $Z_i = \mu_1 + \epsilon_i, \quad \epsilon_i \sim iid \ N(0, \sigma^2)$ (Group 1)
    * $W_i = \mu_2 + \epsilon_i, \quad \epsilon_i \sim iid \ N(0, \sigma^2)$ (Group 2)
* **Matrix Formulation ($Y = X\beta + \epsilon$):**
    * $$
    \underset{Y}{\begin{pmatrix} z_1 \\ \vdots \\ z_m \\ w_1 \\ \vdots \\ w_n \end{pmatrix}} = 
    \underset{X}{\begin{pmatrix} 1 & 0 \\ \vdots & \vdots \\ 1 & 0 \\ 0 & 1 \\ \vdots & \vdots \\ 0 & 1 \end{pmatrix}}
    \underset{\beta}{\begin{pmatrix} \mu_1 \\ \mu_2 \end{pmatrix}} + 
    \underset{\epsilon}{\begin{pmatrix} \epsilon_1 \\ \vdots \\ \epsilon_{m+n} \end{pmatrix}}
    $$
    * **Test Hypothesis:** $H_0: \beta_1 = \beta_2 \iff H_0: \mu_1 = \mu_2$

#### Formulation with Intercept (Dummy Variable Approach)

* **Original Mean Structure:**
    * Group 1 ($1 \le i \le m$): $Z_i = \mu_1 + \epsilon_i$
    * Group 2 ($m+1 \le i \le n$): $W_i = \mu_2 + \epsilon_i = \mu_1 + (\mu_2 - \mu_1) + \epsilon_i$
* **Regression Model:**
    * $$Y_i = \mu_1 + (\mu_2 - \mu_1)X_i + \epsilon_i$$
    * Let $\beta_0 = \mu_1$ and $\beta_1 = \mu_2 - \mu_1$.
    * $$Y_i = \beta_0 + \beta_1 X_i + \epsilon_i$$
* **Dummy Variable Definition ($X_i$):**
    * $X_i = 1$ if $m+1 \le i \le n$ (Group 2)
    * $X_i = 0$ if $1 \le i \le m$ (Group 1)
* **Hypothesis Testing:**
    * $\beta_1 = \mu_2 - \mu_1$ represents the difference between group means.
    * $H_0: \beta_1 = 0 \iff H_0: \mu_1 = \mu_2$
    * $H_1: \beta_1 \neq 0$

### Alternative Hypothesis Testing Formulation (Group Index Variable)

* **Variable Definition ($X_i$):**
    * $X_i = 1$ if $1 \le i \le m$ (Group 1)
    * $X_i = 2$ if $m+1 \le i \le n$ (Group 2)
* **Regression Model:**
    * $$Y_i = \beta_0 + \beta_1 X_i + \epsilon_i$$
* **Group Means Analysis:**
    * **Group 1 ($1 \le i \le m$):**
        * $Y_i = \beta_0 + \beta_1(1) + \epsilon_i$
        * $\Rightarrow \mu_1 = \beta_0 + \beta_1$
    * **Group 2 ($m+1 \le i \le m+n$):**
        * $Y_i = \beta_0 + \beta_1(2) + \epsilon_i$
        * $\Rightarrow \mu_2 = \beta_0 + 2\beta_1$
* **Hypothesis Testing:**
    * **Goal:** Test if group means are equal ($H_0: \mu_1 = \mu_2$).
    * **Difference:** $\mu_2 - \mu_1 = (\beta_0 + 2\beta_1) - (\beta_0 + \beta_1) = \beta_1$.
    * **Conclusion:**
        * $H_0: \mu_1 = \mu_2 \iff \mu_2 - \mu_1 = 0 \iff \beta_1 = 0$
        * $H_1: \mu_1 \neq \mu_2 \iff \beta_1 \neq 0$

### Three-Group Linear Trend Model

* **Variable Definition ($x_i$):**
    * $x_i = 1$ if $1 \le i \le n_1$ (Group Z)
    * $x_i = 2$ if $n_1+1 \le i \le n_1+n_2$ (Group W)
    * $x_i = 3$ if $n_1+n_2+1 \le i \le n_1+n_2+n_3$ (Group T)
* **Regression Model:**
    * $$Y_i = \beta_0 + \beta_1 x_i + \epsilon_i$$
* **Group Distributions:**
    * $Z \sim N(\mu_1, \sigma^2)$, $W \sim N(\mu_2, \sigma^2)$, $T \sim N(\mu_3, \sigma^2)$
* **Mean Structure Analysis:**
    * **Group 1 ($Z_i$):**
        * $Y_i = \beta_0 + \beta_1(1) + \epsilon_i = \mu_1 + \epsilon_i$
        * $\Rightarrow \mu_1 = \beta_0 + \beta_1$
    * **Group 2 ($W_i$):**
        * $Y_i = \beta_0 + \beta_1(2) + \epsilon_i = \mu_2 + \epsilon_i$
        * $\Rightarrow \mu_2 = \beta_0 + 2\beta_1$
    * **Group 3 ($T_i$):**
        * $Y_i = \beta_0 + \beta_1(3) + \epsilon_i = \mu_3 + \epsilon_i$
        * $\Rightarrow \mu_3 = \beta_0 + 3\beta_1$
* **Implications (Relation between Means):**
    * $\mu_2 - \mu_1 = \beta_1$
    * $\mu_3 - \mu_2 = \beta_1$
    * $\mu_3 - \mu_1 = 2\beta_1$
    * **Interpretation:** This model assumes a **linear relationship** between the group index and the group mean.
        * The difference between adjacent groups is constant ($\beta_1$).


### Three-Group One-Way ANOVA Formulation (Regression Approach)

* **Initial Mean Structure:**
    1.  **Group 1 ($Z_i$):** $Y_i = \mu_1 + \epsilon_i$ ($1 \le i \le n_1$)
    2.  **Group 2 ($W_i$):** $Y_i = \mu_2 + \epsilon_i = \mu_1 + (\mu_2 - \mu_1) + \epsilon_i$ ($n_1+1 \le i \le n_1+n_2$)
    3.  **Group 3 ($T_i$):** $Y_i = \mu_3 + \epsilon_i = \mu_1 + (\mu_3 - \mu_1) + \epsilon_i$ ($n_1+n_2+1 \le i \le \sum n_k$)
* **Dummy Variables ($E_2, E_3$):**
    * $X = [1, E_2, E_3]$
    * $E_2$: 1 if in Group 2, else 0.
    * $E_3$: 1 if in Group 3, else 0.
    * Note: Group 1 is the baseline ($\mu_1$).
* **Matrix Formulation:**
    * $$
    \underset{Y}{\begin{pmatrix} Y_1 \\ \vdots \\ Y_{N} \end{pmatrix}} = 
    \underset{X}{\begin{pmatrix} 1 & 0 & 0 \\ \vdots & \vdots & \vdots \\ 1 & 1 & 0 \\ \vdots & \vdots & \vdots \\ 1 & 0 & 1 \\ \vdots & \vdots & \vdots \end{pmatrix}}
    \underset{\beta}{\begin{pmatrix} \mu_1 \\ \mu_2 - \mu_1 \\ \mu_3 - \mu_1 \end{pmatrix}} + 
    \epsilon
    $$
* **Parameter Definition ($\beta$):**
    * $\beta_0 = \mu_1$
    * $\beta_1 = \mu_2 - \mu_1$
    * $\beta_2 = \mu_3 - \mu_1$
* **Hypothesis Testing (ANOVA):**
    * **Goal:** Test equality of all group means ($H_0: \mu_1 = \mu_2 = \mu_3$).
    * **Equivalent Hypothesis in Regression:**
        * $H_0: \beta_1 = \beta_2 = 0$
        * $H_1:$ At least one $\beta_j \neq 0$ (Mean differences exist).
    * **Interpretation:**
        * $\beta_1 = 0 \Rightarrow \mu_2 = \mu_1$
        * $\beta_2 = 0 \Rightarrow \mu_3 = \mu_1$
        * If both are 0, then $\mu_1 = \mu_2 = \mu_3$.


### Cell Means Model & Perfect Multicollinearity

* **Model with Intercept and All Group Indicators:**
    * $Y_i = (\mathbf{1}, E_1, E_2, E_3) (\beta_0, \mu_1, \mu_2, \mu_3)' + \epsilon_i$
* **Design Matrix ($X$) Analysis:**
    * $$
    X = 
    \begin{pmatrix} 1 & 1 & 0 & 0 \\ \vdots & \vdots & \vdots & \vdots \\ 1 & 0 & 1 & 0 \\ \vdots & \vdots & \vdots & \vdots \\ 1 & 0 & 0 & 1 \\ \vdots & \vdots & \vdots & \vdots \end{pmatrix}
    $$
* **Problem: Linear Dependence (Multicollinearity):**
    * The first column ($\mathbf{1}$) is the sum of the group indicator columns ($E_1 + E_2 + E_3$).
    * $\mathbf{1} = E_1 + E_2 + E_3$
    * **Consequence:** Columns are linearly dependent $\rightarrow$ $X'X$ is singular (not invertible) $\rightarrow$ $\beta$ estimation is impossible (식별 불가).

#### Cell Means Model (Solution)

* **Refined Model (Remove Intercept):**
    * $Y = (E_1, E_2, E_3) \beta + \epsilon$
    * $$ Y = (E_1, E_2, E_3) \begin{pmatrix} \mu_1 \\ \mu_2 \\ \mu_3 \end{pmatrix} + \epsilon $$
* **Properties:**
    * Columns $E_1, E_2, E_3$ are linearly independent.
    * Estimation is possible.
* **Hypothesis Testing:**
    * $H_0: \beta_1 = \beta_2 = \beta_3$ (All group means are equal).
    * $H_1:$ Not all $\beta_j$ are equal (At least one pair differs).


### salary example (stratification)
- 매니저 여부, 학력수준 (고/대/석)졸 2\*3=6가지 케이스중 각 E와 M의 조합에 따라 모델을 6개로 분리
### Use qualitative variables (케이스마다 서로 다른 절편)
- 또는 6가지의 경우의 수를 dummy variable을 사용해 나타낼 수 있음
	- (각 관측치는 동분산 $\sigma^2$을 가정)
	- $$S_i = \beta_0 + \beta_1 X_i + \beta_2 E_{i2} + \beta_3 E_{i3} + \beta_4 M_i + \epsilon_i$$
	- $E_{i2} = \begin{cases} 1 & \text{if } E_i=2 \\ 0 & \text{otherwise.},\quad \end{cases}E_{i3} = \begin{cases} 1 & \text{if } E_i=3 \\ 0 & \text{otherwise.},\quad \end{cases} M_{i} = \begin{cases} 1 & \text{if } M \\ 0 & \text{otherwise.}\quad \end{cases}$
- 절편에 dummy var 추가 시 : 경우의 수가 3개라면, 하나를 디폴트 케이스, dummy var은 2개만 쓴다
### Interactions (케이스마다 서로 다른 기울기)
$$S_i = \beta_0 + \beta_1 X_i + \beta_2 E_{i2} + \beta_3 E_{i3} + \beta_4 M_i + \beta_5 E_{i2} X_i + \beta_6 E_{i3} X_i + \epsilon_i$$
- 케이스별로 서로 다른 절편 및 기울기를 가졌다고 가정.
- interactoin term : $E_{i2}X_i, E_{i3}X_i$
- 회귀식의 그래프가 꺾일경우
$$Y_i = \beta_0 + \beta_1 x_i + \beta_2 (x_i - \alpha) A_i + \epsilon_i$$
	- $A_i = I(x\ge a)= \begin{cases} 1 & \text{if } x\ge a \\ 0 & \text{otherwise.}\end{cases}$
