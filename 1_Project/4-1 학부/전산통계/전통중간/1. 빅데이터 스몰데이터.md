###### 빅데이터 개념
- 고사양 컴퓨터 1대 vs 저사양 컴퓨터 여러대를 병렬 제어
	- 저사양 컴퓨터 병렬로 된 것이 빅데이터 저장 비용을 낮춤
- 기업의 수집하는 정보
	- 속성정보(개체의 속성, 시간에 따라 바뀌지 않는 정적 데이터) -> RDB 형태로 저장
	- event log(개체의 상태, 시간에 따라 바뀜) -> 하둡시스템 저장
- 빅데이터 가공 절차 : 데이터수집 -> 저장 -> 집계 -> 지능화
- 고객에 대한 이해 -> 행동 이벤트 관계를 이해하는 방향으로 발전
	- 고객의 속성 정보 모형화에서 행동 정보의 관계를 모형화
###### 스몰데이터, 빅데이터
- 표본오차 : 표본수 증가시 감소, 비표본오차 : 과학적 접근 어려워 계산 불능
- 재현성 : 모델을 만들 때 모든데이터 사용 X, 검증을 위한 테스트셋을 남겨둠
- 통계학 vs 빅데이터
	- 분석을 위한 최소 데이터 수집, 모집단의 구조에 대한 추론, linear 중심
	- 기존 축적 자료를 분석(자료수집비용 low), 모집단의 구조보단 예측에 초점, non-linear 중심
- non-leanear 모델 :
	- 스몰데이터 : non-linear 사용시 overfitting 위험 커짐
	- 빅데이터 : non-ninear 사용시 overfitting 위험 덜하다
