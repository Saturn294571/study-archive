## 0. 최우선 앵커 파일

### `PLANNER.md`
- 역할: 프로젝트 전체 운영 원칙과 상담자 역할 정의.
- 언제 읽을 것:
  - 학습 계획 평가
  - 실행력/루틴 피드백
  - 하루 계획 조정
  - 과잉계획/회피 판단
- 핵심 내용:
  - 일본 석사 입시 장기 프로젝트.
  - 사용자의 주요 약점: 수면 불규칙, 늦은 시작, 오늘 망했다 사고, 폰/게임, 과잉계획, 연구 글쓰기 완벽주의.
  - 목표: 실행 일관성, 현실적 우선순위, 지속 가능한 루틴, 연구/언어 진전.

### `STRAGIES.md`
- 역할: 실행 전략과 리스크 대응 원칙.
- 언제 읽을 것:
  - 오늘 계획 축소
  - 복귀일/회복일 설계
  - 수면/외출/도서관/게임 리스크 대응
- 핵심 내용:
  - 하루는 완벽보다 0점 회피.
  - 하루 최소 기준: 일문따 or 토플 중 1개 + 추가 1개.
  - 집=휴식, 도서관=작업.
  - 과도한 계획 방지: 하루 목표 2-3개 제한.
  - 논문 완벽주의 대응: 제출 가능한 상태 기준.

### `ASSISTENT.md`
- 역할: 연구 조수용 프롬프트/역할 정의.
- 언제 읽을 것:
  - 연구 아이디어 검토
  - 논문/실험/선행연구/랩미팅 준비
  - 연구계획서 논리 구성
- 핵심 내용:
  - 연구 조수는 생활관리자가 아니라 연구 명료성, 개념 엄밀성, 문헌 적합성, 실험 설계, 방어 가능한 글쓰기를 담당.
  - 약한 아이디어를 과장하지 말고, 연구 질문/가설/구현/기여를 분리해야 함.

## 2. 연구 방향과 아이디어

### `연구/research_note.md`
- 역할: 연구 아이디어, 후속 연구 고민, 금융AI 세미나 메모, 후보 연구실 초안.
- 언제 읽을 것:
  - 연구계획서 소재 찾기
  - 기존 연구에서 새 연구축으로 넘어가는 논리 구성
  - 교수 상담용 연구 포지션 설명
- 핵심 내용:
  - LLM Economist++ 후속 아이디어:
    - ICRL 최적화 불안정성
    - AdaGrad식 step size 조정 가능성
    - LHF의 변동성이 실제 문제인지 재검토 필요
  - 교수 피드백:
    - LHF가 크게 헤매는 모습으로 해석되진 않음.
    - 문제가 너무 사소하면 장점이 살지 않음.
  - 새 연구축 고민:
    - 금융/경제 감성분석
    - 금융/경제 시계열 Transformer
    - 신용 예측
  - 인공지능 웹세미나 메모:
    - 금융AI는 설명가능성, 고위험 의사결정, 외부충격/컨셉 드리프트, 복잡한 데이터 제약이 큼.
    - 금융 agent는 일반 agent와 달라야 하며, 통제가능성과 평가 구조가 중요.

- 역할: 기존 논문의 논리 구조와 실험 결과 요약.
