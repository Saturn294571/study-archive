# OLS as minimizing residuals
### 회귀식 $y_i= \beta_0+\beta_1x_i+e_i$
- $(x_1,\cdots,x_n)$, $(y_1,\cdots,y_n)$의 n개의 관측치를 고려.
- OLS : 데이터를 가장 잘 설명하는 선$(\hat{\beta_0}+\hat{\beta_1}x)$을 찾아냄. 추정치.
	- $\hat{y_i}=\hat{\beta_0}+\hat{\beta_1}x_i$는 $y_i$에 대해 추정/예측된 값.
	- $\hat{u_i}=y_i-\hat{y_i}$는 잔차; 모델로 설명/예측 X인 값
### SSE(Squared Sum of Errors)와 OLS
- OLS는 잔차 최소화할 $\beta_0,\beta_1$ 찾. $\hat{u_i}^2$ 최소화 되게(미-가 고려)
- 목표 : $\underset{\hat{\beta_0},\hat{\beta_1}}{\text{argmin}}\sum_{i=1}^n(y_i-\hat{\beta_0}+\hat{\beta_1}x_i)^2$
	- $\hat{\beta_1^*}=\frac{\sum(x_i-\bar{x_i})(y_i-\bar{y_i})}{\sum(x_i-\bar{x_i})^2}=\frac{Cov(x,y)}{var(x)}$, $\hat{\beta_0^*}=\bar{y_i}=\hat{\beta_1^*}\bar{x_i}$
# Regression model and classical assumptions
### 다중회귀 식 $y_i=\beta_0+\beta_1x_{1i}+\cdots+\beta_kx_{ki}+e_i$ 가 주어질 때,
1. 선형성(Linearity): 변수들간 선형적 관계.
2. 조건부 기댓값 0: $E[e_i|X_{1i},\cdots,X_{ki}]=0\quad \forall i$.
	- 위배 : $E[e_i|\mathbb{X}]\neq0\to$ OLS X. biased estimator가 됨.
	- 언제 위배되나? $y_i=\beta_0+\cdots+\beta_kx_{ki}+\underset{\text{없음}}{(\beta_{k+1}x_{k+1i})}+e_i$ 라고 잘못 추정.
		- $e_i=e_i^T+\beta_{k+1}x_{(k+1)i}$의 참모델의 정보 포함.
		- $x_{1i},x_{(k+1)i}$ 간 공선성 높? $\hat{\beta_1}\to\beta_1+\beta_{k+1}\frac{\triangle x_{(k+1)i}}{\triangle x_{1i}}$로 편향; 다른 $\hat{\beta}$들도 편향.
		- 해결책 : 빠진 변수를 넣; 도구변수, 2SLS 사용
3. 동분산성(Homoskedasticity): $E[e_i^2|X_{1i},\cdots,X_{ki}]=\sigma^2\quad \forall i$
4. 독립성 : $Cov[e_ie_j]=E[e_ie_j]=0\quad \forall i\neq j$
	- 3. or 4. 위배시(이분산성/변수간 상관) : OLS는 BLUE가 X.
		- 해결책 : GLS 사용; Feasible GLS : 오차의 이분산성/상관성을 추정 
5. 다중공선성 부재: $x$간 완전한 선형관계 X (no perfect multi-collinearity)
	- 위배 : 완전 다중공선성 -> OLS 작동 X / 약 다공성 -> 왜곡된 추정치
6. 정규성: $e_i\sim N(\cdot)$
	- 위배 : 정확한 통계적 추정 대신 근사만 O; 샘플 크기 n이 충분히 크면 OK
### 가우스-마르코프 정리, BULE
- 가우스-마르코프 정리 : 위 6가지 가정 성립시, OLS는 Best Linear Unbiased Estimator.
