# 금융계량 중간대비(lect. 1~5) 
## 1. OLS review
### OLS as minimizing residuals
#### 회귀식 $y_i= \beta_0+\beta_1x_i+e_i$
- $(x_1,\cdots,x_n)$, $(y_1,\cdots,y_n)$의 n개의 관측치를 고려.
- OLS : 데이터를 가장 잘 설명하는 선$(\hat{\beta_0}+\hat{\beta_1}x)$을 찾아냄. 추정치.
	- $\hat{y_i}=\hat{\beta_0}+\hat{\beta_1}x_i$는 $y_i$에 대해 추정/예측된 값.
	- $\hat{u_i}=y_i-\hat{y_i}$는 잔차; 모델로 설명/예측 X인 값
#### SSE(Squared Sum of Errors)와 OLS
- OLS는 잔차 최소화할 $\beta_0,\beta_1$ 찾. $\hat{u_i}^2$ 최소화 되게(미-가 고려)
- 목표 : $\underset{\hat{\beta_0},\hat{\beta_1}}{\text{argmin}}\sum_{i=1}^n(y_i-\hat{\beta_0}-\hat{\beta_1}x_i)^2$
	- $\hat{\beta_1^*}=\frac{\sum(x_i-\bar{x_i})(y_i-\bar{y_i})}{\sum(x_i-\bar{x_i})^2}=\frac{Cov(x,y)}{var(x)}$, $\hat{\beta_0^*}=\bar y-\hat{\beta_1^*}\bar x$
### Regression model and classical assumptions
#### 다중회귀 식 $y_i=\beta_0+\beta_1x_{1i}+\cdots+\beta_kx_{ki}+e_i$ 가 주어질 때,
1. 선형성(Linearity): 변수들간 선형적 관계.
2. 조건부 기댓값 0: $E[e_i|X_{1i},\cdots,X_{ki}]=0\quad \forall i$.
	- 위배 : $E[e_i|\mathbb{X}]\neq0\to$ OLS X. biased estimator가 됨.
	- 언제 위배되나? $y_i=\beta_0+\cdots+\beta_kx_{ki}+\underset{\text{없음}}{(\beta_{k+1}x_{k+1i})}+e_i$ 라고 잘못 추정.
		- $e_i=e_i^T+\beta_{k+1}x_{(k+1)i}$의 참모델의 정보 포함.
		- $x_{1i},x_{(k+1)i}$ 간 공선성 높? $\hat{\beta_1}\to\beta_1+\beta_{k+1}\frac{\triangle x_{(k+1)i}}{\triangle x_{1i}}$로 편향; 다른 $\hat{\beta}$들도 편향.
		- 해결책 : 빠진 변수를 넣; 도구변수, 2SLS 사용
3. 동분산성(Homoskedasticity): $E[e_i^2|X_{1i},\cdots,X_{ki}]=\sigma^2\quad \forall i$
4. 독립성 : $Cov[e_ie_j]=E[e_ie_j]=0\quad \forall i\neq j$
	- 3. or 4. 위배시(이분산성/변수간 상관) : OLS는 BLUE가 X.
		- 해결책 : GLS 사용; Feasible GLS : 오차의 이분산성/상관성을 추정 
5. 다중공선성 부재: $x$간 완전한 선형관계 X (no perfect multi-collinearity)
	- 위배 : 완전 다중공선성 -> OLS 작동 X / 약 다공성 -> 왜곡된 추정치
6. 정규성: $e_i\sim N(\cdot)$
	- 위배 : 정확한 통계적 추정 대신 근사만 O; 샘플 크기 n이 충분히 크면 OK
#### 가우스-마르코프 정리, BLUE
- 가우스-마르코프 정리 : 위 6가지 가정 성립시, OLS는 Best Linear Unbiased Estimator.

## 2. Return Predictablility I
### Unconditional and conditional expecatation
- Unconditional : $E(Y)=\int y\cdot p(y) dy$
- Conditional : $E(Y|X=x)=\int y\cdot p(y|X=x) dy$
### Law of iterative expectation
- 반복 기대의 법칙 : $E(Y)=E(E(Y|X))$
	- 조건부 확률들의 평균은 무조건부 확률과 같다

### Shiller의 합리적 기대 위배 사례
![](../3_기타/Pasted%20image%2020260325164527.png)
- 주식시장의 초과 변동성(Excess Volatility): 주가의 펀더멘털인 배당금보다 훨씬 요동침
	- 합리적 기대 가설 : 경제주체들은 모든 정보를 통해 미래를 합리적으로 예측
	- 합기 내에서 주가는 미래 배당금들을 현재가치로 할인한 합으로 결정 -> 따라서 주가는 배당금에 동기화.  
		- but, 쉴러는 실제 주가 변동성이 훨씬 $\uparrow$, 가설에 위배됨을 보임.
		- (그래프; 배당(녹)보다 주가(빨)이 훨씬 변동성$\uparrow$; 수익(파), 이자율(검))
- 수익률 예측에 대한 전통적 관점 : 합기에 따라 초과 예측/수익은 있을 수 X; 가격은 배당에 대한 충격(news/shock)에 의존
- **직관 : 배당은 비교적 천천히 움직이는데 가격은 훨씬 크게 흔들리므로, 가격에는 배당 말고도 기대수익률/할인율에 대한 정보가 들어 있다고 본다.**
- **예시 : 같은 기업인데 배당 전망 변화는 크지 않아도 금융위기 때 주가가 급락하는 것은 할인율(요구수익률) 충격으로 설명할 수 있다.**

### Traditional view for return predictability
- $R_{t+1}=a+bx_t+\epsilon_{t+1}$
	- b = 0라면, $E_t[R_{t+1}]=a$; 수익을 예측할 수 X. 
		- $\because$ 무조건부 평균인 a 이상으로 예측할 수 X.
		- $\to$ 예측X = 현재 시장에 모든 정보 반영. 
	- b $\neq$ 0라면, $E_t[R_{t+1}]=a+bx_t$; 수익을 예측할 수 있다
- ![](../3_기타/Pasted%20image%2020260325163011.png)

|      | t(b)                  | $R^2$                         | $\sigma(\cdot)$ |
| ---- | ----------------------------- | ----------------------------- | -------------------------------------- |
| 주식   | $\downarrow$ | $\downarrow$ | $\downarrow$        |
| 국채   | $\uparrow$                    | $\uparrow$                    | $\uparrow$          |
| 초과수익 | $\downarrow$                  | $\downarrow$                  | $\downarrow$                           |
- (초과수익 : $R_{t+1}-\text{T-bill}$, Risk free rate)
### Dividend-price ratio
- $R_{t+1}=\frac{P_{t+1}+D_{t+1}}{P_{t}}$ : 미래 수익 = 미래의 가격&배당과 비례, 현재 가격과 반비례
- $P_{t}=\frac{P_{t+1}+D_{t+1}}{R_{t+1}}$ : 현재 가격 = 미래의 현금흐름(주가+배당)에 대한 현재가치(수익률)
	- $P_t=\sum_{j=1}^\infty \frac{D_{t+j}}{\prod_{i=1}^j R_{t+j}}=E_tP_t$
	- $E_tD_{t+1}$가 바뀔때 : $E_tD_{t+1}\uparrow\uparrow\to P_t\uparrow\uparrow$
		- $E_tR_{t+1}\uparrow\uparrow\to P_t\downarrow\downarrow$ : 리스크$\uparrow\uparrow\to$리턴$\uparrow\uparrow$ 
- **직관 : 현재 가격은 미래 현금흐름을 할인한 값이므로, 가격이 낮아지면 같은 배당 대비 D/P는 올라간다.**
- **예시 : 경기 불안으로 투자자들이 더 높은 수익률을 요구하면 가격은 내려가고 D/P는 올라간다.**
- D/P ratio에 대한 로그 차분
	- OLS가 불가능. 데이터를 변환
	- $R_{t+1}=\frac{D_{t+1}}{P_t}\to \frac{P_{t}}{D_t}=\frac{E_t(D_{t+1}/D_t)}{E_t(R_{t+1})}$ 
	hint: $E_t()$씌우고 $P_t,E_t(R_{t+1})$ 자리 바꿈, $D_t$ 나눔
		- (1기 동안만 hold한다 가정)
	- $p_t-d_t=E_t(\triangle d_{t+1})-E_t(r_{t+1})$ (위에 로그)
		- 의미 :
			- 투자자들이 미래 배당/수익에 대한 정보를 얻어 기대를 형성, 현재 가격이 반응 
			$\triangle d_{t+1}, r_{t+1}\to E_t(\triangle d_{t+1}), E_t(r_{t+1})\propto p_t$
			- 투자자들의 정보 모르지만, 기대가 현재에 반영 ($p_t-d_t$)
			- D/P$\uparrow$ ? :  {현재 가격$(P_t)\uparrow$ + 할인률 기대수익률$(E(R_{t+1}))\downarrow$} 의 신호
		- $p_t$에 영향 주는것?
			- dividend growth ($E_t(\triangle d_{t+1})\uparrow\uparrow$) : 회사 성장 기류; $p_t\uparrow\uparrow$
			- discount rate($E(r_{t+1})\uparrow\uparrow$) : risk $\uparrow\uparrow$; $p_t\downarrow\downarrow$
- **직관 : D/P가 높다는 것은 보통 “배당이 갑자기 좋아졌다”기보다 “현재 가격이 낮거나 기대수익률이 높다”는 쪽으로 해석한다.**

## 3. Basic Time Series
### Differences Between Cross-sectional and Time series data
- 1. 보통 과거->최근 정렬    2. 현실적으로 랜덤샘플링 가정 X
- 3. 시간에 따라 데이터간 강력한 상관성    4. 강 상관성 -> OLS X
- 5. 다수가 trend를 보이는 경향 6. seasonality 관찰 가능
	- $\therefore$ 관측치간 시간적으로 강하게 연결 -> CS Data 쓰듯 OLS X. stationary함을 보장해야함
- **직관 : 시계열은 오늘 값이 어제 값과 연결되어 있어, 관측치 하나하나가 서로 독립이라고 보기 어렵다.**
- **예시 : 오늘의 금리와 어제의 금리는 거의 연결되어 있지만, 두 사람의 키처럼 서로 독립표본으로 보기 어렵다.**
### Stationary
- ![](../3_기타/Pasted%20image%2020260405155703.png)
	- 핵심 아이디어 : $E(),Var(),Cov()$가 시간에 따라 폭주 X. 일정함O
- 확변의 모멘트 : $E[Y^k]$ : k번째 모멘, $E[(Y-E[Y])^k]$ : k번째 중앙모멘트 
	-  데이터 분포 파악을 위한 통계값들
	- 1st/2nd/3rd/4th moment : 평균,기댓값/분산,공분산/왜도/첨도
- 약한 stationary 프로세스
	- $E(Y_t)=\mu,\quad\forall t$
	- $\text{var}(Y_t)=\sigma^2,\quad\forall t$
	- $\text{cov}(Y_t,Y_{t-j})=\gamma_j,\quad\forall t$
- **직관 : stationary의 핵심은 데이터가 출렁이더라도 “출렁이는 규칙” 자체는 시간에 따라 바뀌지 않는 것이다.**
- **예시 : 평균 2%, 분산도 비슷한 범위에서 움직이는 인플레이션은 stationary에 가깝고, 계속 우상향하는 GDP level은 보통 non-stationary다.**
- Stochastic process vs Time series data
	- Stocastic : a sequence of random variable orderd in time(Ex-ante)
	- Time series : A particular realization of stochastic process(Ex-post)
### FDL(Finite Distributed Lag) Models
- 정의 : 오늘 z의 변화가 q기에 걸쳐 y에 영향을 미침 : FDL of order q
	- ex) 면세(pe)로 인한 2년간 출생률(gfr)변화 : $gfr_t=\alpha_0+\delta_0pe_{t}+\delta_1pe_{t-1}+\delta_2pe_{t-2}+u_t$
- FDL model of order q : $y_t=\alpha_0+\delta_0z_t+\cdots+\delta_qz_{t-q}+u_t$
	- Impact propensity(IP, 즉각 효과) = $\delta_0$ : 현재의 충격을 capture
	- Long run propensity(LRP, 장기 효과) = $\delta_0+\cdots+\delta_q$ : 충격 -> 모든 기간의 효과 caputre
- **직관 : 어떤 정책이나 충격은 오늘 바로 끝나지 않고 몇 기에 걸쳐 천천히 반응할 수 있으므로 시차항을 같이 넣는다.**
- **예시 : 금리 인상은 같은 분기 소비를 바로 다 바꾸기보다, 몇 분기 뒤 투자와 소비를 누적적으로 줄일 수 있다.**
- 테일러 준칙 : $\text{ffrate}_t=\alpha_0+\delta_0\text{inf}_t+\cdots+\gamma_0\text{gdpgap}_{t}+\cdots+u_t$
	- (ffrate : 기준금리, gdpgap=$|\text{(잠재 GDP)-(실질 GDP)}|$)
	- Q : 이 모델에 자기자신을 추가하면?($\text{ffrate}_{t-1}$ 등) -> Lagged Dependent Variables
### Models with Lagged Dependent Variables
- $y_t=\alpha_0+\beta_0y_{t-1}+u_t$ <- AR(1)
	- 가정 : $y_t$ -> stationary; $u_t$ -> 모델의 설명력이 충분, 트렌드/패턴 X($u_t\sim N(0,\sigma^2)$)
	- 테일러 준칙에 적용 : $i_t\overset{?}{\to}\pi_t$ (오늘 이자율변화 -> 오늘 인플레 변화?)
		- 정책시차의 필요 :
    ${inf}_t=\beta_0+\beta_1{inf}_{t-1}+\beta_2{unem}_{t-1}+u_t$ $=E({inf}_{t}|I_{t-1})\quad,E(u_t|I_{t-1})=0$
		- $E({inf}_{t+1}|I_t)=\beta_0+\beta_1+{inf}_{t}+\beta_2{unem}_{t}+0$ $(\because E())$
		- 예측오차 : $\eta_{t+1}=\pi_{t+1}-E(\pi_{t+1}|I_t)$
### Characterizing Trending Data
- seasonality가 있는 $y_t$를 어떻게 stationary하게 바꿔 OLS O?? : $y_t\to\triangle y_t$
	- $y_t=\alpha_0+\alpha_1t+e_t,\quad E(y_t)=\alpha_0+\alpha_1t\to$ mean이 constant가 X
	- $\triangle y_t=y_t-y_{t-1}=\alpha_1+\triangle e_t,\quad E(\triangle y_t)=\alpha_t,\forall t$
- **직관 : 추세가 있으면 수준(level)을 그대로 비교하기보다 변화량(change)을 보는 편이 더 안정적이다.**
- **예시 : 물가 수준은 계속 오를 수 있어도 물가상승률은 상대적으로 안정적일 수 있으므로, level보다 차분이나 로그차분을 본다.**

#### Properties of MA(1) 
- MA(1) : $Y_t=\mu+\epsilon_t+\theta\epsilon_{t-1}\quad \theta\in\mathbb{R},\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon)$
	- 충격 -> 짧($\theta$에 달림)
- **직관 : MA는 “상태가 기억하는 것”이 아니라 “한 번의 충격이 몇 기 동안 잔향을 남기나”를 보는 모형이다.**
- $E[Y_t]=\mu+E[\epsilon_t]+\theta E[\epsilon_{t-1}]=\mu$
- $Var[Y_t]=\sigma^2=E[(Y_t-\mu)^2]=\sigma^2_\epsilon(1+\theta^2)$ 
- $Cov[Y_t,Y_{t-1}]=\gamma_1=E[(Y_t-\mu)(Y_{t-1}-\mu)]=\theta\sigma^2_\epsilon$
	- $Cov[Y_t,Y_{t-2}]=\gamma_2 = 0$ ($Cov[Y_t,Y_{t-ㅓ}]=\gamma_j;\quad\forall j>1$)
- $\rho_1=\frac{\gamma_1}{\sigma^2}=\frac{\theta}{(1+\theta^2)},\quad\rho_j=\frac{\gamma_j}{\sigma^2}=0;\quad\forall j>1$
	- $\theta(=,>,<)0\to\rho_1(=,>,<)0$
- Dynamic Stability Condition : $\underset{j\to\infty}{\lim}\rho_j=0$
	- *ex) 반응X or $\downarrow\downarrow$ : 충격 내재화; 통화정책 -> 유동성함정*
#### Properties of MA(2)
- MA(2) : $Y_t=\mu+\epsilon_t+\theta_1\epsilon_{t-1}+\theta_2\epsilon_{t-2}\quad \theta\in\mathbb{R},\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon),\forall t$
	- $E[Y_t]=\mu+E[\epsilon_t]+\theta_1 E[\epsilon_{t-1}]+\theta_2 E[\epsilon_{t-2}]=\mu$
	- $Var[Y_t]=\sigma^2=E[(Y_t-\mu)^2]=\sigma^2_\epsilon(1+\theta_1^2+\theta_2^2)$ 
	- $Cov[Y_t,Y_{t-1}]=\gamma_1=\theta_1\sigma^2_\epsilon$ $Cov[Y_t,Y_{t-2}]=\gamma_2=\theta_2\sigma^2_\epsilon$
		- $Cov[Y_t,Y_{t-j}]=\gamma_j;\quad\forall j>2$)
	- $\rho_{1,2}=\frac{\gamma_{1,2}}{\sigma^2}=\frac{\theta_{1,2}}{(1+\theta_1^2+\theta_2^2)},\quad\rho_j=\frac{\gamma_j}{\sigma^2}=0;\quad\forall j>2$

### AR Model
#### Properties of AR(1)
- AR(1) : $Y_t=c+\phi Y_{t-1}+\epsilon;\quad\phi\in(-1,1),\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon)$
	- $E[Y_t]=\frac{c}{1-\phi}=\mu$
	- $\gamma_0=Var(Y_t)=\frac{\sigma^2}{1-\phi^2}$ (by sta. 가정)
		- $\gamma_j=Cov(Y_t,Y_{t-j})=\phi^j\frac{\sigma^2}{1-\phi^2}$ (by stat.)
	- $\rho_j=\frac{\gamma_j}{\gamma_0}=\phi^j$
	- DSC : $\lim_{j\to\infty}\rho_j=0$
		- AR(1)이 DSC를 항상 만족? -> 현실에선 $|\phi|<1$ X일수도.
		- $\therefore H_0 : \phi=1$을 검정후 기각. (unit root test)
- **직관 : AR(1)은 오늘 상태가 내일로 얼마나 이어지는지를 보는 가장 단순한 persistence 모형이다.**
- **예시 : 인플레이션의 $\phi$가 크면 오늘의 물가상승 충격이 다음 분기에도 오래 남는다는 뜻이다.**
#### Properties of AR(2)
- AR(2) : $Y_t=c+\phi_1Y_{t-1}+\phi_2Y_{t-2}+\epsilon_t\quad \epsilon_t\sim iid\,N(0,\sigma_\epsilon^2)$
	- mean : $E[Y_t]=\frac{c}{1-\phi_1-\phi_2}=\mu$
	- *Var : 구하기 위해 행렬  (stationary 가정->일정함 가정)*
		- *목표 : 고차원 AR(p)를 AR(1)로 바꿔 분산 봄.. (1,1)원소 보면 발산 O? X?)*
		- *$\begin{bmatrix}Y_t\\ Y_{t-1}\end{bmatrix}=\begin{bmatrix}\phi_1 & \phi_2\\ 1 & 0\end{bmatrix}\begin{bmatrix}Y_{t-1}\\ Y_{t-2}\end{bmatrix}+\begin{bmatrix}\epsilon_t\\ 0\end{bmatrix}$ $\implies \zeta_t^{(2\times1)}=F^{(2\times2)}\zeta_{t-1}+v_t^{(2\times1)}$ $v_t\sim N(0,R);\,R=\begin{bmatrix}\sigma^2_{\epsilon} & 0 \\ 0 & 0\end{bmatrix}$*

	- Stationary 테스트 : $\lim_{j\to\infty}\rho_j=0$을 검증

		- hint : $Y_t$에 대해 재귀적 치환
		- $E(Y_t)=0$ (if $Y_0=0$)
		- $Var(Y_t)=\sum_{i=1}^tVar(u_i)=t\sigma^2$ : Var()가 t에 의해 바뀌므로 Non-sta. 함
- $I(p)$ : Intergrated of the order P
	- $let,\triangle Y_t:= Y_t-Y_{t-1};\quad Y_t\sim I(1)$
		- $X_t$가 차분을 p번할 시 sta. O : $X_t\sim I(p)$
	- ex) $Y_t=a+Y_{t-1}+u_t$ $\implies ta+Y_0+\sum_{i=0}^{t-1}u_{t-i};(Y_0=0)$
		- 절편 -> non-sta. 요소 O. shock 누적
			- a 자체가 t-t를 만들어냄
		- $\therefore$ $ta\to$ deterministic, $\sum\cdots\to$ stochastic
			- $Y^*_t=Y_t-at$ 여도, var() 때문에 $\sum$에서 non-sta.
- General non-stationary process : $Y_t=x_t+z_t$ -> non-sta. $\because x_t$
	- $x_t$ : non-sta. component
		- T-T인지? or UR인지? 혹은 혼합?
	- $z_t$ : sta. component -> AR,MA,ARMA 중 하나 OK
- **직관 : 실제 시계열은 “추세처럼 천천히 움직이는 부분”과 “그 주위에서 흔들리는 부분”이 섞여 있다고 보는 것이 편하다.**
- **예시 : GDP level은 성장추세와 경기순환이 함께 섞여 있어, 추세를 걷어내면 경기변동 부분만 볼 수 있다.**
### Lag operator
- $L$ : Lag OP.; ts. var.의 또다른 표기법
	- $L^jY_t=Y_{t-j}$,과거로;    $L^{-j}Y_t=Y_{t+j}$,미래로
- ARMA(p,q) : 
$Y_t=\phi_1Y_{t-1}+\phi_2Y_{t-2}+\cdots+\epsilon_t+\theta_1\epsilon_{t-1}+\cdots$ $\epsilon_t\sim N(0,\sigma^2)$
	- $\Rightarrow Y_t=(\phi_1LY_{t}+\phi_2L^2Y_{t}+\cdots)+(\epsilon_t+\theta_1\epsilon_{t-1}+\cdots)$
		- $\phi(L),\theta(L)$ 함수로 쓰면, : $\phi(L)Y_t=\theta(L)\epsilon_t$
		- where, $\phi(L)=(1-\phi_1L-\cdots-\phi_pL^p),$
		$\theta(L)=(1+\theta_1L+\cdots+\theta_qL^q)$
	- $(1-\phi L)^{-1}=\frac{1}{1-\phi L}$$=1+\phi L+\phi^2 L^2+\cdots+\phi^j L^j+\cdots$
		- 첫항 1, 공비 $\phi L$의 무한급수 합 (단,$|\phi|<1$)
			- $\phi(L)=(1-\phi L)\to$AR(1); $(1-\phi L)^{-1}(1-\phi L)=1$
- $\phi,\lambda$간 관계와 DSC
	- AR(1) : $\phi_1=\lambda$
	- AR(2) : sta. 조건을 찾기 위해 다시 고유값
		- $\lambda^2-\phi_1\lambda-\phi_2=0,|\lambda_n|<1\to sta.$
		- $\phi(L)=0 : 1-\phi_1L-\phi_2L^2=0$
			- 즉, $\phi(\frac{1}{\lambda})=\phi(L)=0$
		- 따라서 $|\lambda|<1\Leftrightarrow|L|>1$ 이어야 한다.
- 왜 unit root가 있다면 conven. 분포 X?
	- let, $y_t=\phi y_{t-1}+e_t;e_t\overset{iid}{\sim}N(0,\sigma^2)$
		- *$H_0:\phi=0,H_1:\phi<1$*
		- *$\hat{\phi}_{OLS}=\phi+\frac{\sum y_{t-1}y_t}{\sum y_{t-1}^2}\to$ 불편성?*
		- *but, 분포가 없? -> 하나 새로 만든다*
---
- Consistency : $\hat{\phi}\overset{p}{\to}\phi$ 가 성립하는가?(A) 분포는 뭔가(B)?
- *$\hat{\phi}=\frac{\sum y_{t-1}y_t}{\sum y_{t-1}^2}=\phi+\frac{1}{\sqrt{T}}\frac{(1):1/\sqrt{T}\sum y_{t-1}e_t}{(2):1/{T}\sum y_{t-1}^2}$*
	- *(A) 일관성 성립하나?* 
		- *($T\to\infty$) (1) : $\frac{1}{T}\sum y_{t-1}y_t\overset{p}{\to}0$; 2) $\frac{1}{T}\sum y_{t-1}^2\overset{p}{\to}Var(y_t)=\gamma_0$* 
	- *(B) 분포?*
		- *CLT에 의해 (2) -> $\gamma_0$*
		- *T 대신 $\sqrt{T}$를 대입하면,(수렴속도 맞춤)*
		  *$\frac{1}{\sqrt{T}}\sum y_{t-1}e_t\overset{d}{\to}N[E(y_te_t),(\star)Var(y_{t-1}e_t)]$ (by CLT)*
		- *$(\star)$ : by LIE, $Var(y_{t-1}e_t)=E(y_{t-1}^2e_t^2)$*
			- *$\to E(E(y_{t-1}^2e_t^2|I_{t-1}))=E(y_{t-1}^2E(e_t^2|I_{t-1}))$$=\sigma^2E(y_{t-1}^2)$*

 *(B) 분포 이어서 : $\hat{\phi}=\frac{\sum y_{t-1}y_t}{\sum y_{t-1}^2}=\phi+\frac{1}{\sqrt{T}}\frac{1/\sqrt{T}\sum y_{t-1}e_t}{1/{T}\sum y_{t-1}^2}$,*
	- *$\sqrt{T}(\hat{\phi}-\phi)\overset{d}{\to}N(0,\frac{\sigma^2}{\gamma_0})$    $\frac{\sigma^2}{\gamma_0}=1-\phi^2$*
	- *URT->$\phi=1$의 분포 : 통상적인 분포가 아니다*
- **직관 : unit root면 분산이 시간에 따라 커져버려서, 평소 쓰던 normal/t 근사 논리가 그대로 작동하지 않는다.**
- **예시 : random walk는 시간이 지날수록 흔들림 자체가 커지므로, stationary일 때의 t-test 기준을 그대로 적용하면 왜곡된다.**
- 왜 분포가 성립하지 않나? : 
	- *$if\phi=1,\frac{\hat{\phi}-\phi}{SE(\hat{\phi})}\sim(?)$<-Dickey-fuller dist.*
		- *임계치(C.V.)를 찾는다면 OLS 가능* 
		  *(CV : 유의수준 $\alpha$에 대해, $P(x)=\alpha$일 때의 $x$값을 읽는다)*
		- *$\sqrt{T}(\hat{\phi}-\phi)=\frac{1/\sqrt{T}\sum y_{t-1}e_t}{1/{T}\sum y_{t-1}^2}$*
### Unit Root Test
- AR(p) : $Y_t=\phi_1Y_{t-1}+\cdots+\phi_pY_{t-p}+\epsilon_t$; URT에선 다음을 테스트 :
	- $H_0:\sum_{i=1}^{p} \phi_i=1$ ($Y_t$ : non-sta.)
	- $H_1:\sum_{i=1}^{p} \phi_i<1$ ($Y_t$ : sta.)
- **직관 : URT의 핵심은 “충격이 결국 사라지는가, 아니면 누적되어 영구적으로 남는가”를 묻는 것이다.**
- **예시 : GDP에 unit root가 있으면 경기침체 충격이 일시적 반등으로 끝나기보다 장기 수준 자체를 바꿀 수 있다.**
#### Model 1 : Reg /w intercetp(절편O 모형)
- pop. : $Y_t=\delta+\phi Y_{t-1}+u_t$ (a)
	- $H_0 : \delta=0\cap\phi=1;\quad H_1:\delta\neq0\cap\phi<1$ (단, H1= !H0가 맞긴 함.)
	- Reg : $\triangle Y_t=\delta+\gamma Y_{t-1}+u_t$ ($let,\triangle Y_t:=Y_t-Y_{t-1};\gamma=-(1-\phi)$)
		- $H_0:\delta=\gamma=0$ ($Y_t$ -> non-sta.);    $H_1:!H_0$ ($Y_t$ -> sta.)
- **직관 : 여기서 핵심 검정 대상은 결국 $\gamma=0$인지 여부이고, 이는 원래 모형에서 unit root가 있는지를 차분회귀로 바꿔 본 것이다.**
#### Model 2 : Reg /w Time-trend(t-tO 모형)
- pop. : $Y_t=\delta_0+\delta_1 t+\phi Y_{t-1}+u_t$ (b)
	- $H_0 : \delta=0\cap\phi=1;\quad H_1:\delta\neq0\cap\phi<1$ (단, H1= !H0가 맞긴 함.)
		- $H_0$ 하의 true Data Generating Process(DGP) -> (a); $H_1$ 하는 -> (b)
	- Reg : $\triangle Y_t=\delta_0+\delta_1t+\gamma Y_{t-1}+u_t$ ($let,\triangle Y_t:=Y_t-Y_{t-1};\gamma=-(1-\phi)$)
		- $H_0:\delta_1=\gamma=0$ ($Y_t$ -> non-sta.);    $H_1:!H_0$ ($Y_t$ -> sta.)
- **직관 : 시간추세를 따로 넣는 이유는 “비정상성이 단순한 deterministic trend 때문인지, 진짜 unit root 때문인지”를 구분하려는 것이다.**
#### Augmented Dickey Fuller (ADF) Test
- (w/i) : $Y_t=\delta+\sum_{i=1}^p\phi_iY_{t-i}+u_t$;   (w/t-t) : $Y_t=\delta_0+\delta_1 t+\sum_{i=1}^p\phi_iY_{t-i}+u_t$ 
- (w/i)나 (w/t-t) 형태의 AR(p)가 존재함. 어떻게 URT? -> ADF.
	- (w/i), p=2; Reg : $\triangle Y_t=\delta+\gamma Y_{t-1}+\lambda_1\triangle Y_{t-1}+u_t$
		- $\gamma=-(1-\phi_1-\phi_2),\lambda_1=-\phi_2$
		- (hint : $\pm\phi_2 Y_{t-1}$ 더함, 차분형으로 만들고 $Y_{t-1}$로 묶기)
		- $H_0:\delta=\gamma=0$ ($Y_t$ -> non-sta.);    $H_1:!H_0$ ($Y_t$ -> sta.)
		- 아래와 같이 확장하자면,
	- (w/i), p=p; Reg : $\triangle Y_t=\delta+\gamma Y_{t-1}+\sum_{i=1}^{p-1}\lambda_i\triangle Y_{t-i}+u_t$
		-  $\gamma=-(1-\sum_{i=1}^p\phi_i)$
		-  $H_0:\delta=\gamma=0$ ($Y_t$ -> non-sta.);    $H_1:!H_0$ ($Y_t$ -> sta.)
	-  (w/t-t), p=p; Reg : $\triangle Y_t=\delta_0+\delta_1 t+\gamma Y_{t-1}+\sum_{i=1}^{p-1}\lambda_i\triangle Y_{t-i}+u_t$
		-  $\gamma=-(1-\sum_{i=1}^{p-1}\phi_i)$
		-  $H_0:\delta=\gamma=0$ ($Y_t$ -> non-sta.);    $H_1:!H_0$ ($Y_t$ -> sta.)
	- 즉, $\gamma$로 표현되는 $1-\sum\phi$에서, 결국 $\sum\phi=1$의 여부가 중요하다 
- **직관 : ADF는 lagged difference를 추가해 오차의 자기상관을 흡수한 뒤에도 unit root가 남는지 보는, 더 현실적인 DF test다.**
- **예시 : 실제 거시 변수는 단순 AR(1)보다 더 긴 자기상관을 가지므로, ADF는 inflation·GDP·interest rate 같은 자료에 더 자주 쓴다.**
