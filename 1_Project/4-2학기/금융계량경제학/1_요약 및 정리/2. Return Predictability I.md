# Unconditional and conditional expecatation
- Unconditional : $E(Y)=\int y\cdot p(y) dy$
- Conditional : $E(Y|X=x)=\int y\cdot p(y|X=x) dy$
# Law of iterative expectation
- 반복 기대의 법칙 : $E(Y)=E(E(Y|X))$
	- 조건부 확률들의 평균은 무조건부 확률과 같다

# Traditional view for return predictability
- $R_{t+1}=a+bx_t+\epsilon_{t+1}$
	- b = 0라면, $E_t[R_{t+1}]=a+bx_t$; 수익을 예측할 수 X. 
		- $\because$ 무조건부 평균인 a 이상으로 예측할 수 X.
		- $\to$ 예측X = 현재 시장에 모든 정보 반영. 
	- b $\neq$ 0라면, $E_t[R_{t+1}]=a+bx_t$; 수익을 예측할 수 있다

# Dividend-price ratio
- $R_{t+1}=\frac{P_{t+1}+D_{t+1}}{P_{t}}$ : 미래 수익 = 미래의 가격&배당과 비례, 현재 가격과 반비례
- $P_{t}=\frac{P_{t+1}+D_{t+1}}{R_{t+1}}$ : 현재 가격 = 미래의 현금흐름(주가+배당)에 대한 현재가치(수익률)
	- $P_t=\sum_{j=1}^\infty \frac{D_{t+j}}{\prod_{i=1}^j R_{t+j}}=E(D_t|I_t)=E_tP_t=P_t$
	- $E_tD_{t+1}$가 바뀔때 : $E_tD_{t+1}\uparrow\uparrow\to P_t\uparrow\uparrow$
		- $E_tR_{t+1}\uparrow\uparrow\to P_t\downarrow\downarrow$ : 리스크$\uparrow\uparrow\to$리턴$\uparrow\uparrow$ 
- DP ratio에 대한 로그 차분
	- OLS가 불가능. 데이터를 변환
	- $R_{t+1}=\frac{D_{t+1}}{P_t}\to \frac{P_{t}}{D_t}=\frac{E_t(D_{t+1}/D_t)}{E_t(R_{t+1})}$ ($E_t()$씌우고 $P_t,E_t(R_{t+1})$ 자리 바꿈, $D_t$ 나눔)
	- $p_t-d_t=E_t(\triangle d_{t+1})-E_t(r_{t+1})$ (위에 로그)
		- 의미 :
			- 투자자들이 미래 배당/수익에 대한 정보를 얻어 기대를 형성, 현재 가격이 반응 ($\triangle d_{t+1}, r_{t+1}\to E_t(\triangle d_{t+1}), E_t(r_{t+1})\propto p_t$)
			- 투자자들의 정보 모르지만, 기대가 현재에 반영 ($p_t-d_t$)
		- $p_t$에 영향 주는것?
			- dividend growth ($E_t(\triangle d_{t+1})\uparrow\uparrow$) : 회사 성장 기류; $p_t\uparrow\uparrow$
			- discount rate $\uparrow\uparrow$ : risk $\uparrow\uparrow$; $p_t\downarrow\downarrow$
