그 목적이면 추천 목록을 꽤 수정해야 합니다.
질문이 이제 단순한 독서가 아니라 **측정 설계**입니다.

> “문학적 우수성이 문화산업의 수요를 견인하는가?”
> → “문학인덱스를 만들고”
> → “그 인덱스가 비평이론적 feature들로 설명되는가?”

이 경우 필요한 책은 **문학비평 입문서**보다 **문학성을 변수화할 수 있는 분석 범주를 제공하는 책**입니다.

## 먼저 결론

영화 분석이 필요 없다면, 저는 이렇게 재구성하겠습니다.

# 3. 서사학 레퍼런스: **Gerald Prince, *A Dictionary of Narratology***

이 책은 두껍지 않지만 레퍼런스 역할이 강합니다.

University of Nebraska Press 정보에 따르면 개정판은 2003년 출간되었고, 표와 도식 9개를 포함한 약 140쪽 분량의 서사학 사전입니다. 전자책판도 2020년에 나왔습니다. ([University of Nebraska Press][2])

처음부터 읽는 책이라기보다, **feature 정의를 표준화할 때 쓰는 책**입니다.

예를 들어 연구 설계에서 이런 문제가 생깁니다.

> “시점”과 “초점화”를 같은 변수로 둘 것인가?
> “서술자 신뢰도”는 어떤 기준으로 코딩할 것인가?
> “플롯”과 “스토리”를 어떻게 구분할 것인가?

이때 Prince가 유용합니다.

| 연구상 필요     | Prince의 역할                      |
| ---------- | ------------------------------- |
| 용어 정의      | 서사학 개념의 간결한 정의 제공               |
| feature 명명 | 변수명을 이론적으로 정당화                  |
| 코딩북 작성     | 주석자 간 일관성 확보                    |

따라서 이 책은 얇지만, “너무 얇어서 useless”한 책이 아닙니다.
**정독서가 아니라 사전형 레퍼런스**이기 때문입니다.

# 4. 독자 반응·몰입 축: **Peter Stockwell, *Cognitive Poetics: An Introduction***

이 책은 지금 주제에 특히 중요합니다.

왜냐하면 선생님의 연구 질문은 결국 다음을 포함하기 때문입니다.

> 문학적 우수성은 수요를 견인하는가?

그렇다면 문학성은 단지 텍스트 내부 구조가 아니라 **독자가 왜 반응하는가**와 연결되어야 합니다.

Routledge는 *Cognitive Poetics* 2판을 문학 읽기와 분석에 대한 인지언어학·심리학 기반 접근으로 소개하며, 2판은 문학적 의미, 독서의 힘, 문학적 force, emotion 등에 관한 설명을 갱신했다고 설명합니다. ([Routledge][3])

여기서 만들 수 있는 feature는 다음과 같습니다.

| 인지시학 개념 | 가능한 feature              |
| ------- | ------------------------ |
| 전경화     | 비일상적 표현, 은유, 반복, 문체적 일탈  |
| 몰입      | 공간·감각 묘사 밀도, 인물 내면 접근성   |
| 정서적 강도  | 감정 어휘, 평가 형용사, 정서 전환     |
| 스키마     | 장르 기대와의 일치/위반            |
| 관점 이동   | 초점화 변화, 대명사 사용, 지각 동사    |
| 인지 부하   | 문장 길이, 구문 복잡도, 시간 구조 복잡도 |

이 축은 “문학인덱스”에 매우 중요합니다.
왜냐하면 문화산업 수요는 순수한 미학성만으로 움직이지 않고, **가독성, 몰입성, 감정적 처리 가능성, 장르 기대 충족**과도 연결되기 때문입니다.

# 다만 연구 설계상 중요한 경고

선생님의 연구 질문에서 가장 위험한 부분은 **“문학적 우수성”이라는 종속 또는 독립 개념을 어떻게 정의할 것인가**입니다.

문학인덱스를 만들 때, 다음을 섞으면 안 됩니다.

| 구분             | 예시                            |
| -------------- | ----------------------------- |
| 텍스트 내재 feature | 문체 복잡도, 서사 구조, 은유 밀도          |
| 비평적 평가 feature | 수상 여부, 평론가 평점, 문학사적 언급량       |
| 시장 성과 feature  | 판매량, 대출량, 검색량, 각색 여부          |
| 문화산업 수요        | 영화화, 드라마화, 웹툰화, 판권 계약, 2차 창작량 |

특히 **문학인덱스에 수상·리뷰·판매량을 넣고, 다시 문화산업 수요를 설명하면 순환논증**이 됩니다.

예를 들어:

> 문학인덱스 = 평론가 평점 + 수상 여부 + 판매량
> 문화산업 수요 = 각색 여부 + 판매량 + 검색량

이렇게 하면 모델이 “문학성이 수요를 견인한다”를 보이는 것이 아니라, **이미 수요와 평판이 섞인 지표가 다른 수요 지표를 예측한다**는 결과가 됩니다.

따라서 문학인덱스는 가능하면 두 층으로 나누는 것이 좋습니다.

| --- | ----------------------------- |

| 주제성 | 주제 다양도, 추상 개념 밀도, 가치 갈등       |
| 장르성 | 장르 관습 밀도, 장르 혼합도              |
| 정서성 | 감정 곡선, 정서 전환, 정서 강도           |

텍스트 외부에서 추출합니다.

| 차원      | feature         |
| ------- | --------------- |

이 둘은 분리해야 합니다.

그리고 최종적으로는 이런 모델이 더 타당합니다.

> 텍스트 기반 문학성
> → 비평적 인정
> → 문화산업 수요

또는

> 텍스트 기반 문학성
>
> * 장르 적합성
> * 시장 조건
>   → 문화산업 수요

| 정서 동역학  | sentiment arc, 감정 전환 빈도          | 인지시학           |
| 해석 가능성  | 상징, 모호성, 열린 결말                   | 문학이론           |
| 사회적 쟁점성 | 젠더·계급·식민성·생태 등 담론 밀도             | 비평이론           |

여기서 중요한 것은 **모든 feature를 “문학적 우수성”으로 넣지 않는 것**입니다.

예를 들어 장르 적합성은 문학적 우수성이라기보다 **시장 수요의 조절변수**일 수 있습니다.

> 문학성 × 장르 적합성 → 수요

이런 interaction term을 봐야 할 가능성이 큽니다.

네. 여기서 제가 너무 연구자식 표현을 썼습니다.
학부 고학년·석사 초입 단계라면 **“상위차원-feature”**를 이렇게 이해하시면 됩니다.

## 1. 그냥 feature를 다 때려박아도 됩니다

머신러닝에서는 실제로 최종 데이터셋이 보통 이렇게 생깁니다.

| 작품 | 평균문장길이 | 어휘다양도 | 감정강도 | 인물수 | 사건밀도 | 장르   |    판매량 |
| -- | -----: | ----: | ---: | --: | ---: | ---- | -----: |
| A  |   18.2 |  0.71 | 0.33 |  12 | 0.42 | SF   |  50000 |
| B  |   12.5 |  0.58 | 0.61 |   6 | 0.73 | 로맨스  | 120000 |
| C  |   25.1 |  0.82 | 0.21 |  30 | 0.35 | 역사소설 |  30000 |

그리고 모델에는 결국 이런 식으로 들어갑니다.

```text
X = [평균문장길이, 어휘다양도, 감정강도, 인물수, 사건밀도, 장르...]
y = 판매량 또는 각색 여부 또는 검색량
```

즉, **모델 입장에서는 feature가 한꺼번에 들어가는 것이 맞습니다.**

제가 말한 “상위차원”은 모델 입력 형식이 아니라, **feature를 설계하고 해석하기 위한 분류표**입니다.

---

# 2. 상위차원은 feature 폴더라고 보시면 됩니다

예를 들어 컴퓨터 파일 정리처럼 생각하시면 됩니다.

```text
문학인덱스/
 ├─ 문체 feature/
 │   ├─ 평균문장길이
 │   ├─ 어휘다양도
 │   ├─ 한자어비율
 │   └─ 비유표현빈도
 │
 ├─ 서사 feature/
 │   ├─ 사건밀도
 │   ├─ 인물수
 │   ├─ 시점전환수
 │   └─ 대화비율
 │
 ├─ 정서 feature/
 │   ├─ 긍정감정비율
 │   ├─ 부정감정비율
 │   ├─ 감정변동성
 │   └─ 클라이맥스감정강도
 │
 └─ 장르 feature/
     ├─ 장르더미변수
     ├─ 장르혼합도
     └─ 장르관습충족도
```

이때 **문체, 서사, 정서, 장르**가 상위차원입니다.
그리고 **평균문장길이, 사건밀도, 감정변동성** 같은 것이 실제 feature입니다.

모델에는 결국 아래 feature들이 한 줄로 들어갑니다.

```text
[평균문장길이, 어휘다양도, 사건밀도, 인물수, 긍정감정비율, 장르더미...]
```

그러나 연구자가 해석할 때는 이렇게 말할 수 있습니다.

> 문체 feature는 수요 예측에 별 도움이 안 되었지만,
> 서사 feature와 장르 feature는 도움이 되었다.

이런 해석을 하려고 상위차원을 나누는 것입니다.

---

# 3. 왜 굳이 상위차원을 나누나?

이유는 세 가지입니다.

## 1) feature를 빠뜨리지 않기 위해서입니다

그냥 생각나는 feature를 넣으면 이런 일이 생깁니다.

```text
평균문장길이
어휘다양도
감정점수
리뷰수
판매량
작가성별
수상여부
장르
```

겉보기에는 다양해 보이지만, 실제로는 뒤죽박죽입니다.

* 텍스트 내부 feature
* 시장 feature
* 작가 metadata
* 비평 제도 feature

가 섞여 있습니다.

이러면 나중에 “문학성이 수요를 예측했다”고 말하기 어렵습니다.
사실은 **수상 여부나 리뷰수 같은 시장·제도 신호가 예측했을 수도 있기 때문**입니다.

---

## 2) 모델 결과를 해석하기 위해서입니다

예를 들어 feature importance가 이렇게 나왔다고 해보겠습니다.

| feature |  중요도 |
| ------- | ---: |
| 장르      | 0.31 |
| 작가 인지도  | 0.22 |
| 사건밀도    | 0.12 |
| 평균문장길이  | 0.04 |
| 어휘다양도   | 0.03 |
| 감정변동성   | 0.10 |
| 인물수     | 0.08 |

이걸 그냥 보면 조금 산만합니다.

하지만 상위차원으로 묶으면 이렇게 볼 수 있습니다.

| 상위차원     | 포함 feature    | 대략적 해석       |
| -------- | ------------- | ------------ |
| 시장/작가 요인 | 장르, 작가 인지도    | 수요 예측에 매우 강함 |
| 서사 요인    | 사건밀도, 인물수     | 어느 정도 영향 있음  |
| 문체 요인    | 평균문장길이, 어휘다양도 | 영향 약함        |
| 정서 요인    | 감정변동성         | 일부 영향 있음     |

그러면 연구 결론이 더 선명해집니다.

> 문화산업 수요는 순수한 문체적 문학성보다 장르성, 작가 인지도, 서사적 사건성에 더 크게 반응한다.

이런 식으로요.

---

## 3) “문학성”을 너무 조잡하게 만들지 않기 위해서입니다

문학적 우수성은 하나의 숫자로 단순화하기 어렵습니다.

그래서 처음부터 이렇게 나눠야 합니다.

```text
문학성 = 문체성 + 서사성 + 주제성 + 정서성 + 장르적 완성도
```

물론 이 공식이 진리라는 뜻은 아닙니다.
연구자가 임시로 만든 조작적 정의입니다.

중요한 점은 이것입니다.

> “문학성”이라는 큰 개념을 바로 숫자로 만들 수는 없습니다.
> 그래서 더 작은 feature들로 쪼개야 합니다.

# 8. “문학인덱스”는 나중에 만들어도 됩니다

처음부터 문학인덱스라는 하나의 점수를 만들 필요는 없습니다.

오히려 순서는 반대가 낫습니다.

## 나쁜 순서

```text
문학인덱스부터 만든다
→ 수요와 상관관계를 본다
→ 해석한다
```

위험합니다.
문학인덱스를 어떻게 만들었는지 방어하기 어렵습니다.

## 좋은 순서

```text
여러 텍스트 feature를 만든다
→ 어떤 feature가 수요를 예측하는지 본다
→ 중요한 feature들을 묶어 사후적으로 차원을 해석한다
→ 그다음 문학인덱스 후보를 만든다
```

처음에는 “문학인덱스”라는 이름을 쓰기보다,

> 텍스트 기반 문학 feature set

정도로 부르는 게 안전합니다.

# 9. 아주 간단한 예시

예를 들어 이런 모델을 돌렸다고 합시다.

```text
y = 리뷰 수

X =
- 평균문장길이
- 어휘다양도
- 대화비율
- 인물수
- 감정변동성
- 장르
- 출간연도
```

결과가 이렇게 나왔다고 해보겠습니다.

| feature | 영향    |
| ------- | ----- |
| 장르      | 큼     |
| 대화비율    | 큼     |
| 감정변동성   | 중간    |
| 어휘다양도   | 작음    |
| 평균문장길이  | 거의 없음 |

그러면 결론은 이렇게 됩니다.

> 리뷰 수로 측정한 문화산업 수요는 문체적 복잡성보다 장르, 대화 중심성, 정서적 변동성에 더 크게 반응하는 경향을 보였다.

이건 꽤 말이 됩니다.

하지만 여기서 바로 이렇게 말하면 안 됩니다.

> 문학적 우수성은 수요에 영향을 주지 않는다.

왜냐하면 평균문장길이와 어휘다양도가 문학적 우수성 전체를 대표하지는 않기 때문입니다.

더 조심스럽게는 이렇게 말해야 합니다.

> 본 연구에서 사용한 제한적 텍스트 feature 기준으로는, 문체적 복잡성보다 장르·서사·정서 feature가 수요 proxy와 더 강하게 관련되었다.

이게 학술적으로 안전한 표현입니다.

# 10. 지금 단계에서 책도 줄이겠습니다

선생님 상황이면 책을 너무 많이 읽는 것보다, **바로 feature 설계를 해보는 게 더 중요합니다.**

## 최소 독서 2권

| 책                                                                             | 목적                  |
| ----------------------------------------------------------------------------- | ------------------- |
| **Abbott, *The Cambridge Introduction to Narrative*** 또는 제럴드 프린스 <서사학이란 무엇인가> | 서사 feature 이해       |
| **Stockwell, *Cognitive Poetics***                                            | 문체·정서·인지 feature 이해 |

## 비평이론 책은 후순위

**<문학 ‘읽기’의 방법들>**은 읽으면 좋지만, 지금 연구 설계의 핵심은 아닙니다.

왜냐하면 ML feature로 바로 추출하기 쉬운 것은 보통 다음입니다.

* 문장 길이
* 어휘 다양도
* 감정 점수
* 대화 비율
* 인물명 빈도
* 장르
* 주제 모델링
* 사건 동사

반면 페미니즘, 탈식민주의, 정신분석 같은 비평이론 feature는 자동 추출하기 어렵습니다.
하려면 annotation, LLM 기반 라벨링, 혹은 별도 분류기가 필요합니다.

초기 프로젝트에서는 위험합니다.

# 정리

선생님이 이해하신 것처럼, **모델에는 feature를 한꺼번에 넣는 것이 맞습니다.**

제가 말한 **상위차원-feature**는 이런 뜻입니다.

> 상위차원 = feature를 정리하는 폴더
> feature = 모델에 실제로 들어가는 숫자 변수

학부 고학년·석사 초입 프로젝트라면 이렇게 가십시오.

1. **문학인덱스를 처음부터 만들지 마십시오.**
2. 우선 텍스트 feature set을 만드십시오.
3. feature를 문체·서사·정서·장르 정도로만 묶으십시오.
4. 수요 proxy는 하나만 고르십시오. 예: 리뷰 수, 대출량, 각색 여부.
5. baseline 모델을 만드십시오.
6. feature importance 또는 회귀계수로 어떤 차원이 중요한지 해석하십시오.

처음부터 거대한 “문학성 지수”를 만들려고 하면 추상성이 너무 커집니다.
처음 연구는 **“문학성 전체”가 아니라 “텍스트 feature들이 수요를 어느 정도 설명하는가”**로 낮추는 게 맞습니다.

---
네. **오히려 그렇게 한정하는 편이 좋습니다.**
학부 고학년·석사 초입 연구라면 “문학 전체”를 대상으로 잡는 것보다 **실존주의 문학 또는 SF 소설 중 하나로 좁히는 것이 훨씬 안전합니다.**

다만 **실존주의 문학과 SF를 동시에 한 장르 차원으로 묶는 것은 조심해야 합니다.** 둘은 성격이 다릅니다.

| 범주      | 성격                 |
| ------- | ------------------ |
| 실존주의 문학 | 사조·철학적 문제의식·주제적 계열 |
| SF 소설   | 장르·세계관 규칙·서사 관습    |

즉, **SF는 장르 변수로 다루기 쉽고**, **실존주의 문학은 주제/사조 변수로 다루는 편이 더 자연스럽습니다.**

---

## 가장 좋은 선택: SF로 한정

연구 설계상으로는 **SF 소설만 대상으로 삼는 것**을 더 추천합니다.

이유는 명확합니다.

| 이유         | 설명                                               |
| ---------- | ------------------------------------------------ |
| 표본 확보      | SF는 장르 라벨이 비교적 명확합니다                             |
| 시장 수요 측정   | 판매량, 리뷰 수, 각색 여부, 팬덤 반응과 연결하기 쉽습니다               |
| feature 설계 | 세계관, 기술, 미래성, 외계성, 인식 전환 등 장르 feature를 만들 수 있습니다 |
| 문화산업 연결성   | 영화화·드라마화·게임화·웹툰화 등 IP 확장과 연결하기 좋습니다              |

SF로 한정하면 연구 질문은 이렇게 정리할 수 있습니다.

> SF 소설에서 텍스트 기반 문학 feature는 문화산업 수요를 예측하는가?

조금 더 구체적으로는:

> SF 소설의 서사 구조, 문체적 복잡성, 정서 곡선, 세계관 밀도, 과학기술 소재성이 리뷰 수·대출량·각색 여부 같은 수요 지표를 설명하는가?

이 정도면 석사 초입 연구로도 형태가 잡힙니다.

## SF로 한정할 때 feature 예시

SF는 일반 문학 feature에 더해 **SF 고유 feature**를 만들 수 있습니다.

| 상위차원  | feature 예시                                     |
| ----- | ---------------------------------------------- |
| 문체    | 평균문장길이, 어휘다양도, 전문용어 비율                         |

이 중에서 처음부터 전부 하지 마십시오.
초기 프로젝트라면 아래 정도면 충분합니다.

| 최소 feature | 구현 난도  |
| ---------- | ------ |
| 평균문장길이     | 쉬움     |
| 어휘다양도      | 쉬움     |
| 대화비율       | 중간     |
| 고유명사 수     | 중간     |
| 과학기술 어휘 비율 | 중간     |
| 감정변동성      | 중간     |
| 하위장르 태그    | 수작업 가능 |

SF에서는 특히 **세계관 밀도**와 **과학기술 어휘 비율**이 흥미로운 변수가 될 수 있습니다.

## 실존주의 문학으로 한정할 경우

실존주의 문학도 가능합니다.
하지만 SF보다 어렵습니다.

이유는 다음입니다.

| 문제             | 설명                                         |
| -------------- | ------------------------------------------ |
| 장르 경계가 흐림      | 무엇을 실존주의 문학으로 볼지 합의가 어렵습니다                 |
| 표본 수 제한        | 카뮈, 사르트르, 도스토옙스키, 카프카 등을 넣을지 논쟁적입니다        |
| 수요 측정 왜곡       | 고전성, 교육과정, 철학사적 명성이 수요에 크게 개입합니다           |
| feature 자동화 난도 | 부조리, 소외, 자유, 불안, 죽음 같은 개념은 단순 빈도로 잡기 어렵습니다 |

즉, 실존주의 문학은 “장르”라기보다 **주제적·철학적 코퍼스**입니다.

연구 질문도 이렇게 바꿔야 합니다.

> 실존주의적 주제 feature는 독자 반응 또는 비평적 수용과 어떤 관련을 갖는가?

또는:

> 실존주의 문학에서 소외, 불안, 죽음, 자유, 부조리의 주제 강도는 독자 평점·리뷰 양상과 관련되는가?

이쪽은 문화산업 수요보다는 **독자 반응 분석**이나 **비평적 수용 분석**에 더 잘 맞습니다.

## 둘을 같이 하고 싶다면?

가능은 합니다.
다만 연구 질문을 이렇게 바꿔야 합니다.

> SF와 실존주의 문학에서 텍스트 feature가 수요 지표를 설명하는 방식은 어떻게 다른가?

하지만 이건 난도가 확 올라갑니다.

비교해야 할 것이 많아집니다.

| 비교 항목 | 문제                               |
| ----- | -------------------------------- |
| 장르 차이 | SF는 대중장르, 실존주의는 사조/철학적 계열        |
| 시대 차이 | 실존주의 고전은 오래된 작품이 많음              |
| 번역 차이 | 한국어 번역본 기준이면 번역자 문체가 feature에 섞임 |
| 수요 차이 | SF 수요와 고전문학 수요는 성격이 다름           |
| 표본 수  | 양쪽 균형 잡기가 어려움                    |

학부·석사 초입에서는 **비추천**입니다.

## 3안: SF 안의 실존주의적 주제만 본다 — 가장 흥미로운 절충안

개인적으로는 이게 제일 좋습니다.

즉, **SF 소설을 대상으로 하되, 실존주의적 주제 feature를 넣는 방식**입니다.

연구 질문:

> SF 소설에서 실존주의적 주제성은 문화산업 수요와 어떤 관계를 갖는가?

예를 들면:

| SF 작품의 요소  | 실존주의적 feature |
| ---------- | ------------- |
| 인간과 AI의 경계 | 인간 정체성        |
| 우주적 고립     | 소외            |
| 디스토피아      | 자유와 억압        |
| 시간여행       | 선택과 책임        |
| 외계 문명 접촉   | 인간 조건의 상대화    |
| 포스트아포칼립스   | 죽음, 생존, 의미    |

이렇게 하면 두 관심사를 모두 살릴 수 있습니다.

이 경우 feature는 이렇게 잡을 수 있습니다.

| feature 그룹    | 예시                               |
| ------------- | -------------------------------- |
| SF 장르 feature | 과학기술 어휘, 세계관 밀도, 하위장르            |
| 서사 feature    | 사건밀도, 인물수, 대화비율                  |
| 정서 feature    | 감정변동성, 불안/공포/희망 어휘               |
| 실존주의 feature  | 소외, 자유, 죽음, 부조리, 선택, 책임 관련 어휘·문장 |
| 수요 지표         | 리뷰 수, 평점 수, 대출량, 각색 여부           |

이게 연구 제목으로도 더 선명합니다.

> **SF 소설의 실존주의적 주제성과 문화산업 수요의 관계: 텍스트 마이닝 기반 탐색 연구**

이 정도면 학부 고학년 프로젝트나 석사 초입 연구로 꽤 현실적입니다.

# 최종 판단

**장르 차원을 실존주의 문학 또는 SF 소설로 한정해도 됩니다.**
오히려 한정해야 합니다.

다만 추천 순서는 이렇습니다.

1. **SF 소설만 대상으로 한다**
   → 가장 현실적이고 데이터화가 쉬움.

2. **SF 소설 안에서 실존주의적 주제 feature를 본다**
   → 선생님 관심사를 가장 잘 살리는 절충안.

3. **실존주의 문학만 대상으로 한다**
   → 가능하지만 장르 연구보다는 주제·수용 연구가 됨.

제일 좋은 방향은 2번입니다.

> **SF라는 장르를 고정하고, 그 안에서 실존주의적 주제성이 수요와 관련되는지 본다.**

이렇게 하면 장르 차원은 통제되고, 선생님이 진짜 궁금해하는 철학적·문학적 feature를 분석할 수 있습니다.

---

맞습니다. 이 문제는 **단순한 실무 장애가 아니라 연구 설계의 핵심 제약**입니다.
그래서 처음부터 “현대 SF 원문 전체를 대량으로 긁어서 분석한다”로 잡으면 위험합니다.

정리하면 제약은 세 가지입니다.

| 제약  | 문제                                         |
| --- | ------------------------------------------ |
| 저작권 | 현대 소설 원문을 대량 수집·저장·분석하는 행위가 법적으로 불안정할 수 있음 |
| 접근성 | PDF, TXT, EPUB이 항상 제공되지 않음                 |
| 품질  | OCR, 번역본, 판본 차이 때문에 텍스트 feature가 왜곡될 수 있음  |

따라서 연구를 설계할 때는 **원문 전체 분석형**과 **원문 비의존형**을 분리해서 생각해야 합니다.

# 1. 가장 안전한 길: 퍼블릭 도메인 SF로 시작

학부 고학년·석사 초입 프로젝트라면 가장 안전한 출발점은 **저작권이 만료되었거나 공개 이용이 가능한 텍스트**입니다.

예를 들어:

* 쥘 베른
* H. G. 웰스
* 메리 셸리
* 에드거 라이스 버로스 일부 작품
* 초기 과학소설 잡지 수록작 일부
* Project Gutenberg 수록 SF 고전

Project Gutenberg는 미국 저작권법 기준으로 운영되며, 미국 외 지역에서는 저작권 상태가 다를 수 있으므로 재배포나 활용 전 각국 법률 확인이 필요하다고 명시합니다. 따라서 한국에서 연구할 경우에도 “미국에서 공개되어 있으니 무조건 안전하다”고 단정하면 안 됩니다. ([Project Gutenberg][1])

그래도 연구실 내부 분석용으로는 **가장 낮은 위험의 출발점**입니다.

## 장점

| 장점        | 설명                   |
| --------- | -------------------- |
| 원문 확보 쉬움  | TXT 형태가 많음           |
| 반복 가능성    | 다른 연구자가 재현하기 쉬움      |
| 저작권 위험 낮음 | 현대 상업소설보다 훨씬 안전      |
| 전처리 쉬움    | PDF/OCR보다 텍스트 품질이 좋음 |

## 단점

| 단점               | 설명                             |
| ---------------- | ------------------------------ |
| 현대 문화산업 수요와 거리   | 오래된 작품이라 현재 시장 수요와 직접 연결하기 어려움 |
| 표본 편향            | 고전 중심                          |
| 생존자 편향           | 이미 살아남은 작품만 분석하게 됨             |
| SF 장르의 현대적 특성 부족 | AI, 사이버펑크, 기후 SF, 포스트휴먼 등은 약함  |

따라서 이 방식은 **방법론 파일럿**에 적합합니다.

> “문학인덱스 feature를 추출할 수 있는가?”
> “feature가 평판·수용 지표와 어느 정도 관련되는가?”

를 보는 데 좋습니다.

---

# 2. 현대 SF를 보려면 “원문 전체”가 아니라 “합법적 proxy”를 써야 합니다

현대 작품을 대상으로 하려면 원문 전체를 확보하지 못해도 가능한 설계가 있습니다.

## 대안 A: 메타데이터 + 리뷰 텍스트 분석

원문 소설 대신 다음을 분석합니다.

| 데이터     | 의미           |
| ------- | ------------ |
| 줄거리 소개  | 주제, 장르, 소재   |
| 출판사 책소개 | 시장 포지셔닝      |
| 독자 리뷰   | 수용 방식, 감정 반응 |
| 평론      | 비평적 인정       |
| 태그      | 장르·주제 분류     |
| 평점 수    | 관심도 proxy    |
| 리뷰 수    | 수요 proxy     |
| 도서관 대출량 | 실제 이용 proxy  |

이 방식은 원문 전체를 쓰지 않기 때문에 저작권 위험이 상대적으로 낮습니다.
다만 플랫폼 약관과 크롤링 정책은 반드시 확인해야 합니다.

이 설계의 질문은 이렇게 바뀝니다.

> SF 소설의 원문 feature가 수요를 예측하는가?

가 아니라:

> SF 소설의 메타데이터·리뷰·소개문 기반 feature가 수요를 예측하는가?

덜 이상적이지만 **현실성은 훨씬 높습니다.**

# 3. 원문 없이도 만들 수 있는 feature

원문이 없어도 꽤 많은 feature를 만들 수 있습니다.

## 책소개/줄거리 기반 feature

| feature  | 예시                                     |
| -------- | -------------------------------------- |
| 하위장르     | 디스토피아, 우주개척, AI, 시간여행, 기후 SF           |
| 소재 밀도    | 과학기술어, 우주어, 생명공학어, 재난어                 |
| 실존주의 주제성 | 고립, 죽음, 선택, 자유, 책임, 정체성                |
| 갈등 유형    | 인간 vs 자연, 인간 vs 기술, 인간 vs 체제, 인간 vs 자기 |
| 세계관 명료성  | 고유명사, 장소명, 조직명                         |

## 리뷰 기반 feature

| feature   | 의미                             |
| --------- | ------------------------------ |
| 감정 평균     | 독자 반응의 전반적 긍정/부정               |
| 감정 분산     | 호불호 강도                         |
| 몰입 관련 어휘  | “몰입”, “흡입력”, “페이지터너” 등         |

| 장르쾌감 어휘   | “설정”, “세계관”, “반전”, “상상력” 등     |
| 실존주의 어휘   | “고독”, “불안”, “의미”, “인간”, “존재” 등 |

이건 오히려 “문화산업 수요” 연구에 강점이 있습니다.
왜냐하면 수요는 원문 자체보다 **독자가 작품을 어떻게 받아들였는가**와 더 직접적으로 연결되기 때문입니다.

* 공개 샘플 챕터

주의할 점은, **전자책 DRM을 우회하거나 불법 파일을 사용하는 방식은 피해야 합니다.** 연구 윤리상도 좋지 않고, 나중에 논문이나 발표에서 방법론을 공개하기 어렵습니다.

# 5. “비소비적 연구” 방식도 있습니다

해외 디지털 인문학에서는 **non-consumptive research**라는 방식이 있습니다.
이는 연구자가 저작권 보호 텍스트의 원문을 읽거나 배포하지 않고, 통계량·feature·모델 출력만 사용하는 방식입니다.

HathiTrust Research Center는 저작권 보호 자료에 대해 원문 다운로드 없이 데이터 마이닝 같은 비소비적 연구를 수행할 수 있는 도구를 제공한다고 설명합니다. ([HathiTrust][2])

이 개념은 선생님 연구에 매우 중요합니다.

핵심은 이겁니다.

> 원문을 공개하거나 재배포하지 않고,
> 원문에서 추출한 통계 feature만 분석한다.

예를 들어 논문에는 이런 것만 남깁니다.

| 작품 | 평균문장길이 | 어휘다양도 | 감정변동성 | 과학기술어비율 |
| -- | -----: | ----: | ----: | ------: |
| A  |   18.2 |  0.71 |  0.33 |   0.042 |
| B  |   12.5 |  0.58 |  0.61 |   0.017 |

원문 문장은 공개하지 않습니다.

다만 이것도 **자료 접근 자체가 합법적이어야 합니다.**
불법 PDF를 구해 놓고 “통계만 뽑았으니 괜찮다”는 논리는 위험합니다.

# 10. 제 판단

선생님의 문제의식은 정확합니다.
**원문 전체를 전제로 한 문학 ML 연구는 저작권과 데이터 접근성 때문에 초입 연구에는 위험합니다.**

따라서 이렇게 가는 게 좋습니다.

## 가장 현실적인 경로

1. **공개 원문 SF로 텍스트 feature 추출 방법을 검증한다.**
2. **현대 SF는 원문 대신 리뷰·책소개·메타데이터·대출량으로 분석한다.**
3. **원문 feature와 수용 feature를 분리한다.**
4. **불법 텍스트나 DRM 우회는 쓰지 않는다.**
5. **논문에서는 원문을 공개하지 않고 feature table만 공개한다.**

즉, 연구를 이렇게 바꾸는 게 안전합니다.

> “소설 원문 전체를 분석해 문학성을 측정한다”
> 보다는
> **“공개 원문과 수용 담론 데이터를 결합해 SF 소설의 문학적·장르적 feature가 수요와 어떤 관련을 갖는지 탐색한다.”**

이 방향이 학부 고학년·석사 초입 수준에서 가장 현실적이고, 방어 가능성이 높습니다.

---

네. 그 질문이라면 **원문 전체가 필요하다는 판단이 맞습니다.**
책소개·리뷰·메타데이터만으로는 선생님이 묻는 핵심 질문에 도달하기 어렵습니다.

선생님의 질문은 사실상 이것입니다.

> 장르, 작가 인지도, 마케팅, 출판사 규모, 수상 여부, 플랫폼 노출, 시대효과 등을 통제한 뒤에도
> **텍스트 자체의 문학적 우수성**이 기대수요를 설명하는가?

이건 원문 기반 feature 없이는 방어하기 어렵습니다.

다만 여기서 중요한 점은, 연구를 설계할 때 **“원문 전체를 읽어야 한다”**와 **“원문 전체를 공개하거나 공유해야 한다”**는 전혀 다르다는 것입니다.

# 1. 원문 전체가 필요한 이유

선생님이 보고 싶은 것은 **텍스트 내재적 문학성**입니다.
이건 외부 데이터로 대체하기 어렵습니다.

| 알고 싶은 것    | 원문 필요성 |
| ---------- | -----: |
| 문체적 복잡성    |     높음 |
| 서사 구조      |     높음 |
| 인물 구성      |     높음 |
| 정서 곡선      |     높음 |
| 주제 복합성     |     높음 |
| 실존주의적 문제의식 |     높음 |
| 세계관 밀도     |     높음 |
| 장르 관습의 변형  |     높음 |

반대로 리뷰·평점·수상·서평은 이미 외부 수용이 섞인 데이터입니다.

그걸 쓰면 이런 문제가 생깁니다.

> “문학성이 수요를 설명한다”가 아니라
> “기존 평판과 독자 반응이 수요를 설명한다”가 됩니다.

그래서 선생님 질문에는 원문 전체가 필요합니다.

---

# 2. 그러나 원문 전체 연구에는 두 가지 방식이 있습니다

## 방식 A: 공개 원문만 사용

가장 안전합니다.

대상은 다음처럼 제한됩니다.

* 저작권 만료 SF
* 공개 라이선스 소설
* Project Gutenberg 등 공개 텍스트
* 직접 공개한 웹소설·오픈 액세스 문학
* 저자가 연구 이용을 허락한 텍스트

이 방식의 장점은 연구 윤리와 재현성이 좋다는 것입니다.
단점은 현대 문화산업 수요와 거리가 생긴다는 것입니다.

---

## 방식 B: 저작권 보호 텍스트를 합법적으로 접근해 feature만 추출

선생님 질문에 더 잘 맞는 방식은 이것입니다.

즉:

> 연구자가 합법적으로 원문에 접근한다.
> 원문 전체를 저장·공유·공개하지 않는다.
> 원문에서 추출한 비가역적 feature만 분석한다.

예를 들어 논문에 공개하는 것은 이런 표입니다.

| 작품ID | 평균문장길이 | 어휘다양도 | 감정변동성 | 사건동사비율 | 실존주의어휘비율 | 수요 |
| ---- | -----: | ----: | ----: | -----: | -------: | -: |
| A    |   18.4 |  0.72 |  0.31 |  0.083 |    0.021 |  1 |
| B    |   13.2 |  0.61 |  0.44 |  0.127 |    0.008 |  0 |

원문 문장은 공개하지 않습니다.

이건 연구 설계상 훨씬 방어 가능합니다.
다만 **원문 접근 경로가 합법적이어야 합니다.**

---

# 3. 핵심은 “원문 접근권”입니다

피해야 할 방식은 명확합니다.

| 방식                         | 판단                       |
| -------------------------- | ------------------------ |
| 불법 PDF/EPUB 다운로드           | 부적절                      |
| DRM 우회                     | 부적절                      |
| 유료 전자책 대량 크롤링              | 위험                       |
| 웹소설 본문 무단 수집               | 위험                       |
| 도서관 전자책 화면 OCR             | 매우 위험                    |
| 구매한 전자책을 개인 연구용으로 제한 분석    | 가능성은 있으나 약관·DRM 문제 확인 필요 |
| 출판사·작가·플랫폼 허락 후 분석         | 가장 안전                    |
| 공개 라이선스 텍스트 분석             | 안전                       |
| 연구기관 라이선스 DB에서 feature만 추출 | 비교적 안전                   |

즉, 문제는 “ML 분석을 해도 되는가”보다 **그 텍스트를 어떤 권한으로 확보했는가**입니다.

---

# 4. 연구 범위를 줄이면 가능성이 올라갑니다

처음부터 현대 SF 500권을 원문 분석하려 하면 거의 막힙니다.
현실적으로는 **작은 표본 + 강한 통제**로 시작해야 합니다.

## 추천 설계

> 현대 한국 SF 또는 번역 SF 30~80권을 대상으로,
> 합법적으로 접근 가능한 원문에서 텍스트 feature를 추출하고,
> 외부효과를 통제한 뒤 수요 proxy를 설명하는지 검증한다.

학부 고학년·석사 초입이면 30~80권도 충분히 의미 있습니다.

# 5. 종속변수 y는 “기대수요”로 잡는 게 맞습니다

선생님이 말한 “기대수요”는 중요합니다.
실제 판매량은 마케팅, 유통, 운, 플랫폼 노출의 영향을 너무 많이 받습니다.

그래서 y를 다음 중 하나로 잡을 수 있습니다.

| y       | 의미             | 장점          | 단점               |
| ------- | -------------- | ----------- | ---------------- |
| 도서관 대출량 | 실제 이용 수요       | 비교적 공공성 있음  | 장르 팬덤 반영 약할 수 있음 |
| 리뷰 수    | 관심도            | 구하기 쉬움      | 팬덤·마케팅 영향        |
| 평점 수    | 읽은 사람 규모 proxy | 직관적         | 플랫폼 편향           |
| 판매 순위   | 시장 수요          | 산업성과에 가까움   | 데이터 접근 어려움       |
| 각색 여부   | IP 수요          | 문화산업과 직접 연결 | 표본 수 부족          |
| 검색량     | 관심도            | 시계열 가능      | 작품명 중복 문제        |

초기 연구에서는 **도서관 대출량 + 리뷰 수** 조합이 가장 현실적입니다.

---

# 6. 통제변수는 반드시 따로 둬야 합니다

선생님 질문은 “외부효과를 다 통제하고도”입니다.
그러면 외부효과를 최대한 모델에 넣어야 합니다.

| 통제 범주 | 변수 예시                      |
| ----- | -------------------------- |
| 작가 효과 | 작가 기존 작품 수, 이전 수상, 이전 리뷰 수 |
| 출판 효과 | 출판사 규모, 출간연도, 초판 여부        |
| 장르 효과 | SF 하위장르, 장르 더미             |
| 제도 효과 | 문학상 수상/후보, 추천도서 선정         |
| 노출 효과 | 플랫폼 리뷰 수 초기값, 언론 기사 수      |
| 번역 효과 | 원작 언어, 번역 여부, 번역자 인지도      |
| 판본 효과 | 전자책 여부, 종이책 여부, 개정판 여부     |

중요한 점은 **문학적 feature와 외부 feature를 섞지 않는 것**입니다.

---

# 7. 모델 구조는 단순하게 시작하십시오

처음부터 복잡한 딥러닝보다, 이런 방식이 좋습니다.

## 1단계: 외부효과만 넣은 모델

```text
수요 = 작가효과 + 출판사효과 + 장르 + 출간연도 + 수상여부 + 마케팅 proxy
```

이 모델이 baseline입니다.

## 2단계: 텍스트 feature 추가

```text
수요 = 외부효과 + 문체 feature + 서사 feature + 정서 feature + 주제 feature
```

그리고 비교합니다.

| 비교   | 질문                             |
| ---- | ------------------------------ |
| 모델 1 | 외부효과만으로 수요를 얼마나 설명하는가          |
| 모델 2 | 텍스트 feature를 추가했을 때 설명력이 증가하는가 |
| 차이   | 문학적 우수성의 독립 기여가 있는가            |

이때 핵심은 **incremental validity**입니다.

> 외부효과를 통제한 뒤에도 텍스트 feature가 설명력을 추가하는가?

이게 선생님 질문의 통계적 형태입니다.

---

# 8. “문학적 우수성”은 처음부터 하나의 점수로 만들지 않는 게 낫습니다

이 부분은 단호하게 말씀드리겠습니다.

초기 연구에서 “문학적 우수성 인덱스” 하나를 먼저 만들면 방어가 어렵습니다.

왜냐하면 심사자가 바로 물을 겁니다.

> 왜 평균문장길이가 문학성인가?
> 왜 어휘다양도가 높으면 우수한가?
> 왜 감정변동성이 문학적 우수성인가?
> 왜 장르 관습 충족이 문학성인가?

그래서 처음에는 이렇게 해야 합니다.

## 나쁜 방식

```text
문학인덱스 = 문체점수 + 서사점수 + 정서점수 + 주제점수
```

그리고 수요를 예측.

## 좋은 방식

```text
외부효과 통제 모델
→ 텍스트 feature 추가
→ 어떤 텍스트 feature군이 추가 설명력을 갖는지 확인
→ 이후 해석 단계에서 “문학적 우수성의 일부 차원”으로 논의
```

즉, 처음 논문 제목도 너무 크게 잡지 않는 게 좋습니다.

---

# 9. 연구 질문을 더 정확히 바꾸면

원래 질문:

> 외부효과를 전부 다 통제하고도 남은 문학적 우수성만으로 기대수요를 설명할 수 있나?

연구용으로는 이렇게 바꾸는 게 좋습니다.

> 작가 인지도, 출판사, 장르, 출간연도, 수상 여부 등 외부 요인을 통제한 뒤에도, SF 소설의 텍스트 내재 feature는 수요 proxy를 추가적으로 설명하는가?

더 정교하게는:

> SF 소설에서 문체·서사·정서·주제 feature는 외부 노출 및 제도적 평판 변수를 통제한 후에도 리뷰 수, 대출량, 각색 여부 등 수요 지표의 변동을 유의미하게 설명하는가?

이렇게 쓰면 훨씬 방어 가능합니다.

# 10. 원문 확보 전략

현실적인 순서는 이렇습니다.

## 1단계: 공개 원문으로 파이프라인 구축

먼저 Project Gutenberg 등으로 코드를 완성하십시오.

* 형태소 분석
* 어휘 다양도
* 감정 분석
* 고유명사 추출
* 인물명 후보 추출
* 주제어 사전 매칭

이 단계에서는 저작권 걱정을 줄이고 기술을 만듭니다.

## 2단계: 지도교수 또는 연구실을 통해 원문 접근권 확보

이건 혼자 하기 어렵습니다.

가능한 경로는 다음입니다.

| 경로            | 설명                 |
| ------------- | ------------------ |
| 출판사 협약        | 특정 출판사 SF 목록 제공 요청 |
| 작가 허락         | 신진 작가·독립출판 작가 대상   |
| 공모전/문예지 협력    | 투고작 또는 공개작 분석      |
| 전자책 플랫폼 연구 협력 | 난도 높지만 가장 강력       |
| 학교 도서관 DB     | 라이선스 범위 확인 필요      |
| 공개 웹소설        | 약관 확인 필요           |

학부생 혼자 하기보다는 **지도교수의 이름과 연구계획서**가 있어야 훨씬 유리합니다.

## 3단계: feature만 저장

원문은 분석 후 폐기하거나, 접근 제한 저장소에 둡니다.

최종 공개 데이터는 feature table만 둡니다.

```text
원문 공개 X
원문 일부 대량 인용 X
feature table 공개 O
코드 공개 O
작품 목록 공개 O
```

이 방식이 가장 깔끔합니다.

# 12. 예상되는 결과와 해석

가능한 결과는 세 가지입니다.

## 결과 A: 텍스트 feature가 추가 설명력을 가짐

해석:

> 외부효과를 통제한 뒤에도 일부 텍스트 내재 feature가 수요 proxy와 관련된다.

이 경우 선생님 가설에 부분 지지입니다.

## 결과 B: 외부효과가 대부분 설명하고 텍스트 feature는 약함

해석:

> 문화산업 수요는 텍스트 내재성보다 노출, 작가 인지도, 장르, 제도적 평판에 더 크게 좌우될 수 있다.

이것도 좋은 결과입니다.
오히려 현실적으로 그럴 가능성이 높습니다.

## 결과 C: 특정 feature만 유의미함

예:

* 문체 복잡성은 음의 관계
* 감정변동성은 양의 관계
* 세계관 밀도는 장르에 따라 다름
* 실존주의어 비율은 리뷰 수에는 양의 관계, 대출량에는 무관

이게 가장 흥미롭습니다.

# 13. 중요한 방법론적 주의

“외부효과를 전부 다 통제”는 현실적으로 불가능합니다.
논문에서는 이렇게 말하면 안 됩니다.

> 외부효과를 전부 통제했다.

대신 이렇게 말해야 합니다.

> 관찰 가능한 주요 외부 요인을 통제했다.

또는:

> 본 연구에서 확보 가능한 외생적 변수들을 통제한 뒤 텍스트 feature의 추가 설명력을 검증했다.

이 표현이 학술적으로 안전합니다.

# 결론

선생님이 말한 목적이라면 **원문 전체 분석이 필요하다는 판단은 맞습니다.**

하지만 연구 설계는 이렇게 가야 합니다.

1. **원문 전체를 분석하되, 원문을 공개하지 않는다.**
2. **합법적 접근권을 확보한 텍스트만 사용한다.**
3. **문학인덱스부터 만들지 말고, 외부효과 모델에 텍스트 feature를 추가하는 방식으로 검증한다.**
4. **핵심 질문은 “텍스트 feature의 추가 설명력”으로 바꾼다.**
5. **“외부효과 전부 통제”가 아니라 “관찰 가능한 외부요인 통제”라고 쓴다.**

연구의 통계적 구조는 이 한 문장입니다.

> **외부효과만 넣은 모델보다, 원문 기반 텍스트 feature를 추가한 모델이 기대수요를 더 잘 설명하는가?**

이렇게 잡으면 선생님의 문제의식이 연구 설계로 바뀝니다.
