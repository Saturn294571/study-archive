# 일본어 문법 무작정 따라하기 핵심정리 소책자

## 1. 품사 기본 활용

### 01 명사의 보통체형
- 현재 긍정 : `～だ` = ~이다
- 현재 부정 : `～じゃない / ～ではない` = ~가 아니야/아니다
- 과거 긍정 : `～だった` = ~이었다
- 과거 부정 : `～じゃなかった / ～ではなかった` = ~가 아니었다
- 문장 끝 : "~이야"는 명사만으로도 가능. ex) `学生。`

### 02 명사의 정중체형
- 현재 긍정 : `～です` = ~이에요/입니다
- 현재 부정 : `～じゃありません / ～ではありません` = ~가 아니에요/아닙니다
- 과거 긍정 : `～でした` = ~이었어요/이었습니다
- 과거 부정 : `～じゃありませんでした / ～ではありませんでした` = ~가 아니었어요/아니었습니다

### 03 な형용사의 보통체형
- 명사 수식 : `な형용사 + な + 명사`
- 현재 긍정 : `～だ` = ~하다
- 현재 부정 : `～じゃない / ～ではない` = ~하지 않다
- 과거 긍정 : `～だった` = ~했다
- 과거 부정 : `～じゃなかった / ～ではなかった` = ~하지 않았다

### 04 な형용사의 정중체형
- 현재 긍정 : `～です` = ~해요/합니다
- 현재 부정 : `～じゃありません / ～ではありません` = ~하지 않아요/않습니다
- 과거 긍정 : `～でした` = ~했어요/했습니다
- 과거 부정 : `～じゃありませんでした / ～ではありませんでした` = ~하지 않았어요/않았습니다

### 05 쓰임이 어려운 な형용사
- 한국어는 "~을/를 좋아하다/잘하다/싫어하다/못하다"이지만 일본어는 `を`가 아니라 `が`.
- 주요 단어 : `好きな`, `上手な`, `得意な`, `嫌いな`, `下手な`, `苦手な`
- `同じ`는 な형용사지만 명사 수식 시 예외적으로 `同じ + 명사`.

### 06 い형용사의 보통체형
- 명사 수식 : `い형용사 + 명사`
- 현재 긍정 : `～い` = ~하다
- 현재 부정 : `～くない` = ~하지 않다
- 과거 긍정 : `～かった` = ~했다
- 과거 부정 : `～くなかった` = ~하지 않았다
- `いい` 예외 : `いい / よくない / よかった / よくなかった`

### 07 い형용사의 정중체형
- 현재 긍정 : `～いです` = ~해요/합니다
- 현재 부정 : `～くないです / ～くありません` = ~하지 않아요/않습니다
- 과거 긍정 : `～かったです` = ~했어요/했습니다
- 과거 부정 : `～くなかったです / ～くありませんでした` = ~하지 않았어요/않았습니다

## 2. 동사 활용

### 08 1류동사의 보통체형
- 현재 긍정 : `～う단` = ~하다
- 현재 부정 : `あ단 + ない` = ~하지 않다
	- 예외 : `ある → ない`, `～う → ～わない`
- 과거 긍정 : `～く→～いた`, `～ぐ→～いだ`, `～う/つ/る→～った`, `～ぬ/む/ぶ→～んだ`, `～す→～した`
	- 예외 : `行く → 行った`
- 과거 부정 : `あ단 + なかった`
	- 예외 : `ある → なかった`, `～う → ～わなかった`

### 09 1류동사의 정중체형
- 현재 긍정 : `い단 + ます` = ~해요/합니다
- 현재 부정 : `い단 + ません` = ~하지 않아요/않습니다
- 과거 긍정 : `い단 + ました` = ~했어요/했습니다
- 과거 부정 : `い단 + ませんでした` = ~하지 않았어요/않았습니다

---

### 10 2류동사의 보통체형
- 현재 긍정 : `～る` = ~하다
- 현재 부정 : `る삭제 + ない` = ~하지 않다
- 과거 긍정 : `る삭제 + た` = ~했다
- 과거 부정 : `る삭제 + なかった` = ~하지 않았다

### 11 2류동사의 정중체형
- 현재 긍정 : `る삭제 + ます` = ~해요/합니다
- 현재 부정 : `る삭제 + ません` = ~하지 않아요/않습니다
- 과거 긍정 : `る삭제 + ました` = ~했어요/했습니다
- 과거 부정 : `る삭제 + ませんでした` = ~하지 않았어요/않았습니다


### 12 3류동사의 보통체형
- 현재 긍정 : `来る / する` = 오다/하다
- 현재 부정 : `来ない / しない` = 오지 않다/하지 않다
- 과거 긍정 : `来た / した` = 왔다/했다
- 과거 부정 : `来なかった / しなかった` = 오지 않았다/하지 않았다

### 13 3류동사의 정중체형
- 현재 긍정 : `来ます / します` = 와요/합니다
- 현재 부정 : `来ません / しません` = 오지 않아요/하지 않습니다
- 과거 긍정 : `来ました / しました` = 왔어요/했습니다
- 과거 부정 : `来ませんでした / しませんでした` = 오지 않았어요/하지 않았습니다

### 14 ない형
- 1류동사 : `あ단 + ない`
	- 예외 : `ある → ない`
- 2류동사 : `る삭제 + ない`
- 3류동사 : `来ない / しない`

### 15 사역형
- 만드는 법 : 1류 `あ단 + せる`, 2류 `る삭제 + させる`, 3류 `来させる / させる`
- 자동사 문장 : `～は ～を + 사역형`
- 타동사 문장 : `～は ～に ～を + 사역형`
- 사람 이외의 것도 주어나 대상이 될 수 있음.

### 16 수동형
- 만드는 법 : 1류 `あ단 + れる`, 2류 `る삭제 + られる`, 3류 `来られる / される`
- 타동사 문장 : `～は ～に + 수동형`, `～は ～に ～を + 수동형`
- 자동사 문장 : `～は ～に + 수동형`
- 피해, 불쾌함, 억울함, 힘듦의 뉘앙스가 자주 붙음.

### 17 사역수동형
- 1류 : `あ단 + される` / `あ단 + せられる`
	- `せられる`는 주로 사전형 끝이 `す`인 동사에 사용
- 2류 : `る삭제 + させられる`
- 3류 : `来させられる / させられる`
- 문형 : `～は ～に + 사역수동형`
- 하기 싫은데 시켜서 어쩔 수 없이 하게 되는 뉘앙스.

### 18 ます형
- 1류 : `い단 + ます`
- 2류 : `る삭제 + ます`
- 3류 : `来ます / します`

### 19 사전형
- 1류 : `～う단`
- 2류 : `～る`
- 3류 : `来る / する`

### 20 금지형
- 1류/2류/3류 공통 : `사전형 + な`

### 21 명령형
- 1류 : `～え단`
- 2류 : `る삭제 + ろ`
- 3류 : `来い / しろ`


### 22 가능형
- 1류 : `え단 + る`
- 2류 : `る삭제 + られる / れる`
- 3류 : `来られる / できる`
- 조사 : `～が + 가능형`, `～を + 가능형`
- 가능형 사이에 다른 말이 끼면 `を`가 일반적. `する → できる`는 `が`가 일반적.

### 23 ば형
- 1류 : `え단 + ば`
- 2류 : `る삭제 + れば`
- 3류 : `来れば / すれば`

### 24 의지형
- 1류 : `お단 + う`
- 2류 : `る삭제 + よう`
- 3류 : `来よう / しよう`

---

### 25 て형
- 1류 : `～く→～いて`, `～ぐ→～いで`, `～う/つ/る→～って`, `～ぬ/む/ぶ→～んで`, `～す→～して`
	- 예외 : `行く → 行って`
- 2류 : `る삭제 + て`
- 3류 : `来て / して`
- 표현 : `～て～て` = ~하고/~해서 나열, `～て` = ~해서, `～て。` = ~해 줘


## 3. 조사

### 26 꼭 알아 두어야 할 조사
- `は` : ~은/는
- `が` : ~이/가, ~을/를, ~지만, ~ㄴ데요
	- `が`가 목적어처럼 쓰이는 경우 : 좋다/싫다, 잘하다/못하다, 원하다/하고 싶다, 할 수 있다
- `を` : ~을/를, ~에서/~을/를(출발점), 자동사의 이동 범위
- `の` : ~의, ~의 것, ~것, 명사 수식문 주어의 ~이/가
- `も` : ~도, ~도 ~하지 않다, 의문사+も, ~나/~씩이나
- `と` : ~와/과, ~와/과 함께, ~라고

### 27 헷갈리기 쉬운 조사
- `へ` : ~로 [방향]
- `に` : ~에(도달점/존재 장소/시간/빈도), ~에게/한테/에, ~에게서/~로부터
- `で` : ~에서 [장소], ~로 [수단/도구/재료], ~때문에, ~면/~에 [한정]
- `から` : ~부터/~에서, ~로부터, ~를 통해서, ~로 [원료/원인/출처/판단 근거], ~니까
- `ので` : ~므로, ~때문에
- `より` : ~부터/~에서, ~보다
- `まで` : ~까지 [계속]
- `までに` : ~까지 [그 전에]
- `だけ` : ~만/~뿐, ~ㄹ 뿐
- `しか` : ~밖에
- `ばかり` : ~만/~뿐

### 28 문장 끝에 쓰는 조사
- `か` : ~까?, ~ㄴ가/~나, 선택, 의문사+か
- `かい` : ~니? [남자 말투, か보다 부드러움]
- `だい` : ~니? [남자 말투]
- `ね` : ~네/~네요, ~지/~죠, 확인/동의/강조
- `よ` : 알려주는 말투, 불만/비난
- `わ` : 가벼운 결심/주장, 놀람/감탄, 강조

### 29 그 밖의 조사들
- `や` : ~며, ~랑, ~나, ~라든가 [격식]
- `とか` : ~든가 [편한 말투]
- `し` : ~고, ~니/~고 해서
- `でも` : ~라도, ~일지라도, 의문사+でも
- `など` : ~등
- `くらい / ぐらい` : ~정도

## 4. 의문사, 부사, 접속사

### 30 의문사
- 기본 : `いつ` 언제, `どこ` 어디, `誰/どなた` 누구, `どちら/どっち` 어느 쪽, `何` 무엇/몇, `なぜ/どうして/なんで` 왜, `いかが/どう` 어떻게/어때, `どれ` 어느 것
- 수량 : `いくつ` 몇/몇 개/얼마, `どのくらい/どれくらい` 어느 정도/얼마나, `いくら` 얼마
- 명사 앞 : `どの` 어느, `どんな` 어떤

### 31 꼭 알아 두어야 할 부사
- `もう` : 벌써/이미, 곧/이제, 더
- `まだ` : 아직, 여전히
- `あまり` : 별로/그다지, 너무/지나치게
- `よく` : 잘, 자주
- `確か` : 아마, 내 기억으로는
- `絶対(に)` : 절대로, 꼭/틀림없이

### 32 뜻과 쓰임이 비슷한 부사
- `はじめて` : 경험상 처음으로 / `はじめ` : 시간 흐름상 처음, 시작
- `さっき` : 아까, 조금 전 / `この前` : 지난번, 요전
- `どうぞ` : 어서 ~하세요 / `どうも` : 감사합니다
- `今度` : 다음에 / `後で` : 이따가
- `必ず` : 반드시 [100%] / `きっと` : 꼭 [아닐 수도 있음] / `ぜひ` : 꼭 [희망, 의지, 권유]
- `すごく` : 무지, 엄청 [구어] / `とても` : 아주, 무척 / `非常に` : 매우 [문어]

### 33 접속사
- `そして` 그리고, `そうして` 그리고/그리하여, `それから` 그러고 나서/그 이후/그리고
- `それで` 그래서, `それに` 게다가
- `けれど/けれども/でも` 하지만/그렇지만
- `しかし` 그러나, `また` 또, `または` 또는/혹은
- `では` 그럼/그러면, `だから` 그러니까/그래서, `すると` 그러자/그렇다면

## 5. 수식, 파생, 접두사/접미사

### 34 명사를 수식하는 방법
- 기본 : `보통체형 + 명사`
- 예외 : 명사 현재형 `명사 + の + 명사`, な형용사 현재형 `な형용사 + な + 명사`
- 명사 수식문 주어는 `が` 대신 `の` 가능. ex) `雨が降った日 / 雨の降った日`

### 35 명사·형용사의 て형
- 명사 : `명사 + で`
- な형용사 : `な삭제 + で`
- い형용사 : `い → く + て`
- 부정형 : 명사/な형용사 `じゃなくて / ではなくて`, い형용사 `くなくて`

### 36 형용사를 부사로 만드는 방법
- な형용사 : `～な → ～に`
- い형용사 : `～い → ～く`
- 예외 : `いい → よく`

### 37 형용사를 동사로 만드는 방법
- な형용사 : `～な → ～がる`
- い형용사 : `～い → ～がる`

### 38 형용사·동사를 명사로 만드는 방법
- な형용사 : `～な → ～さ`
- い형용사 : `～い → ～さ`
- 예외 : `いい → よさ`
- 동사 : `ます형 → ます 삭제`

### 39 접두사와 접미사
- 접두사 : `お/ご[御]～` = 높임, 공손함, 미화
- 접미사 : `～中(ちゅう)` ~(하는) 중/기간 중, `～中(じゅう)` ~전체/온 ~
- 사람/복수 : `～たち`, `～方`, `～ら`
- 시간/순서 : `～頃` ~경/쯤, `～おきに` ~걸러/~마다, `～目` ~째, `～ずつ` ~씩
- 기타 : `～屋` 가게/주인/성격, `～様/さん/ちゃん/君`, `～家` ~가

## 6. 기본 문형

### 40 존재 표현
- 기본 : `～に ～が ある/いる` = ~에 ~가 있다
- 위치 중심 : `～は ～に ある/いる` = ~는 ~에 있다
- 수량 : `～が + 수량 + ある/いる` = ~가 ~(수량) 있다
- 위치 : `～の + 위치 + に + ある/いる` = ~의 ~(위치)에 있다

### 41 주다와 받다
- `もらう` : `～は ～に/から ～をもらう` = ~는 ~에게/로부터 ~를 받다
- `あげる` : 나에게 가까운 쪽에서 먼 쪽으로 줌
- `くれる` : 먼 쪽에서 나/나에게 가까운 쪽으로 줌
- 높임 : `差し上げる` 드리다, `くださる` 주시다, `いただく` 받다
- 낮춤/친근 : `やる` = 아랫사람/동물/식물 등에게 주다

### 42 자동사와 타동사
- 사전형이 `～れる`로 끝나면 대체로 자동사.
- 사전형이 `あ단 + る`로 끝나면 대체로 자동사, 짝 타동사는 `え단 + る`.
- 사전형이 `～す`로 끝나면 대체로 타동사.

### 43 명사만 연결되는 표현
- `명사 + が欲しい` = ~를 갖고 싶다
- `명사 + らしい` = ~답다
- `명사 + がする` = 소리/냄새/맛 등이 나다

### 44 문장을 명사화하는 표현
- `보통체형 + の` = ~(하는) 것
	- 명사/な형 현재형 : `명사 + な + の`, `な형 + な + の`
- `보통체형 + こと` = ~(하는) 것
	- 명사/な형 현재형 : `명사 + である + こと`, `な형 + な + こと`
- `보통체형 + ということ` = ~하다는 것



## 7. 동사 형태별 연결 표현

### 45 ない형에 연결
- `～ないで` = ~하지 않고
- `～なくて` = ~하지 않아서, ~하지 않고
- `～ずに` = ~하지 않고
	- 예외 : `する → せずに`
- 의무 : `～なければならない/いけない/だめだ`, `～なくてはならない/いけない/だめだ`, `～ないといけない/だめだ` = ~해야 한다

---

### 46 ます형에 연결
- `～ませんか` = ~하지 않을래요?
- `～ましょう` = ~합시다
- `～ましょうか` = ~할까요?, ~해 드릴까요?
- `～たい / ～たがる` = ~하고 싶다 / ~하고 싶어하다
- `～に` = ~하러, `～方` = ~(하는) 방법, `～なさい` = ~해라
- `～始める / ～出す` = ~하기 시작하다
- `～終わる` = 다 ~하다, `～続ける` = 계속 ~하다
- `～やすい / ～にくい` = ~하기 쉽다 / 어렵다
- `～ながら` = ~하면서
- `～すぎる` = 너무/지나치게 ~하다
- `～そうだ` = ~할 것 같다, ~해 보인다

### 47 사전형에 연결

### 48 의지형에 연결

## 8. 비교, 긍정·부정, 부탁, 가정, 높임말

### 52 비교 표현
- `～は ～より ～` = ~는 ~보다 ~
- `～より ～の方が ～` = ~보다 ~가 더 ~
- `～と ～と、どちら(の方)が ～ / ～の方が ～` = ~와 ~중 어느 쪽이 ~? / ~가 더 ~
- `～ほど ～ない` = ~만큼 ~하지 않다
- `～の中で ～が一番 ～？ / ～が一番 ～` = ~중에서 ~가 제일 ~? / ~가 제일 ~

### 53 긍정·부정이 짝이 되는 표현
- `～つもりだ / ～ないつもりだ` = ~할 생각이다 / ~하지 않을 생각이다
- `～た方がいい / ～ない方がいい` = ~하는 편이 좋다 / ~하지 않는 편이 좋다
- `～てもいい / ～なくてもいい / ～てはいけない` = ~해도 된다 / ~하지 않아도 된다 / ~하면 안 된다
- `～ても構わない / ～なくても構わない` = ~해도 상관없다 / ~하지 않아도 상관없다
- `～ことがある / ～ないことがある / ～たことがある` = ~하는 경우가 있다 / ~하지 않는 경우가 있다 / ~한 적이 있다
- `～よう(に) / ～ないよう(に)` = ~하도록 / ~하지 않도록
- `～ように言う / ～ないように言う` = ~하도록 말하다 / ~하지 않도록 말하다
- 변화 : `～にする`, `～くする`, `～ようにする`, `～ないようにする`
- 변화 : `～になる`, `～くなる`, `～ようになる`, `～ないようになる`, `～なくなる`
- 결정 : `～にする`, `～ことにする`, `～ないことにする`
- 결과 : `～になる`, `～ことになる`, `～ないことになる`

### 54 부탁할 때 쓰는 표현
- `～をください` = ~를 주세요
- `～てください / ～ないでください` = ~해 주세요 / ~하지 말아 주세요
- `～てくださいますか / ～てくださいませんか` = ~해 주시겠어요? / ~해 주시지 않겠어요?
- `～てもらえますか / ～てもらえませんか` = ~해 줄 수 있어요? / ~해 줄 수 없어요?
- `～ていただけますか / ～ていただけませんか` = ~해 주실 수 있습니까? / ~해 주실 수 없습니까?
- `～(さ)せてください` = ~하게 해 주세요

### 55 가정 표현
- `～ば` = ~하면. 항상/변함없이, 가정, "~면"에 초점. 의지는 원칙적으로 나타나지 않음.
- `～と` = ~하면. 항상/변함없이. 의지는 나타나지 않음.
- `～たら` = ~하면. 가정, 또는 "~한 후에"의 정해진 미래.
- `～なら` = ~라면/~한다면. 가정, B가 A보다 먼저 일어나는 경우. 의지 표현 가능.

### 56 높임말 표현
- 존경어 : `お/ご～になる`, `～(ら)れる`, 존경동사, `お/ご～ください`, `お/ご + 명사/형용사`
- 겸양어1 : `お/ご～する`, 겸양동사 1, `お/ご + 명사/형용사`
- 겸양어2 : 겸양동사 2
- 겸양어1+겸양어2 : `お/ご～いたす`
- 정중어 : `～です / ～ます`, `명사/な형 + でございます`
- 미화어 : `お/ご + 명사`

### 백지복원
- 명사/な형용사 보통체 현재 긍정은 `～だ`, 정중체는 `～です`; い형용사는 `～い / ～いです`.
- 1류동사 핵심 : 부정 `あ단+ない`, 정중 `い단+ます`, 가능 `え단+る`, 명령 `え단`, 의지 `お단+う`.
- 2류동사 핵심 : `る삭제 + ない/ます/た/て/られる/よう`.
- 3류동사 핵심 : `来る/する`, `来ない/しない`, `来た/した`, `来て/して`.
- 조사 암기 축 : `が`는 주어뿐 아니라 좋아함/원함/가능의 목적어에도 쓰임; `に`는 도달점·존재·시간, `で`는 장소·수단.
- 연결 표현은 앞 형태로 묶기 : `ない형`, `ます형`, `사전형`, `의지형`, `て형`, `た형`, `보통체형`.
- 가정 표현 구분 : `ば/と`는 일반 조건, `たら`는 가정·완료 후, `なら`는 화제 제시·선행 조건.
- 높임말은 존경어(상대 높임), 겸양어(나를 낮춤), 정중어(`です/ます`), 미화어(`お/ご`)로 분리.
