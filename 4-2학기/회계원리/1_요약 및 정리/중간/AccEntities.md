회계원리 강의에서 **현재까지 실제로 나온 계정과목들만** 한눈에 보이게 정리하면 아래처럼 볼 수 있습니다.  
시험용으로는 **영문 계정명 기준으로 익히고, 한국어 뜻만 짧게 붙여서** 보는 게 가장 좋습니다.

**Assets**
- `Cash` : 현금
- `Accounts Receivable` / `Account Receivable` : 외상매출금, 받을 돈
- `Supplies` : 소모품
- `Prepaid Rent` : 선급임차료
- `Prepaid Insurance` : 선급보험료
- `Inventory` : 재고자산
- `Equipment` : 비품/장비
- `Building` : 건물
- `Land` : 토지

**Contra Asset**
- `Accumulated Depreciation` : 감가상각누계액

**Liabilities**
- `Notes Payable` / `Note Payable` : 지급어음, 차입금
- `Accounts Payable` / `Account Payable` : 외상매입금, 갚을 돈
- `Interest Payable` : 미지급이자
- `Salary and Wages Payable` : 미지급급여
- `Unearned Service Revenue` : 선수수익
- `Unearned Revenue` : 선수수익 일반형

**Equity**
- `Share Capital` : 주식자본
- `Contributed Capital` : 납입자본
- `Retained Earnings` / `Retained Earning` : 이익잉여금
- `Dividends` / `Dividend` : 배당금

**Revenues**
- `Revenue` : 수익 일반형
- `Service Revenue` : 용역수익
- `Sales` : 매출액

**Expenses**
- `Rent Expense` : 임차료
- `Supplies Expense` : 소모품비
- `Insurance Expense` : 보험료
- `Depreciation Expense` : 감가상각비
- `Interest Expense` : 이자비용
- `Salary and Wages Expense` : 급여
- `Utilities Expense` : 수도광열비
- `Cost of Goods Sold` : 매출원가
- `Selling, General and Administrative Expense (SG&A)` : 판매비와관리비
- `Research and Development Expense` : 연구개발비
- `Taxes` / `Tax Expense` : 법인세비용

**Closing/Temporary 관련**
- `Income Summary` : 손익집계계정
- `Revenue accounts` : 수익계정들
- `Expense accounts` : 비용계정들
- `Dividend account` : 배당금계정

**시험용으로 특히 자주 보일 핵심 계정**
- `Cash`
- `Accounts Receivable`
- `Supplies`
- `Prepaid Insurance`
- `Equipment`
- `Accumulated Depreciation`
- `Accounts Payable`
- `Notes Payable`
- `Unearned Service Revenue`
- `Service Revenue`
- `Salary and Wages Payable`
- `Share Capital`
- `Retained Earnings`
- `Dividends`
- `Rent Expense`
- `Supplies Expense`
- `Insurance Expense`
- `Depreciation Expense`

헷갈리지 않게 외우는 기준도 같이 적으면 좋습니다.

- `Asset` 계정: `Cash, A/R, Supplies, Prepaid~, Equipment`
- `Liability` 계정: `~Payable, Unearned~`
- `Equity` 계정: `Share Capital, Retained Earnings, Dividends`
- `Revenue` 계정: `Service Revenue, Sales`
- `Expense` 계정: `~Expense, Cost of Goods Sold`
