## 1. 객관식

### 1번
다음 중 비디오의 MPEG 압축 방식에 대한 설명으로 가장 적절한 것은?

1. I-frame은 이전/이후 프레임을 모두 참조하므로 압축 효율이 가장 높다.
2. P-frame은 해당 프레임 이미지 자체만으로 출력이 가능하다.
3. B-frame은 이전 및 이후 프레임 정보를 참조하며 압축 효율이 가장 좋지만 가장 늦게 디코딩 가능하다.
4. 모든 프레임은 동일한 압축 정도를 사용하므로 품질 차이가 없다.

### 2번
다음 중 GOP(Group of Pictures)에 대한 설명으로 가장 적절한 것은?

1. GOP는 P-frame만으로 구성되어야 한다.
2. GOP에는 반드시 1장 이상의 I-frame이 포함되어야 한다.
3. GOP는 일반적으로 100~150 프레임 단위로 구성된다.
4. GOP는 오디오 데이터에서만 사용하는 개념이다.

### 3번
다음 중 Unicode에 대한 설명으로 가장 적절한 것은?

1. ANSI가 제정한 7-bit 문자열 코드이다.
2. ASCII와 별개이며 ASCII 문자는 Unicode에 포함되지 않는다.
3. 현대 컴퓨터의 표준 문자열 표현 형식이며, UTF-8/UTF-16 같은 매핑 방식이 있다.
4. 오직 영어와 숫자만 표현하기 위한 코드 체계이다.

### 4번
다음 중 raster graphic(bitmap graphic)과 vector graphic의 비교로 가장 적절한 것은?

1. bitmap은 수학적 도형 기반이고, vector는 픽셀 행렬 기반이다.
2. bitmap은 픽셀 밝기 기반 표현이고, vector는 도형/수식 기반 표현이다.
3. 둘 다 압축과 전혀 관련이 없다.
4. vector graphic은 비디오에서만 사용된다.

### 5번
다음 중 32-bit OS와 address space에 대한 설명으로 가장 적절한 것은?

1. 32-bit OS는 주소를 16-bit 변수로 표현한다.
2. word가 1 byte일 때 최대 address space는 2GB이다.
3. word가 1 byte일 때 32-bit 주소 체계의 최대 address space는 4GB이다.
4. 64-bit OS는 4GB 이상의 메모리를 사용할 수 없다.

### 6번
다음 중 bootstrap process에 대한 설명으로 가장 적절한 것은?

1. 운영체제를 ROM에 전부 저장한 뒤 그대로 실행하는 과정만을 의미한다.
2. 일반적으로 작은 bootstrap program이 먼저 로드된 뒤, 이것이 운영체제를 메모리로 로드한다.
3. 사용자가 직접 운영체제를 기계어로 번역하는 과정이다.
4. 인터프리터가 소스 코드를 줄 단위로 실행하는 과정이다.

### 7번
다음 중 TCP/IP와 OSI model의 관계에 대한 설명으로 가장 적절한 것은?

1. TCP/IP는 일반적으로 2계층으로만 표현된다.
2. OSI model은 application protocol의 포트 번호만 다룬다.
3. TCP/IP는 일반적으로 4계층 혹은 5계층으로 표현되며, 5계층은 network access layer를 더 세분화한 것이다.
4. TCP/IP와 OSI model은 완전히 동일한 이름의 계층만 갖는다.

### 8번
다음 중 URL의 구성 요소를 모두 올바르게 포함한 것은?

1. protocol, host, port, path
2. MAC, IP, port, packet
3. host, router, path, switch
4. protocol, ALU, register, path
