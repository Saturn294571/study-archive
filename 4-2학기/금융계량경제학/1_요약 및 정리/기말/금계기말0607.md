# 금융계량 중간대비(lect. 6-8) 
## 6.MLE
### Maximum Likelihood Estimation
- Model : $y_i=\mu+e_i$
    - OLS Sample EQ : $y_i=\hat{\mu}+\hat{e}_i$
    - obj func of OLS(SSE) : $\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}\hat{e}_i^{2}=\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}(y_i-\hat{\mu})^{2}$
    - OLS estimator $\mu$ : $\hat{\mu}=\frac{1}{N}\sum_{i=1}^N y_i$
        - $\sigma^2$ : $\hat{\sigma}^2=\frac{1}{N-1}\sum_{i=1}^N (y_i-\hat{\mu})^2(=\hat{e}_i^2)$
- Likelihood value 정의 : 특정 모수하에서, 모집단으로부터 생성된 샘플 데이터가 나올 가능도
    - $f(y;\theta)=(2\pi\sigma^2)^{-1/2}\exp\{-\frac{1}{2\sigma^2}(y-\mu)^2\}$$\theta=\{\mu,\sigma^2\}$
        - 샘플링 이전엔 y를 모름. 확변. $\mu,\sigma^2$주어졌다면, y에 대한 확률 추정 가능
    - PDF : 확률 추정은 PDF를 통해 가능
        - 1) $Pr(y>\mu)=\int_{\mu}^{\infty}f(y;\theta)dy=0.5$ 2) $Pr(10>y>4)=\int_{4}^{10}f(y;\theta)dy$
            - (joint)JPDF of $\{y_1,\cdots,y_N\}$$=f(y_1,\cdots, y_N;\theta)\quad \theta=\{\mu,\sigma^2\}$
            - Marginal PDF of $y_i=f(y_i;\theta)$
        - r.v. A,B가 독립 $\to f(A \cap B)=f(A)f(B)$ : $f(Y;\theta)=\prod_{i=1}^N f(y_i;\theta)\quad Y=(y_1\cdots y_N)^T$
            - if $y_i\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$, then $f(Y;\theta)=(2\pi\sigma^2)^{-N/2}\exp\{-\frac{1}{2\sigma^2}\sum_i(y_i-\mu)^2\}$
- Likelihood function : $L(\mu,\sigma^2|y_1,\cdots,y_N)=f(y_1,\cdots,y_N;\mu,\sigma^2)$
    - MLE의 목적함수는 $\underset{\mu,\sigma^2}{\text{argmax}}\ln L(\mu,\sigma^2|Y)$
        - $\ln()$ : 단조증가? -> 합성해도 해가 달라지지 X.
    - FOC of MLE : $\frac{\partial\ln L(\theta|Y)}{\partial\theta}=0$ : MLE는 FOC를 통해 모수들을 추정
- MLE example : $y_i=X_i'\beta+e_i$
    1) $y_i$ 분포 : $y_i\sim N(X_i'\beta,\sigma^2)$
    2) $f(y_i)$? ($y_i$의 pdf?) : $f(y_i;\beta,\sigma^2)=1/\sqrt{2\pi\sigma^2}\exp\{-\frac{(y_i-X_i'\beta)^2}{2\sigma^2}\}$
    3) Y의 JPDF? : $f(Y;\beta,\sigma^2)=\prod_{i=1}^N f(y_i;\beta,\sigma^2)$$=(2\pi\sigma^2)^{-\frac{n}{2}}\exp\{-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{2\sigma^2}\}$
    4) $L\to\ln L$ : $\ln L(\beta,\sigma^2|Y)=-\frac{n}{2}\ln 2\pi-\frac{n}{2}\ln\sigma^2-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{2\sigma^2}$
    5) $\frac{\partial\ln L}{\partial \theta}=0$ : $\to\hat{\beta}_{\text{MLE}}=\hat{\beta}_{\text{OLS}}\quad \text{but},\hat{\sigma^2}_{\text{MLE}}=\frac{1}{n}\sum\hat{e}_i^2$
### MLE generalization
- $\hat{\theta}_{\text{MLE}}=\underset{\theta}{\text{argmax}}\ln L(\theta|Y)$
- 랜덤 샘플링시 LL(log likelihood) : $\ln L(\theta|Y)= \ln(\prod_{i=1}^{n}f(y_i;\theta))=\sum_{i=1}^{n}\ln f(y_i;\theta)$
- FOC of MLE : $\forall \theta_i \in\theta=\{\theta_1,\cdots,\theta_k\},\quad\frac{\partial \ln L(\hat{\theta}_{MLE}|Y)}{\partial \theta_i}=0$
- score vector : $S(\theta|Y)=\frac{\partial \ln L(\theta|Y)}{\partial \theta},\quad S(\hat{\theta}_{MLE}|Y)=0$
- LL func for linear reg model : $\ln L(\theta|y,X)=-\frac{n}{2}\ln(2\pi)-\frac{n}{2}\ln(\sigma^2)$ $-\frac{1}{2\sigma^2}(y-X\beta)'(y-X\beta)\implies\frac{\partial \ln L(\theta|y,X)}{\partial\theta}=0$
    - $\hat{\beta}_{MLE}=(X'X)^{-1}X'y=\hat{\beta}_{OLS}$
    - but, $\hat{\sigma}^2_{MLE}=\frac{1}{n}(y-X\hat{\beta}_{MLE})'(y-X\hat{\beta}_{MLE})$ $\neq\hat{\sigma}^2_{OLS}=\frac{1}{n-k}(y-X\hat{\beta}_{OLS})'(y-X\hat{\beta}_{OLS})$
        - 단, n의 크기가 커질수록 서로간 오차가 미미해짐

### MLE for series data
- IID ts의 LL : $\ln L(\theta|y)=\sum_{t=1}^{T}\ln f(y_t;\theta)$
- 시계열의 경우 오차가 IID X. (독립X)
    - $\therefore$ 교사건 확률을 조건부 확률로 표현 : $p(A\cap B)=p(B|A)p(A)$ $P(A\cap B\cap C) = p(C|A\cap B)p(B|A)p(A)$
    - ts에선, : $f(y_T,\cdots,y_1;\theta)=\{\prod_{t=p+1}^{T}f(y_t|I_{t-1};\theta)\}$ $\cdot f(y_p,\cdots,y_1;\theta)$
        - $I_{t}=\{y_t,\cdots,y_1\}$ : t시점의 가능한 정보
        - $y_p,\cdots,y_1$ : p개의 초기 관측치
        - $\therefore$ LL 에서 : $\ln L(\theta|y)=\sum_{t=p+1}^T \ln f(y_t|I_{t-1};\theta)$ $+\ln f(y_p,\cdots,y_1;\theta)$ $\hat{\theta}_{MLE}= \underset{\theta}{\text{argmax}} \ln L(\theta|y)$
        - hint : 과거 $I_{t-1}$로 설명된 부분 제거 -> 새 innovation만 density로 평가
### MLE for AR(1) model
- sta.한 AR(1) 모델 : $y_t=c+\phi y_{t-1}+\epsilon_t;\quad \epsilon_t\overset{IID}{\sim}N(0,\sigma^2)|\phi|<1$
    - $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$
    - conditional LL : $\ln L_c(\theta|y)$ $=\sum_{t=2}^{T}\left[-\frac12\ln(2\pi)-\frac12\ln\sigma^2-\frac{(y_t-c-\phi y_{t-1})^2}{2\sigma^2}\right]$
    - 초기값 $y_1$ 처리 : conditional MLE는 $f(y_1)$ 생략; exact MLE는 $f(y_1;\theta)$ 포함
    - sta. hint : $|\phi|<1,\quad E(y_t)=\frac{c}{1-\phi},\quad Var(y_t)=\frac{\sigma^2}{1-\phi^2}$

### MLE for ARMA(p,q)
- ARMA(p,q) : $y_t=c+\sum_{i=1}^{p}\phi_i y_{t-i}+\epsilon_t+\sum_{j=1}^{q}\theta_j\epsilon_{t-j}$ $\epsilon_t\sim N(0,\sigma^2)$
    - 핵심 : $y_t|I_{t-1}\sim N(\mu_{t|t-1},\sigma^2)$
    - $\mu_{t|t-1}=c+\sum_i\phi_i y_{t-i}+\sum_j\theta_j\epsilon_{t-j}$
    - LL : $\ln L_c=\sum_{t=m+1}^{T}\ln f(y_t|I_{t-1};\theta)$ $m=\max(p,q)$
    - AR part : 과거 $y$ 직접 관측 O / MA part : 과거 $\epsilon$ 관측 X -> recursion/초기값 필요
    - 함의 : 식은 regression처럼 보여도 $\epsilon_{t-j}$가 모수 의존 -> closed form 보통 X
### Newton-Raphson method & numerical optimazation
- 왜 필요? : 복잡한 ML은 FOC 손풀이/closed form X -> 컴퓨터가 LL surface에서 peak search
- global vs local max
    - global max : 전체 구간 최고점
    - local max : 주어진 초기값/탐색구간 근처 최고점
    - 실증 hint : initial value/grid 바꿔보기; 말 안 되는 parameter range 주의
- Newton-Raphson : 현재점에서 gradient+curvature로 다음점 update
    - $\theta^{(k+1)}=\theta^{(k)}-\left[H(\theta^{(k)})\right]^{-1}S(\theta^{(k)})$
    - $S(\theta)=\partial\ln L/\partial\theta$ : score(기울기)
    - $H(\theta)=\partial^2\ln L/\partial\theta\partial\theta'$ : Hessian(곡률)
    - max에서 $S(\hat\theta)=0$, $H(\hat\theta)$ negative definite
- 정보행렬 : $I(\theta)=-E[H(\theta)]$
    - curvature 큼 -> peak sharp -> estimator var 작음
    - curvature 작음 -> peak flat -> estimator var 큼

### MLE asymptotic properties
- large sample에서 MLE
    1) consistent : $\hat\theta_{MLE}\overset{p}{\to}\theta_0$
    2) asym. normal : $\sqrt{n}(\hat\theta-\theta_0)\overset{d}{\to}N(0,I(\theta_0)^{-1})$
    3) asym. efficient : large sample에서 var. 작음(Cramer-Rao lower bound)
- 강의 직관 : sample↑ -> 추정분포 좁아짐; normal approx 가능; information matrix inverse가 분산
- OLS와 관계
    - classical linear normal model -> $\hat\beta_{MLE}=\hat\beta_{OLS}$
    - $\hat\sigma^2_{MLE}=SSR/n,\quad \hat\sigma^2_{OLS}=SSR/(n-k)$ -> small sample 차이, $n$ 커지면 미미

### 백지복원
- MLE : data $Y$ 고정, parameter $\theta$ 바꿔 $L(\theta|Y)=f(Y;\theta)$ max. 
- PDF/JPDF와 수학형태 같지만 해석 방향 반대. iid면 $\ln L=\sum_i\ln f(y_i;\theta)$; ts dep. 있으면 chain rule로 $\ln L=\sum_t\ln f(y_t|I_{t-1};\theta)+initial$. 
- AR(1)은 $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$라 conditional LL 구성. 
- ARMA는 MA error가 관측 X라 recursion 필요, closed form 대개 X -> Newton-Raphson 등 numerical opt. 사용. 
- max에서 score=0, Hessian/information matrix가 곡률 및 estimator var 정보 제공. 
- large sample MLE : consistent, asym. normal, efficient.

## 7. GARCH

### Idea
- GARCH : $R_t$의 time-varying vola.(volatility) + vola. clustering 설명 -> 조건부 분산 모형화
- 기존 : $y_t=x_t'\beta+\epsilon_t,\quad \epsilon_t\sim(0,\sigma^2)$
- GARCH : $\epsilon_t|I_{t-1}\sim(0,\sigma_t^2)$ -> 분산도 $I_{t-1}$ 따라 update
- 금융 data 특징 : time-varying vola. / vola. clustering / fat tail / asym.(asymmetry, leverage)
- 핵심 : 수익률 평균만 맞 X, 잔차 분산이 어떻게 진화?

### Conditional Moment
- $I_t$ : $t$까지 이용 가능 info. set
	- 이미 알려진 정보 -> shock X, condition
	- shock : 예상 못 한 부분
	- LIE : 큰 info. 안의 rv는 상수취급; nested info. -> smaller set wins
- 조건부 평균/분산 : $\mu_{t+1|t}=E(r_{t+1}|I_t),\quad \sigma_{t+1|t}^2=Var(r_{t+1}|I_t)$
- vola. : $\sigma_{t+1|t}$ = conditional std.
- 표준화 : $z_t=\epsilon_t/\sigma_t,\quad z_t\overset{iid}{\sim}(0,1)\Rightarrow \epsilon_t=\sigma_tz_t$
	- $\epsilon_t$ = shock size($z_t$) $\times$ vola. scale($\sigma_t$)

### Mean Eq.
- 기본 : $y_t=\mu+\epsilon_t$
- with regressor : $y_t=x_{t-1}'\beta+\epsilon_t,\quad \epsilon_t=\sigma_tz_t$
	- $x_{t-1}$ : $x_t$-$\epsilon_t$ 동시상관 회피
- mean side : ARMA/exog 가능; 관심 : residual의 $\sigma_t^2$ law of motion

---

### ARCH
- ARCH : Autoregressive Conditional Heteroskedasticity
	- AR : 과거 shock 사용 / C : $I_{t-1}$ 조건부 / H : 이분산
- ARCH(1) : $\sigma_t^2=\alpha_0+\alpha_1\epsilon_{t-1}^2$
	- 어제 큰 잔차 -> 오늘 큰 조건부 분산
- ARCH(p) : $\sigma_t^2=\alpha_0+\sum_{i=1}^{p}\alpha_i\epsilon_{t-i}^2$
	- 과거 $p$기 shock 크기 -> 현재 vola.
- 조건 : $\alpha_0>0,\quad \alpha_i\ge0,\quad \sum_i\alpha_i<1$
	- 앞 둘 : 분산 음수 X / 마지막 : 발산 X
- Uncond. var. : $E(\sigma_t^2)=\frac{\alpha_0}{1-\sum_i\alpha_i}$
	- 복원 hint : ARCH식 양변 $E(\cdot)$ -> conditional 변해도 장기 평균분산 O

### GARCH
- ARCH 한계 : 긴 vola. persistence 설명하려면 고차항 많이 필요
- GARCH : 과거 shock + 과거 vola. 자체
	- $GARCH(p,q):\quad \sigma_t^2=\omega+\sum_{i=1}^{q}\alpha_i\epsilon_{t-i}^2$ $+\sum_{j=1}^{p}\beta_j\sigma_{t-j}^2$
	- ARCH term : $\epsilon_{t-i}^2$ = new shock
	- GARCH term : $\sigma_{t-j}^2$ = vola. persistence
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- $\alpha$ : 새 shock 영향 / $\beta$ : 과거 vola. 지속 / $\alpha+\beta$ : persistence
- 조건/장기분산 : $\omega>0,\quad \alpha,\beta\ge0,\quad \alpha+\beta<1,\quad E(\sigma_t^2)=\frac{\omega}{1-\alpha-\beta}$
	- $\alpha+\beta\approx1$ -> shock 오래 감
- 실증 기본 : GARCH(1,1)부터; high order 남발 X(noisy + 추정불안정)

### GARCH-in-Mean
- idea : high risk -> high return? vola.가 기대수익률에 직접 영향
- $y_t=x_{t-1}'\beta+\lambda g(\sigma_t^2)+\epsilon_t,\quad g\in\{\sigma_t,\sigma_t^2,\log\sigma_t^2\}$
- $\lambda>0$ : risk↑ return↑ / $\lambda<0$ : risk↑ return↓

### Asymmetric GARCH
- 기본 GARCH : $\epsilon_{t-1}^2$ -> $+5,-5$ 동일 취급
- 현실 : bad news -> good news보다 vola.↑ 가능
- EGARCH : $\log\sigma_t^2=\omega+\beta\log\sigma_{t-1}^2+\alpha(|z_{t-1}|-E|z_{t-1}|)+\gamma z_{t-1}$
	- log var. -> 양수제약 자연 처리
	- $\gamma$ : shock sign 효과; 보통 $\gamma<0$ -> negative shock가 vola.↑
- TGARCH/GJR : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\gamma I(\epsilon_{t-1}<0)\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- positive shock : $\alpha$ / negative shock : $\alpha+\gamma$
	- $\gamma>0$ -> negative shock 추가효과 O

### Exogenous Vola. Factor
- 외생 factor : 금리기대, FX, 거래량, 뉴스빈도, overnight R, implied vola., 지정학 risk
- 예시 : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2+\delta z_{t-1}$
- 주의 : 변수 많이 넣기 X -> data 충분? 경제적 설명? graph상 variation?

### MLE
- vola. 직접 관측 X : $\sigma_t^2$는 residual 기반 latent object -> OLS X, MLE O
- 정규가정 : $\epsilon_t|I_{t-1}\sim N(0,\sigma_t^2)$
- log-likelihood : $\ell(\theta)=\sum_t[-\frac12\log(2\pi)-\frac12\log\sigma_t^2-\frac{\epsilon_t^2}{2\sigma_t^2}]$
- 절차 : mean eq. 설정 -> GARCH recursion으로 $\sigma_t^2$ 생성 -> conditional PDF -> LL maximize
- fat tail 강함 -> Normal 대신 Student-t 등

### Multivariate GARCH
- 1 asset : $\sigma_t^2$ scalar
- $N$ assets : $r_t\in\mathbb{R}^N,\quad \Sigma_t\in\mathbb{R}^{N\times N}$
	- 관심 : 개별 vola. + cov/corr 시간변화
- BEKK / CCC(Constant Conditional Corr.) / DCC(Dynamic Conditional Corr.)
- DCC : $\Sigma_t=D_tR_tD_t$
	- $D_t$ : cond. std. diagonal / $R_t$ : cond. corr.
	- CCC : $R$ fixed / DCC : $R_t$ time-varying

### 백지복원
- GARCH : $R_t$의 time-varying vola. + clustering 설명 -> $\sigma_t^2$ 모형화. 
- mean eq. : $y_t=x_{t-1}'\beta+\epsilon_t,\ \epsilon_t=\sigma_tz_t,\ z_t\sim iid(0,1)$.
- ARCH : $\sigma_t^2=\alpha_0+\sum_i\alpha_i\epsilon_{t-i}^2$ -> 과거 shock 크기 반영.
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$.
- $\alpha$ = new shock, $\beta$ = persistence, $\alpha+\beta<1$, $E(\sigma_t^2)=\omega/(1-\alpha-\beta)$.
- $\sigma_t^2$ 관측 X -> conditional PDF + MLE. sign 효과 필요 -> EGARCH/TGARCH.

## 8. Vector Auto-Regression (VAR)

### Idea
- VAR : 여러 sta.(stationary) ts를 **vector로 묶은 AR**
	- scalar AR : $y_t=c+\phi y_{t-1}+e_t$
	- VAR : $Y_t=A_0+A_1Y_{t-1}+\cdots+A_pY_{t-p}+u_t$
- 왜? : 경제 shock는 한 변수에만 X, 여러 시장/부문에 동시 전파
	- ex) 금리 shock -> $\pi_t$, GDP, 실업률, 환율 등 같이 움직임
	- partial eq. 직관($ceteris paribus$) 약함 -> system으로 같이 추정
- VARMA? 가능하지만 복잡 -> 보통 VAR로 approx.
- 주의 : 변수 “막” 넣기 X -> 경제이론/데이터 variation/추정가능성 필요

### Before VAR
- 전제 : VAR 기본형은 sta. 변수 사용
	- unit root test -> non-sta.면 차분/성장률/추세제거
	- 정보손실 걱정? non-sta. 그대로 쓰는 모형 : VECM, UC 등
- 변수 선택 : 같이 움직일 경제적 이유 O?
- lag order : 너무 크게 X
	- 변수 수↑, lag↑ -> parameter 폭증 -> 추정불안정/비경제적 부호
	- 실증 hint : 데이터 graph + theory + IC(AIC/BIC) + robustness

### VAR(p)
- $Y_t=(y_{1t},\cdots,y_{nt})'$
- reduced-form VAR(p)
	- $Y_t=c+A_1Y_{t-1}+\cdots+A_pY_{t-p}+u_t$ $E(u_t)=0,\quad E(u_tu_t')=\Sigma_u$
- each eq. : 같은 RHS($Y_{t-1},...,Y_{t-p}$) -> eq별 OLS 가능
	- OLS처럼 쉬움; 어려운 건 변수/lag/식별/해석
- 활용
	1. dynamics 파악 : 변수간 lead-lag
	2. forecast : 과거 $Y$로 미래 경로 예측
	3. policy/shock analysis : shock가 각 변수에 퍼지는 경로(IRF)

### Reduced Form vs Structural Form
- foundation : simultaneous eq.(수요/공급처럼 동시결정); 관측은 구조곡선 X, 균형값 O
- reduced form : data로 바로 추정 가능
	- $Y_t=c+\sum_i A_iY_{t-i}+u_t$
	- $u_t$끼리 동시상관 가능 : $\Sigma_u$ non-diagonal
	- reduced coeff. 자체를 causal structural effect로 읽기 X
- structural form : 경제 구조/동시관계 포함
	- $B_0Y_t=b+\sum_i B_iY_{t-i}+\varepsilon_t,\quad E(\varepsilon_t\varepsilon_t')=D$
	- $\varepsilon_t$ : structural shock, 서로 orthogonal하게 해석하고 싶음
- 연결
	- $Y_t=B_0^{-1}b+\sum_i B_0^{-1}B_iY_{t-i}+B_0^{-1}\varepsilon_t$
	- $u_t=B_0^{-1}\varepsilon_t,\quad \Sigma_u=B_0^{-1}D(B_0^{-1})'$
- 핵심 문제 : reduced form은 추정 O, structural shock은 바로 관측 X -> identification 필요

### Normalization / Identification
- 단순 예
	- $\alpha^*y_t=\beta^*X_t+e_t,\quad e_t\sim N(0,\sigma^{*2})$
	- $y_t=\frac{\beta^*}{\alpha^*}X_t+\frac{e_t}{\alpha^*}=\beta X_t+\epsilon_t$ $Var(\epsilon_t)=\sigma^{*2}/\alpha^{*2}$
- 함의 : $(\alpha^*,\beta^*,\sigma^{*2})$ 여러 조합 -> 같은 $(\beta,\sigma^2)$ 가능
	- structural unknown 3개, reduced-form info 2개 -> 식별불가
- 해결 : 모르는 것 하나를 normalize/restrict
	- $\alpha^*=1$ 또는 $\sigma^{*2}=1$
	- VAR에서도 structural parameter 수 > reduced-form moments -> 제약 필요
- 식별 직관 : 관측되는 건 균형값/축약형 shock; 수요/공급/정책 shock는 구조제약 없이는 분리 X

### Recursive / Cholesky Identification
- 목적 : $\Sigma_u=PP'$인 $P$를 찾아 $u_t=P\varepsilon_t,\quad Var(\varepsilon_t)=I$
- Cholesky : $P$ lower triangular -> ordering으로 동시반응 제약 부여
	- 위에 둔 변수 : 같은 시점에 뒤 변수 shock에 즉시 반응 X
	- 아래 변수 : 앞 변수 shock에 즉시 반응 O
- 함의 : variable ordering = 경제적 가정
	- 순서 바꾸면 IRF 달라질 수 있음 -> theory로 justify 필요
- shock scale : 보통 1 s.d. shock; 보고서용으론 1% shock로 normalize 가능

### IRF(Impulse Response Function)
- IRF : structural shock 1회 발생 -> 각 변수의 미래 반응 경로
	- $\varepsilon_{jt}$ 1단위/1 s.d. shock -> $Y_{t+h}$ 변화
- VAR(1) intuition
	- $Y_t=A_1Y_{t-1}+u_t,\quad u_t=P\varepsilon_t$
	- $h$기 반응 : $\partial Y_{t+h}/\partial\varepsilon_t=A_1^hP$
- 해석 hint
	- 금리↑ shock -> 이론상 $\pi$↓, output↓, unemployment↑ 예상
	- 초기 반응 이상하면? ordering/변수/proxy/lag/sample 문제 의심
	- 실업률 등 slow-moving 변수는 즉시반응 작고 후행 가능
- 장기효과
	- sta. VAR이면 shock 효과는 시간이 지나며 0으로 수렴
	- 정책은 주로 cycle에 영향, trend 영구효과 주장은 별도 이론 필요

### Forecast / FEVD
- Forecast : $\hat Y_{T+h}$를 VAR recursion으로 생성
	- in-sample fit 좋음 ≠ forecast 좋음
	- forecast error가 새 info. update의 핵심
- FEVD(forecast error variance decomposition)
	- $h$기 예측오차 분산 중 각 shock가 설명하는 비중
	- “어떤 shock가 변동을 주로 설명?” 질문

### Practical Checklist
- 1. data plot : 충분한 variation O?
- 2. stationarity check : unit root -> 차분/성장률/추세제거 or VECM/UC
- 3. variables : theory로 묶기; proxy 필요시 검토
- 4. lag order : 너무 크게 X, IC/robustness
- 5. reduced-form VAR estimate : eq별 OLS
- 6. identification : Cholesky/order/restriction 명시
- 7. IRF/FEVD : shock 방향/scale/ordering 해석

### 백지복원
- VAR : $Y_t$ vector의 AR. 경제 shock는 여러 변수에 동시 전파 -> scalar eq.보다 system 필요.
- reduced-form : $Y_t=c+\sum_iA_iY_{t-i}+u_t$, sta. 변수 사용, eq별 OLS 가능.
- $u_t$는 reduced-form shock -> structural policy shock 아님.
- structural form : $B_0Y_t=b+\sum_iB_iY_{t-i}+\varepsilon_t,\quad u_t=B_0^{-1}\varepsilon_t$
- $\varepsilon_t$ 복원 필요 -> identification.
- reduced-form moments만으론 structural parameter 부족 -> normalization/restriction.
- Cholesky : ordering으로 동시반응 제약, $u_t=P\varepsilon_t$ 분해.
- IRF : shock 1회가 미래 $Y_{t+h}$에 미치는 경로; VAR(1) -> $A_1^hP$.
- 변수/lag/order 막 넣기 X -> stationarity, theory, data variation 확인.
