# 금융계량 기말대비(lect. 6-8) 
## 6.MLE
### Idea
- MLE : data $Y$는 관측값으로 고정, parameter $\theta$를 바꿔 $L(\theta|Y)=f(Y;\theta)$ max.
- PDF와 likelihood는 수학형태 같지만 해석 방향 다름
	- PDF : $\theta$ given, $Y$가 나올 확률
	- Likelihood : $Y$ given, 어떤 $\theta$가 그 데이터를 잘 설명?
- log 사용 : $\ln(\cdot)$ 단조증가 $\to$ argmax 동일, product를 sum으로 바꿈

### Likelihood Construction
- iid sample : $L(\theta|Y)=\prod_{i=1}^{n}f(y_i;\theta),\quad \ell(\theta|Y)=\sum_{i=1}^{n}\ln f(y_i;\theta)$
- MLE 목적함수 : $\hat\theta_{MLE}=\underset{\theta}{\text{argmax}}\ \ell(\theta|Y)$
- FOC / score : $S(\theta|Y)=\frac{\partial \ell(\theta|Y)}{\partial\theta},\quad S(\hat\theta_{MLE}|Y)=0$
- Hessian : $H(\theta)=\frac{\partial^2\ell(\theta|Y)}{\partial\theta\partial\theta'}$
	- max에서 보통 $H(\hat\theta)$ negative definite

### Normal Linear Model
- $y=X\beta+e,\quad e\sim N(0,\sigma^2I)$
- LL : $\ell(\beta,\sigma^2)=-\frac{n}{2}\ln(2\pi)-\frac{n}{2}\ln\sigma^2-\frac{1}{2\sigma^2}(y-X\beta)'(y-X\beta)$
- 핵심 : normal LL max $\Leftrightarrow$ SSR min
	- $\hat\beta_{MLE}=(X'X)^{-1}X'y=\hat\beta_{OLS}$
	- $\hat\sigma^2_{MLE}=SSR/n,\quad \hat\sigma^2_{OLS}=SSR/(n-k)$
	- $\sigma^2$ 차이 : finite sample df correction, $n$ 커지면 미미

### Time Series MLE
- 핵심 : $y_t$들이 독립 X $\to$ joint density를 conditional density product로 분해
- chain rule : $f(y_T,\cdots,y_1;\theta)=\{\prod_{t=p+1}^{T}f(y_t|I_{t-1};\theta)\}f(y_p,\cdots,y_1;\theta)$
	- $I_t=\{y_t,\cdots,y_1\}$ : t시점 info. set
	- hint : 과거 $I_{t-1}$로 설명된 부분 제거 $\to$ 새 innovation density만 평가
- **주의 : 핵심은 "오차가 iid가 아니다"가 아니라 "관측치 $y_t$들이 독립이 아니다"임. innovation은 iid/conditional iid로 둘 수 있음.**

### AR(1) Example
- $y_t=c+\phi y_{t-1}+\epsilon_t,\quad \epsilon_t\overset{iid}{\sim}N(0,\sigma^2),\quad |\phi|<1$
- $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$
- conditional LL : $\ell_c=\sum_{t=2}^{T}\left[-\frac{1}{2}\ln(2\pi\sigma^2)-\frac{(y_t-c-\phi y_{t-1})^2}{2\sigma^2}\right]$
- conditional MLE : $f(y_1)$ 생략 / exact MLE : $f(y_1;\theta)$ 포함
	- stationary AR(1) : $E(y_t)=\frac{c}{1-\phi},\quad V(y_t)=\frac{\sigma^2}{1-\phi^2}$
	- $\phi\approx1$ : persistence↑, mean/variance 식 민감, unit-root-like behavior 주의

### Numerical Optimization
- 왜? : 복잡한 ML은 FOC 손풀이/closed form X $\to$ LL surface의 peak를 컴퓨터로 search
- Newton-Raphson : gradient+curvature로 다음점 update
	- $\theta^{(k+1)}=\theta^{(k)}-\left[H(\theta^{(k)})\right]^{-1}S(\theta^{(k)})$
- global/local max 주의 : initial value/grid/parameter range 확인
- information matrix : $I(\theta)=-E[H(\theta)]$
	- curvature sharp $\to$ estimator variance 작음
	- curvature flat $\to$ estimator variance 큼

### Large Sample Properties
- consistent : $\hat\theta_{MLE}\overset{p}{\to}\theta_0$
- asymp. normal : $\sqrt{n}(\hat\theta-\theta_0)\overset{d}{\to}N(0,I(\theta_0)^{-1})$
- asymp. efficient : large sample에서 분산 작음(Cramer-Rao lower bound)
- 강의 직관 : sample↑ $\to$ 추정분포 좁아짐; information matrix inverse가 추정분산

### 백지복원
- MLE : $Y$ 고정, $\theta$ 바꿔 likelihood max.
- iid면 $\ell=\sum_i\ln f(y_i;\theta)$; ts면 $\ell=\sum_t\ln f(y_t|I_{t-1};\theta)+initial$.
- score=0이 FOC; Hessian/information matrix는 curvature와 $V(\hat\theta)$ 정보.
- normal linear model : LL max = SSR min $\to$ $\hat\beta_{MLE}=\hat\beta_{OLS}$, 단 $\hat\sigma^2$는 $n$ vs $n-k$.
- AR(1) : $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$라 conditional LL 구성.
- closed form 어려우면 Newton-Raphson; large sample MLE = consistent, asymp. normal, efficient.

## 7. GARCH

### Idea
- GARCH : $R_t$의 time-varying vola.(volatility) + vola. clustering 설명 $\to$ 조건부 분산 모형화
- 기존 : $y_t=x_t'\beta+\epsilon_t,\quad \epsilon_t\sim(0,\sigma^2)$
- GARCH : $\epsilon_t|I_{t-1}\sim(0,\sigma_t^2)$ $\to$ 분산도 $I_{t-1}$ 따라 update
- 금융 data 특징 : time-varying vola. / volatility clustering / fat tail
- 핵심 : 수익률 평균만 맞 X, residual의 조건부 분산 $\sigma_t^2$가 어떻게 진화?

### Conditional Moment / Vola.
- $I_t$ : $t$까지 이용 가능 info. set
- 조건부 평균/분산 : $\mu_{t+1|t}=E(r_{t+1}|I_t),\quad \sigma_{t+1|t}^2=V(r_{t+1}|I_t)$
- vola. : $\sigma_{t+1|t}$ = conditional std.
- 표준화 : $z_t=\frac{\epsilon_t}{\sigma_t},\quad z_t\overset{iid}{\sim}(0,1)\Rightarrow \epsilon_t=\sigma_tz_t$
	- $\epsilon_t$ = shock size($z_t$) $\times$ vola. scale($\sigma_t$)

### Mean Eq. vs Variance Eq.
- 기본 : $y_t=\mu+\epsilon_t$
- with regressor : $y_t=x_{t-1}'\beta+\epsilon_t,\quad \epsilon_t=\sigma_tz_t$
	- $x_{t-1}$ : $x_t$-$\epsilon_t$ 동시상관 회피
- mean side : exog/lagged terms 가능; 관심 : residual의 $\sigma_t^2$ law of motion


### ARCH -> GARCH
- ARCH : Autoregressive Conditional Heteroskedasticity
	- AR : 과거 shock 사용 / C : $I_{t-1}$ 조건부 / H : 이분산
- ARCH(1) : $\sigma_t^2=\alpha_0+\alpha_1\epsilon_{t-1}^2$
	- 어제 큰 잔차 $\to$ 오늘 큰 조건부 분산
- ARCH(p) : $\sigma_t^2=\alpha_0+\sum_{i=1}^{p}\alpha_i\epsilon_{t-i}^2$
	- 과거 $p$기 shock 크기 $\to$ 현재 vola.
- ARCH 한계 : 긴 vola. persistence 설명하려면 고차항 많이 필요
- GARCH : 과거 shock + 과거 vola. 자체
	- $GARCH(p,q):\quad \sigma_t^2=\omega+\sum_{i=1}^{q}\alpha_i\epsilon_{t-i}^2$ $+\sum_{j=1}^{p}\beta_j\sigma_{t-j}^2$
	- ARCH term : $\epsilon_{t-i}^2$ = new shock
	- GARCH term : $\sigma_{t-j}^2$ = vola. persistence

### GARCH(1,1)
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- $\alpha$ : 새 shock 영향 / $\beta$ : 과거 vola. 지속 / $\alpha+\beta$ : persistence
- 조건/장기분산 : $\omega>0,\quad \alpha,\beta\ge0,\quad \alpha+\beta<1,\quad E(\sigma_t^2)=\frac{\omega}{1-\alpha-\beta}$
	- $\omega>0,\alpha,\beta\ge0$ : variance 음수 방지
	- $\alpha+\beta<1$ : variance 발산 X, 장기평균 존재
	- $\alpha+\beta\approx1$ : shock 오래 감, high-vol state 천천히 식음
- 실증 기본 : GARCH(1,1)부터; high order 남발 X(noisy + 추정불안정)

### MLE
- vola. 직접 관측 X : $\sigma_t^2$는 residual 기반 latent object $\to$ OLS X, MLE O
- **오답방지 : GARCH를 MLE로 추정하는 이유는 단순히 "iid가 아니어서"가 아니라 $\sigma_t^2$가 관측불가능 + time-varying이라 conditional PDF로 평가해야 하기 때문**
- 정규가정 : $\epsilon_t|I_{t-1}\sim N(0,\sigma_t^2)$
- log-likelihood : $\ell(\theta)=\sum_t[-\frac{1}{2}\log(2\pi)-\frac{1}{2}\log\sigma_t^2-\frac{\epsilon_t^2}{2\sigma_t^2}]$
- 절차 : mean eq. 설정 $\to$ GARCH recursion으로 $\sigma_t^2$ 생성 $\to$ conditional PDF $\to$ LL maximize

### Fat Tail / Asymmetry(light)
- fat tail 직관 : conditional normal + time-varying $\sigma_t^2$ $\to$ 여러 variance의 normal mixture $\to$ unconditional tail 두꺼움
	- 기본 fat tail : 양쪽 tail 두꺼운 heavy tail, skewness와 구분
- 기본 GARCH : $\epsilon_{t-1}^2$ 사용 $\to$ $+5,-5$ 동일 취급
- leverage/asymmetry : negative shock가 positive shock보다 vola. 더 키울 수 있음
	- EGARCH/TGARCH/GJR : sign effect 반영하는 확장. 식 암기보다 필요 이유만.

### 확장 언급(light)
- GARCH-in-Mean : risk/vola.가 expected return에 직접 들어감
- Exogenous vola. factor : news, trading volume, implied vola. 등으로 $\sigma_t^2$ 설명 보강
- 1 asset : $\sigma_t^2$ scalar
- multivariate GARCH : $N$ assets의 $\Sigma_t$ 모형화 $\to$ 개별 vola. + cov/corr time-varying
	- BEKK/DCC/CCC : 이름 언급 수준. DCC=time-varying corr., CCC=constant corr.
---

### 백지복원
- GARCH : $R_t$의 time-varying vola. + clustering 설명 $\to$ $\sigma_t^2$ 모형화. 
- mean eq. : $y_t=x_{t-1}'\beta+\epsilon_t,\ \epsilon_t=\sigma_tz_t,\ z_t\sim iid(0,1)$.
- ARCH : $\sigma_t^2=\alpha_0+\sum_i\alpha_i\epsilon_{t-i}^2$ $\to$ 과거 shock 크기 반영.
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$.
- $\alpha$ = new shock, $\beta$ = persistence, $\alpha+\beta<1$, $E(\sigma_t^2)=\frac{\omega}{1-\alpha-\beta}$.
- $\sigma_t^2$ 관측 X $\to$ GARCH recursion + conditional PDF + MLE.
- fat tail : time-varying variance의 normal mixture; asymmetry 필요시 EGARCH/TGARCH 언급.


## 8. Vector Auto-Regression (VAR)

### Idea
- VAR : 여러 stationary ts를 **vector로 묶은 AR**
	- scalar AR : $y_t=c+\phi y_{t-1}+e_t$
	- VAR : $Y_t=A_0+A_1Y_{t-1}+\cdots+A_pY_{t-p}+u_t$
- 왜? : 경제 shock는 한 변수에만 X, 여러 시장/부문에 동시 전파
	- ex) 금리 shock $\to$ $\pi_t$, GDP, 실업률, 환율 등 같이 움직임
	- single eq.의 ceteris paribus 직관 약함 $\to$ system으로 같이 추정
- 강의 반복 포인트 : VAR 자체는 OLS처럼 추정 쉬움; 어려운 건 shock 해석/identification

### VAR(p)
- $Y_t=(y_{1t},\cdots,y_{nt})'$
- reduced-form VAR(p) : $Y_t=c+A_1Y_{t-1}+\cdots+A_pY_{t-p}+u_t,\quad E(u_tu_t')=\Sigma_u$
- each eq. : 같은 RHS($Y_{t-1},...,Y_{t-p}$) $\to$ eq별 OLS 가능
- 활용
	1. dynamics : 변수간 lead-lag
	2. forecast : 과거 $Y$로 미래 경로 예측
	3. structural shock analysis : shock가 각 변수에 퍼지는 경로(IRF)
- 주의(light) : 변수/lag 막 넣기 X $\to$ parameter 폭증, data variation/theory 필요

### Reduced Form vs Structural Form
- foundation : simultaneous eq.처럼 경제 변수는 같은 시점에 함께 결정; 관측은 구조곡선 X, 균형값 O
- structural form : $B_0Y_t=b+\sum_iB_iY_{t-i}+\varepsilon_t,\quad E(\varepsilon_t\varepsilon_t')=D$
	- $B_0$ : contemporaneous relation
	- $\varepsilon_t$ : economic structural shock, 서로 orthogonal/independent하게 해석하고 싶음
- reduced form : $Y_t=c+\sum_iA_iY_{t-i}+u_t,\quad E(u_tu_t')=\Sigma_u$
	- data로 바로 추정 가능
	- $u_t$끼리 contemporaneous correlation 가능 $\to$ 경제적 shock으로 바로 읽기 X
- 연결
	- $Y_t=B_0^{-1}b+\sum_i B_0^{-1}B_iY_{t-i}+B_0^{-1}\varepsilon_t$
	- $u_t=B_0^{-1}\varepsilon_t,\quad \Sigma_u=B_0^{-1}D(B_0^{-1})'$
- 핵심 : reduced form 추정 O, structural shock 관측 X $\to$ identification 필요

### Normalization / Identification
- identification 문제 : reduced-form moments만으로 structural parameters를 모두 복원할 수 없음
- 단순 직관 : $\alpha^*y_t=\beta^*X_t+e_t$는 양변을 $\alpha^*$로 나누면 같은 reduced form을 여러 structural parameter 조합이 만들 수 있음
- 해결 : normalize/restrict 필요
	- ex) $\alpha^*=1$ 또는 shock variance normalize
	- VAR에서도 structural parameter 수 > reduced-form information $\to$ restriction 필요
- 식별 직관 : 관측되는 건 균형값/축약형 shock; 수요/공급/정책 shock는 구조제약 없이는 분리 X

### Recursive / Cholesky Identification
- 목적 : $\Sigma_u=PP'$인 $P$를 찾아 $u_t=P\varepsilon_t,\quad V(\varepsilon_t)=I$
- Cholesky : $P$ lower triangular $\to$ ordering으로 동시반응 제약 부여
	- 위에 둔 변수 : 같은 시점에 뒤 변수 shock에 즉시 반응 X
	- 아래 변수 : 앞 변수 shock에 즉시 반응 O
- 함의 : var ordering = 경제적 가정
	- 순서 바꾸면 structural shock, IRF 달라질 수 있음 $\to$ theory로 justify 필요
- shock scale : 보통 1 s.d. shock; 보고서용으론 1% shock로 normalize 가능

---

### IRF(Impulse Response Function)
- IRF : structural shock 1회 발생 $\to$ 각 변수의 미래 반응 경로
	- $\varepsilon_{jt}$ 1단위/1 s.d. shock $\to$ $Y_{t+h}$ 변화
- VAR(1) intuition
	- $Y_t=A_1Y_{t-1}+u_t,\quad u_t=P\varepsilon_t$
	- $h$기 반응 : $\frac{\partial Y_{t+h}}{\partial\varepsilon_t}=A_1^hP$
- 해석 hint
	- 금리↑↑ shock $\to$ 이론상 $\pi$↓↓, output↓↓, unemployment↑↑ 예상
	- 초기 반응 이상하면? ordering/변수/proxy/lag/sample 문제 의심
	- 실업률 등 slow-moving 변수는 즉시반응 작고 후행 가능
- 장기효과
	- sta. VAR이면 shock 효과는 시간이 지나며 0으로 수렴
	- 정책은 주로 cycle에 영향, trend 영구효과 주장은 별도 이론 필요

### Forecast / FEVD(light)
- Forecast : $\hat Y_{T+h}$를 VAR recursion으로 생성
	- in-sample fit 좋음 ≠ forecast 좋음
	- forecast error가 새 info. update의 핵심
- FEVD : $h$기 예측오차 분산 중 각 shock가 설명하는 비중
	- 강의자료 원문상 깊은 유도 X $\to$ IRF와 대비되는 직관만

### Practical Notes(light)
- stationarity : VAR 기본형은 stationary 변수 사용
- 변수/lag 선택 : theory + data variation + IC/robustness
- IRF 해석 : shock 방향/scale/ordering 명시

### 백지복원
- VAR : $Y_t$ vector의 AR. 경제 shock는 여러 변수에 동시 전파 $\to$ system 필요.
- reduced-form : $Y_t=c+\sum_iA_iY_{t-i}+u_t$, eq별 OLS 가능.
- $u_t$는 reduced-form residual $\to$ structural policy shock 아님.
- **오답방지 : $u_t$ 구성요소는 contemporaneous correlation 가능 $\to$ 경제적 독립 shock으로 바로 해석 X**
- structural form : $B_0Y_t=b+\sum_iB_iY_{t-i}+\varepsilon_t,\quad u_t=B_0^{-1}\varepsilon_t$
- $\varepsilon_t$ 복원 필요 $\to$ identification.
- reduced-form moments만으론 structural parameter 부족 $\to$ normalization/restriction.
- Cholesky : ordering으로 동시반응 제약, $u_t=P\varepsilon_t$ 분해.
- **Cholesky ordering 복원 : 위 변수는 같은 시점에 아래 변수 shock에 반응 X, 아래 변수는 위 변수 shock에 반응 O**
- IRF : shock 1회가 미래 $Y_{t+h}$에 미치는 경로; VAR(1) $\to$ $A_1^hP$.
- FEVD(light) : 예측오차 분산 중 각 shock의 설명비중; IRF=경로, FEVD=기여도 정도만.
- 변수/lag/order 막 넣기 X $\to$ stationarity, theory, data variation 확인.

## Weakness
### 시험용 약점 문장

#### 1. MLE

1) Conditional LL
- AR(1) $y_t=c+\phi y_{t-1}+\epsilon_t,\ \epsilon_t\sim N(0,\sigma^2)$에서 $y_1$을 given으로 보면 $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$.
- 따라서 $\ln L_c=-\frac{T-1}{2}\ln(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum_{t=2}^{T}(y_t-c-\phi y_{t-1})^2$.

2) Exact vs Conditional MLE
- Conditional MLE는 초기 관측치의 density를 생략하고 $\prod_{t=2}^T f(y_t|I_{t-1};\theta)$만 사용한다.
- Exact MLE는 초기분포 $f(y_1;\theta)$까지 포함하므로 stationary AR(1)에서는 $y_1\sim N\left(\frac{c}{1-\phi},\frac{\sigma^2}{1-\phi^2}\right)$를 이용한다.

3) $\phi\approx1$
- $\phi$가 1에 가까우면 shock persistence가 커지고 mean reversion이 매우 느리다.
- 이때 $E(y_t)=c/(1-\phi)$, $V(y_t)=\sigma^2/(1-\phi^2)$가 $\phi$에 민감해져 stationary AR(1)이라도 unit-root-like behavior를 보이므로 standard stationary asymptotics 해석에 주의한다.

4) MLE vs OLS
- Normal linear model에서는 log-likelihood를 최대화하는 것이 SSR을 최소화하는 것과 같으므로 $\hat\beta_{MLE}=\hat\beta_{OLS}$이다.
- 단, MLE는 $\hat\sigma^2=SSR/n$을 쓰고 OLS unbiased estimator는 $SSR/(n-k)$를 쓰므로 finite sample에서 차이가 난다.

#### 2. GARCH

1) 설명 대상
- GARCH는 $R_t$의 조건부 평균보다 residual의 조건부 분산 $\sigma_t^2$가 시간에 따라 어떻게 변하는지를 모형화한다.
- 즉 $\epsilon_t|I_{t-1}\sim N(0,\sigma_t^2)$에서 $\sigma_t^2$가 과거 정보에 의해 update되는 구조이다.

2) $\alpha,\beta$ 의미
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$.
- $\alpha$는 직전 shock size가 현재 volatility에 주는 영향이고, $\beta$는 과거 volatility 자체가 지속되는 정도이다.

3) $\alpha+\beta$
- $\alpha+\beta$가 1에 가까울수록 volatility shock이 오래 지속되고 high-volatility state가 천천히 식는다.
- 반대로 $\alpha+\beta$가 작으면 shock 이후 volatility가 빠르게 장기수준으로 mean-revert한다.

4) Fat tail
- 조건부로는 정규분포를 가정해도 $\sigma_t^2$가 time-varying하면 전체 수익률 분포는 여러 variance의 normal mixture가 된다.
- 이 mixture에서는 calm period의 0 근처 관측치와 high-vol period의 극단 관측치가 함께 많아져 unconditional distribution의 양쪽 tail이 정규분포보다 두꺼워진다.
- 한쪽 꼬리 비대칭은 skewness/asymmetry 문제이고, 기본 GARCH의 fat tail은 주로 symmetric heavy tail이다.

5) MLE 이유
- GARCH에서 $\sigma_t^2$는 직접 관측되지 않는 latent/time-varying object이므로 OLS로 바로 추정하기 어렵다.
- 평균방정식의 residual과 GARCH recursion으로 $\sigma_t^2$를 생성한 뒤, conditional density를 이용해 likelihood를 구성하고 MLE로 추정한다.

#### 3. VAR

1) VAR 항/차원
- $Y_t=A_0+A_1Y_{t-1}+u_t$에서 $Y_t,u_t,A_0$는 $n\times1$, $A_1$은 $n\times n$, $\Sigma_u=E(u_tu_t')$이다.
- $A_1$은 각 변수의 lag가 현재 변수들에 미치는 dynamic effect matrix이다.

2) Reduced-form vs Structural shock
- Reduced-form residual $u_t$는 서로 contemporaneous correlation을 가질 수 있으므로 경제적으로 독립적인 structural shock으로 바로 해석할 수 없다.
- 따라서 $u_t=P\varepsilon_t$처럼 structural shock $\varepsilon_t$를 복원하려면 identification restriction이 필요하다.

3) Cholesky ordering
- Cholesky identification은 $\Sigma_u=PP'$에서 $P$를 lower triangular로 두어 ordering에 따른 contemporaneous restriction을 부여한다.
- $Y_t=(r_t,\pi_t)'$이면 위 변수 $r_t$는 같은 시점의 $\pi_t$ shock에 즉시 반응하지 않고, 아래 변수 $\pi_t$는 같은 시점의 $r_t$ shock에 즉시 반응할 수 있다.

4) Ordering 변경
- 변수 ordering을 바꾸면 contemporaneous causal restriction이 바뀌고, 이에 따라 $P$와 structural shock의 해석이 달라진다.
- 따라서 같은 reduced-form VAR이라도 ordering에 따라 IRF와 FEVD가 달라질 수 있으며, ordering은 경제이론으로 정당화해야 한다.

---

5) IRF vs FEVD(light)
- IRF는 structural shock 1회가 발생했을 때 각 변수의 미래 경로가 어떻게 반응하는지를 보여준다.
- FEVD는 특정 horizon의 forecast error variance 중 각 structural shock이 몇 %를 설명하는지를 보여준다.
- 즉 IRF는 shock의 동학적 경로이고, FEVD는 forecast uncertainty의 shock별 기여도라는 직관만 잡으면 충분하다.
