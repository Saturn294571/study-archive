## Maximum Likelihood Estimation
- Model : $y_i=\mu+e_i$
    - OLS Sample EQ : $y_i=\hat{\mu}+\hat{e}_i$
    - obj func of OLS(SSE) : $\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}\hat{e}_i^{2}=\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}(y_i-\hat{\mu})^{2}$
    - OLS estimator $\mu$ : $\hat{\mu}=\frac{1}{N}\sum_{i=1}^N y_i$
        - $\sigma^2$ : $\hat{\sigma}^2=\frac{1}{N-1}\sum_{i=1}^N (y_i-\hat{\mu})^2(=\hat{e}_i^2)$
- Likelihood value 정의 : 특정 모수하에서, 모집단으로부터 생성된 샘플 데이터가 나올 가능도
    - ex) $f(y;\theta)=(2\pi\sigma^2)^{-1/2}\exp\{-\frac{1}{2\sigma^2}(y-\mu)^2\}\quad\theta=\{\mu,\sigma^2\}$
        - 샘플링 이전엔 y를 모름. 확변. $\mu,\sigma^2$주어졌다면, y에 대한 확률 추정 가능
    - PDF : 확률 추정은 PDF를 통해 가능
        - 1) $Pr(y>\mu)=\int_{\mu}^{\infty}f(y;\theta)dy=0.5$ 2) $Pr(10>y>4)=\int_{4}^{10}f(y;\theta)dy$
            - (joint)JPDF of $\{y_1,\cdots,y_N\}=f(y_1,\cdots, y_N;\theta)\quad \theta=\{\mu,\sigma^2\}$
            - Marginal PDF of $y_i=f(y_i;\theta)$
        - r.v. A,B가 독립 $\to f(A \cap B)=f(A)f(B)$ : $f(Y;\theta)=\prod_{i=1}^N f(y_i;\theta)\quad Y=(y_1\cdots y_N)^T$
            - if $y_i\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$, then $f(Y;\theta)=(2\pi\sigma^2)^{-N/2}\exp\{-\frac{1}{2\sigma^2}(y-\mu)^2\}$
- Likelihood function : $L(\mu,\sigma^2|y_1,\cdots,y_N)=f(y_1,\cdots,y_N;\mu,\sigma^2)$
    - MLE의 목적함수는 $\underset{\mu,\sigma^2}{\text{argmax}}\ln L(\mu,\sigma^2|Y)$
        - $\ln()$ : 단조증가? -> 합성해도 해가 달라지지 X.
    - FOC of MLE : $\frac{\partial\ln L(\theta|Y)}{\partial\theta}=0$ : MLE는 FOC를 통해 모수들을 추정
- MLE example : $y_i=X_i'\beta+e_i$
    1) $y_i$ 분포 : $y_i\sim N(X_i'\beta,\sigma^2)$
    2) $f(y_i)$? ($y_i$의 pdf?) : $f(y_i;\beta,\sigma^2)=1/\sqrt{2\pi\sigma^2}\exp\{-\frac{(y_i-X_i'\beta)^2}{\sigma^2}\}$
    3) Y의 JPDF? : $f(Y;\beta,\sigma^2)=\prod_{i=1}^N f(y_i;\beta,\sigma^2)=(2\pi\sigma^2)^{-\frac{n}{2}}\exp\{-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{\sigma^2}\}$
    4) $L\to\ln L$ : $\ln L(\beta,\sigma^2|Y)=-\frac{n}{2}\ln 2\pi-\frac{n}{2}\ln\sigma^2-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{\sigma^2}$
    5) $\frac{\partial\ln L}{\partial \theta}=0$ : $\to\hat{\beta}_{\text{MLE}}=\hat{\beta}_{\text{OLS}}\quad \text{but},\hat{\sigma^2}_{\text{MLE}}=\frac{1}{n}\sum\hat{e}_i^2$
## MLE generalization
- $\hat{\theta}_{\text{MLE}}=\underset{\theta}{\text{argmax}}\ln L(\theta|Y)$
- 랜덤 샘플링시 LL(log likelihood) : $\ln L(\theta|Y)= \ln(\prod_{i=1}^{n}f(y_i;\theta))=\sum_{i=1}^{n}f(y_i;\theta)$
- FOC of MLE : $\forall \theta_i \in\theta=\{\theta_1,\cdots,\theta_k\},\quad\frac{\partial \ln L(\hat{\theta}_{MLE}|Y)}{\partial \theta_i}=0$
- score vector : $S(\theta|Y)=\frac{\partial \ln L(\hat{\theta}_{MLE}|Y)}{\partial \theta_i},\quad S(\hat{\theta}_{MLE}|Y)=0$
- LL func for linear reg model : $\ln L(\theta|y,X)=-\frac{n}{2}\ln(2\pi)-\frac{n}{2}\ln(\sigma^2)-\frac{1}{2\sigma^2}(y-X\beta)'(y-X\beta)\implies\frac{\partial \ln L(\theta|y,X)}{\partial\theta}=0$
    - $\hat{\beta}_{MLE}=(X'X)^{-1}X'y=\hat{\beta}_{OLS}$
    - but, $\hat{\sigma}^2_{MLE}=\frac{1}{n}(y-X\hat{\beta}_{MLE})'(y-X\hat{\beta}_{MLE})\neq\hat{\sigma}^2_{OLS}=\frac{1}{n-k}(y-X\hat{\beta}_{OLS})'(y-X\hat{\beta}_{OLS})$
        - 단, n의 크기가 커질수록 서로간 오차가 미미해짐

## MLE for series data
- 시계열의 LL : $\ln L(\theta|y)=\sum_{t=1}^{T}\ln f(y_t;\theta)$
- 시계열의 경우 오차가 IID X. (독립X)
    - $\therefore$ 교사건 확률을 조건부 확률로 표현 : $p(A\cap B)=p(B|A)p(A);\quad P(A\cap B\cap C) = p(C|A\cap B)p(B|A)p(A)$
    - ts에선, : $f(y_T,\cdots,y_1;\theta)=\{\prod_{t=p+1}^{T}f(y_t|I_{t-1};\theta)\}\cdot f(y_p,\cdots,y_1;\theta)$
        - $I_{t}=\{y_t,\cdots,y_1\}$ : t시점의 가능한 정보
        - $y_p,\cdots,y_1$ : p개의 초기 관측치
        - $\therefore$ LL 에서 : $\ln L(\theta|y)=\sum_{t=p+1}^T \ln f(y_t|I_{t-1}\theta)+\ln f(y_p,\cdots,y_1;\theta),\quad \hat{\theta}_{MLE}= \max \ln L(\theta|y)$
