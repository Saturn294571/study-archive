# Motivation
- Auto Regressive Moving Average(ARMA) : 가장 단순한 선형 단변량 시계열 모델
	- 현재의 한단위 충격이 미래에 영향을 얼마나 주는지 ($\frac{\partial Y_{t+i}}{\partial e_t}$)
	- $Y_t=\psi_0e_0+\underbrace{\psi_1e_1+\cdots}_{\text{wold form(representation)}}$
#### ARMA(p,q)
- $$Y_t=\mu+\phi_1Y_{t-1}+\cdots+\phi_pY_{t-p}+\epsilon_t+\theta_1\epsilon_{t-1}+\cdots+\theta_q\epsilon_{t-q}\quad\epsilon_t\sim N(0,\sigma^2)$$
	- mead-adj. 형태 : $Y_t-\mu$꼴을 사용
	- AR : (과거 나) -영향-> (현재 나) (영향 김; p기간 동안)
	- MA : (과거 충격) -영향-> (현재 나) (영향 짧; q기간)

- any stationary time series -> wold form
	- 오차 -> 실제 데이터엔 없음
- $y_t=\mu+\epsilon_t+$

- ACF(AutoCorrelation Function)
### Properties of MA(1) 
- MA(1) : $Y_t=\mu+\epsilon_t+\theta\epsilon_{t-1}\quad \theta\in\mathbb{R},\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon)$
	- 충격 -> 짧($\theta$에 달림)
- $E[Y_t]=\mu+E[\epsilon_t]+\theta E[\epsilon_{t-1}]=\mu$
- $Var[Y_t]=\sigma^2=E[(Y_t-\mu)^2]=\sigma^2_\epsilon(1+\theta^2)$ 
- $Cov[Y_t,Y_{t-1}]=\gamma_1=E[(Y_t-\mu)(Y_{t-1}-\mu)]=\theta\sigma^2_\epsilon$
	- $Cov[Y_t,Y_{t-2}]=\gamma_2 = 0$ ($Cov[Y_t,Y_{t-ㅓ}]=\gamma_j;\quad\forall j>1$)
- $\rho_1=\frac{\gamma_1}{\sigma_2}=\frac{\theta}{(1+\theta^2)},\quad\rho_j=\frac{\gamma_j}{\sigma_2}=0;\quad\forall j>1$
	- $\theta(=,>,<)0\to\rho_1(=,>,<)0$
- Dynamic Stability Condition : $\underset{j\to\infty}{\lim}\rho_j=0$
	- ex) 반응X or $\downarrow\downarrow$ : 충격 내재화; 통화정책 -> 유동성함정
### Properties of MA(2)
- MA(2) : $Y_t=\mu+\epsilon_t+\theta_1\epsilon_{t-1}+\theta_2\epsilon_{t-2}\quad \theta\in\mathbb{R},\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon),\forall t$
- $E[Y_t]=\mu+E[\epsilon_t]+\theta_1 E[\epsilon_{t-1}]+\theta_2 E[\epsilon_{t-2}]=\mu$
- $Var[Y_t]=\sigma^2=E[(Y_t-\mu)^2]=\sigma^2_\epsilon(1+\theta_1^2+\theta_2^2)$ 
- $Cov[Y_t,Y_{t-1}]=\gamma_1=\theta_1\sigma^2_\epsilon;\quad Cov[Y_t,Y_{t-2}]=\gamma_2=\theta_2\sigma^2_\epsilon$
	- $Cov[Y_t,Y_{t-j}]=\gamma_j;\quad\forall j>2$)
- $\rho_{1,2}=\frac{\gamma_{1,2}}{\sigma_2}=\frac{\theta_{1,2}}{(1+\theta_1^2+\theta_2^2)},\quad\rho_j=\frac{\gamma_j}{\sigma_2}=0;\quad\forall j>2$
- DSC : $\underset{j\to\infty}{\lim}\rho_j=0$

# AR Model
### Properties of AR(1)
- AR(1) : $Y_t=c+\phi Y_{t-1}+\epsilon;\quad\phi\in(-1,1),\epsilon_t\overset{iid}{\sim}N(0,\sigma^2_\epsilon)$
- $E[Y_t]=\frac{c}{1-\phi}=\mu$
- $\gamma_0=Var(Y_t)=\frac{\sigma^2}{1-\phi^2}$ (by stat. 가정)
	- $\gamma_j=Cov(Y_t,Y_{t-j})=\phi^j\frac{\sigma^2}{1-\phi^2}$ (by stat.)
- $\rho_j=\frac{\gamma_j}{\gamma_0}=\phi^j$
- DSC : $\lim_{j\to\infty}\rho_j=0$
	- AR(1)이 DSC를 항상 만족? -> 현실에선 $|\phi|<1$가 항상 O는 X.
	- $\therefore H_0 : \phi=1$을 검정후 기각되어야함 (unit root test)
### Properties of AR(2)
- AR(2) : $Y_t=c+\phi_1Y_{t-1}+\phi_2Y_{t-2}+\epsilon_t\quad \epsilon_t\sim iid\,N(0,\sigma_\epsilon^2)$
	- mean : $E[Y_t]=\frac{c}{1-\phi_1-\phi_2}=\mu$
	- Var : 구하기 위해 행렬  (stationary 가정->일정함 가정)
		- 목표 : 고차원 AR(p)를 AR(1)로 바꿔 분산 봄.. (1,1)원소 보면 발산 O? X?
		- $\begin{bmatrix}Y_t\\ Y_{t-1}\end{bmatrix}=\begin{bmatrix}\phi_1 & \phi_2\\ 1 & 0\end{bmatrix}\begin{bmatrix}Y_{t-1}\\ Y_{t-2}\end{bmatrix}+\begin{bmatrix}\epsilon_t\\ 0\end{bmatrix}$ $\implies \zeta_t^{(2\times1)}=F^{(2\times2)}\zeta_{t-1}+v_t^{(2\times1)}\quad v_t\sim N(0,R);\,R=\begin{bmatrix}\sigma^2_{\epsilon} & 0 \\ 0 & 0\end{bmatrix}$
		- $Var[\zeta_t]=F\cdot Var[\zeta_t]\cdot F'+Var[v_t]$
		  $Vec(Var[\zeta_t])=Vec(F\cdot Var[\zeta_t]\cdot F')+Vec(Var[v_t])$
		  $Vec(Var[\zeta_t])=(F\odot F)Vec(Var[\zeta_t])+Vec(R)$
		  $(I_4-F\odot F)Vec(Var[\zeta_t])=Vec(R)$
		  $Vec(Var[\zeta_t])=(I_4-F\odot F)^{-1}Vec(R)$
			- $Vec(Var[\zeta_t])$의 첫번째 원소는 $E[Y_t]$
	- Stationary 테스트 : $\lim_{j\to\infty}\rho_j=0$을 검증
		- $\underbrace{\begin{bmatrix}\rho_j\\ \rho_{j-1}\end{bmatrix}}_{\rho_j}=\underbrace{\begin{bmatrix}\phi_1 & \phi_2\\ 1 & 0\end{bmatrix}}_{F}\underbrace{\begin{bmatrix}\rho_{j-1}\\ \rho_{j-2}\end{bmatrix}}_{\rho_{j-1}}$ ($\rho_j$ : state vector, 내 상태를 정의)
		- F의 고유값 $\lambda$에 대해 $F=T\Lambda T^{-1},T=T^2$,
			- $\lim_{j\to\infty}F^j=T\lim_{j\to\infty}\Lambda^jT^{-1}=0\quad \therefore |\lambda_n|<1$
			- 따라서 |람다|<1 이어야 starionary OK

# IR 정리
### AR(1) : $y_t=\phi y_{t-1}+e_t\quad(let,\mu=0)$
- $\lim_{j\to\infty}\rho_j=0$ 가정 $\Rightarrow$ stationary OK
- $\frac{\partial Y_{t+j}}{\partial e_t}=\phi^j$, $\phi = \lambda$    $|\phi|<1\to$ (stationary) 항상 X. (sta. 한 환경에서만)
	- $\phi>1\to$ permanant & 충격 증폭해 발산
	- $\phi=1\to$ permanant but, 증폭 X
	- $\phi<1\to$ transitory & 충격 소멸
### AR(2) : $y_t=\phi_1 y_{t-1}+\phi_2 y_{t-2}+e_t\quad(let,\mu=0)$
- 가장 큰 계수가 stat. 을 결정
- 1st step : state space form 정의 -> 1st order model로 변형 (단, 고유하진 X)
	- $let\,z_t=Fz_{t-1}+\epsilon_t\implies\begin{pmatrix}y_{t}\\ y_{t-1}\end{pmatrix}=\begin{pmatrix}\phi_1&\phi_2\\ 1&0\end{pmatrix}\begin{pmatrix}y_{t-1}\\ y_{t-2}\end{pmatrix}+\begin{pmatrix}e_t\\ 0\end{pmatrix}$
		- hint : F 만들때 $y_{t-1}=y_{t-1}$
- 2nd step : shock에 대한 wold form으로 변형
	- $z_{t+j}=F^{j+1}z_t+\sum F^i\epsilon_{t+j-i}$
		- wold form : $z_t=\epsilon_t+\epsilon_{t-1}+F^2\epsilon_{t-2}+\cdots\to\infty$ order of shock
- 3rd step : 목표 : IR분석은 $\frac{\partial Y_{t+j}}{\partial e_t}$를 찾기 -> $z_t\in y_t$ 이므로
	- $z_t=\begin{pmatrix}y_{t}\\ y_{t-1}\end{pmatrix}=\cdots+\begin{pmatrix}F^j_{11}&F^j_{12}\\ F^j_{21}&F^j_{22}\end{pmatrix}\begin{pmatrix}e_{t-j}\\ e_{t-j-1}\end{pmatrix}+\cdots$ (단, stat. 가정 -> $\frac{\partial Y_{t+j}}{\partial e_t}=\frac{\partial Y_{t}}{\partial e_{t-j}}$)
		- 즉, $F^j=\begin{pmatrix}\phi_1&\phi_2\\ 1&0\end{pmatrix}^j=\begin{pmatrix}F^j_{11}&F^j_{12}\\ F^j_{21}&F^j_{22}\end{pmatrix}\implies$ IR의 정보가 담김
			- ex) $\begin{pmatrix}y_{t}-(unem)\\ x_t-\triangle\mu\end{pmatrix}=\cdots\begin{pmatrix}e_{1t}\\ e_{2t}\end{pmatrix}$
		- 이때 $\phi_1,\phi_2$ 중 어느게 impact가 큰지를 확인 필요 -> 특이값 분해
- 4th step : SVD : $Fv=\lambda v\quad(v\neq0)$
	- $(F-\lambda I)v=0\to \det(F-\lambda I)=0$ 면 $v\neq0$ 인 해 존재
	- 특성방정식 : $\lambda^2-\phi_1\lambda-\phi_2=0\Rightarrow\,\lambda_1,\lambda_2$
		- 단, 제약조건 : $\forall \lambda_n,v_n$에 대해, $Fv_n=\lambda v_n,v_n'v_n=1$; n개의 선형독립 필.
	- $FV=V\Lambda\implies F\begin{pmatrix}v_1&v_2\end{pmatrix}=\begin{pmatrix}v_1&v_2\end{pmatrix}\begin{pmatrix}\lambda_1&0\\0&\lambda_2\end{pmatrix}$
		- (V : 특성 vec.들을 모음, $\lambda$ : 고유값들을 대각성분 모음)
	- $F=C\Lambda C^{-1}\to F^j=C\Lambda^jC^{-1}$
	- $\therefore\frac{\partial Y_{t+j}}{\partial e_t}=\frac{\partial Y_{t}}{\partial e_{t-j}}=?\to F^j_{11}=\omega_1\lambda_1^j+\omega_2\lambda_2^j$
		- stability condition : $|\lambda_n|<1,\forall n\to\lim_{j\to\infty}\rho^j=0$
