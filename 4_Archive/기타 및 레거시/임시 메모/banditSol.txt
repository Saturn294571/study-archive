bandit6 : find 명령어의 사용법과 활용
find는 계층적 디렉토리의 파일이나 디렉토리 위치를 알 수 있다. 이 명령어는 파일 이름, 크기, 소유자, 수정시간, 파일 유형  등 표준 검색을 사용한다.
find (파일경로) (검색옵션) (액션)으로 사용
여러 검색옵션을 사용하려면 "AND"절을 사용해야한다.
find / -user (유저ID) -print : 최상위 디렉토리 / 에서 유저ID가 소유한 파일들의 경로를 출력함
-user : 해당 유저가 소유하고 있는 파일들을 보여줌
-group : 해당 그룹이 소유하고 있는 파일들을 보여줌
-size : 특정 크기의 파일을 보여줌

bandit8 : 파이핑, sort 사용법, uniq 사용법
파이핑 : 순차적으로 명령어의 실행 결과가 다음 명령어의 입력값이 된다. 파이핑의 방법은 '|'을 통해 실행하면 된다.
sort : 입력받은 데이터들을 오름차순/내림차순으로 정렬한다. 중복되는 항목을 제거하지 않는다.
uniq : 입력받은 정렬된 데이터들을 중복을 제거하여 표시한다. -u 옵션을 쓰면 중복되지 않는 유일한 라인만 표시하고, -d는 반대로 중복되는 라인만 표시한다. -c를 쓰면 중복되는 횟수를 표시한다.
사용법 : sort (입력) | uniq -u

bandit11 : tr 명령어 사용법

ex1) echo 'Hello, World!' | tr 'A-Za-z' 'D-ZA-Cd-za-c'
ex2) echo 'Hello, World!' | tr 'abced' 'hijkl'

bandit20 : nc를 사용하여 데이터 전송
파이프를통해 nc로 데이터를 입력하면(echo, cat등) nc 명령어에서 지정하는 포트로 데이터를 송신할 수 있다. 반대로 데이터를 입력하지 않고 nc명령어를 쓸 경우, 해당 포트에서 데이터를 수신하게 된다.
nc 명령어로 새로운 포트를 여는 방법은 : nc -l (포트번호) (호스트 주소) 이다.
자신의 컴퓨터에 새로운 포트를 열고싶다면 localhost 또는 생략하면 된다.
-kl 인수를 붙이면 nc에서 데이터를 송신 후에도 포트가 닫히지 않는다. (단, 데이터는 처음에만 보낸다.)
nc 명령어 끝에 '&'를 붙이면 백그라운드에서 실행된다.
ex) echo '안녕하세요!' | nc -lk 7000 &

banidt21 : cron의 의미와 crontab 사용법, /dev/null과 '&>'의 의미
cron : 리눅스에서 특정 시간에 특정 작업을 하는 데몬(백그라운드 프로그램)을 크론이라 한다
crontab : 크론이 언제 무엇을 하는지 특정 파일에 저장하는 것을 크론탭이라고 한다.
크론탭 작업은 크론이 원하는 시간에 원하는 명령/프로그램을 수행하도록 명령리스트를 만드는 것이다.
crontab 사용법 :
  크론탭 편집/작업 내용 확인/크론탭 삭제 :
    crontab (-e/-l/-r)

  크론탭 주기 :
    * * * * * {실행명령}
    (위 순서대로 분 시 일 월 요일 {실행명령})

    매 분마다 실행 : * * * * * {실행명령} or 1 * * * * {실행명령}
    매주 월요일 13시 정각에 실행 : 0 13 * * 1 {실행명령}

  크론탭 시작/중지/동작확인 :
    service cron (start/stop/status)

  크론탭 재시작 :
    service cron restart    or    service crond restart

/dev/null : 리눅스에서의 블랙홀과 같은 곳이다. 이곳으로 파이프를 통해 데이터를 입력하면 데이터가 사라진다
'&>' : 리다이렉트 한다는 얘기이다. 따라서 '(파일) &> /dev/null'은 (파일)에 대한 stdout(1)과 stderr(2)를 모두 /dev/null로 redirect(버린다) 한다.
