###### Neural Network
- 뉴런을 수학적 모형으로 모방 -> 인간처럼 판단 수행 : $f(\sum w_ix_i+b)=y$가 되도록 미지수 w값을 구하고자함.
- ![[Pasted image 20251202152353.png]]
	- 입력 $X_1,X_2,X_3$에 각 가중값을 곱함. 가중치 큼? -> 해당자극이 신경을 활성화하는데 중요한 자극. 즉, 원하는 결과가 어떤 자극에 의해 나타나는지 가중치로 구함
	- f : 활성함수; 조건 : 비선형 && 연속함수
		- f -> sigmoid? : 신경망이 logistic reg.와 같아짐.
		- y는 종속변수(hypothesis), $X_{1\sim3}$는 독립변수(feature) t는 target
			- $Y=S(WX+b)=\frac{1}{1+\exp[-(WX+b)]}$
- 뉴런 작동 과정 : 임의의 w가중치를 준 후 연산해서 error를 구함 -> 오차를 줄이는 방향으로 w값 업데이트
