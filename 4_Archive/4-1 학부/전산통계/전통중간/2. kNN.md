###### 1. kNN(k Nearst Neighbor)
- 최근접 이웃 알고리즘 : 거리를 통해 가장 가까운 이웃 k개를 선정. 그리고 가장 이웃의 특성이 새 데이터의 특성으로 분류
	- feature selection : 집단을 구별할 수 있는 변수를 선정
- 방법 : 새로운 데이터를 유클리드 거리$(dist(P,Q)=\sqrt{(p_1-q_1)^2 + \cdots (p_n-q_n)^2} )$을 구해 가장 가까운 이웃 k개 추출 $\to$ 이웃들의 feature중 가장 많은 수의 feature로 새 데이터 분류
	- ex) 토마토$\to$(오렌지, 포도, 땅콩);    토마토 $\to$ 과일
- 변수 standardization
	- 사용 이유 : 각 변수의 스케일이 다르면 거리 계산이 왜곡되기 때문 
	- Z-score 정규화 : $Z_{ij}=\frac{x_{ij}-\bar{x}}{\bar{s}_i}$
	- minimax 정규화 : $x_{new} = \frac{x-x_{min}}{x_{max}-x_{min}}$
- confusion matrix : 
  ```python
# confusion matrix output
[[1397 21]
[ 23 227]]
  ```

|                 | Predicted Negative | Predicted Positive |
| --------------- | ------------------ | ------------------ |
| Actual Negative | TN (1397)          | FP (21)            |
| Actual Positive | FN (23)            | TP (227)           |

- fp=1종 오류, fn = 2종 오류 $\to$ fn과 fp간의 상충관계
	- ![[Pasted image 20251013145408.png]]
- Accuracy(총 맞춘 확률) = $\frac{tp+tn}{tp+tn+fp+fn}$, Precision(p라고 했을 때 맞출 확률) = $\frac{tp}{tp+fp}$, Recall(실제 참 중에서 맞췄을 확률) = $\frac{tp}{tp+fn}$
	- 실무적으론 $F_1=\frac{2(\text{Precision}\cdot \text{Recall})}{\text{Presicion}+\text{Recall}}$(조화평균) 이 높은걸 택.
	- 암진단, 스팸필터중 recall과 precision중 어떤게 더 중요할까?
		- 암 : 재현률, 암환자를 놓치는것(fn)이 정상을 암환자로 진단(fp)하는게 더 치명적.
		- 스팸메일 : 정밀도, 정상메일을 스팸으로 오분류(fp)시 중요 메일을 놓치는 것이 더 치명적
###### 2. Example : Diagnosing breast cancer
- 범주형데이터(one-hot-encoding) : (사과, 딸기, 배) $\overset{\text{X}}{\to} (1,2,3);\, \overset{\text{O}}{\to}(1,0,0),(0,1,0),(0,0,1)$
	- 범주를 벡터로 만들어 거리를 통일
- feature selection과 t-test
	- $t=\frac{\bar{X}_1-\bar{X}_2}{\sqrt{S_1^2/n_1+S_2^2/n_2}}$;    $p=CDF : \overset{\text{우측검정}}{1-F(t)}\text{ or }\overset{\text{좌측검정}}{F(t)}\text{ or }\overset{\text{양측검정}}{2|1-F(t)|}$
- 데이터 분할 : 표준화를 통해 $f(x)\to f(z)$, 30% 검증, 랜덤하게 샘플링

| diag    | Z       |                                     |
| ------- | ------- | ----------------------------------- |
| y_train | Z_train | <- y_train = f(z_train)             |
| y_test  | Z_test  | pred = f(z_test)<br>pred == y_test? |
- Train / Test Set 분리(Test Set 크기 30%)
