###### 1. Spam mail 유래
- 스팸메일의 가능성이 높은 단어 ex) viagra, casino, ... 이 포함된 단어들을 나이브 베이지안을 통해 분류
###### 2. 조건부 확률
- $P(A|B)=\frac{P(B|A)P(A)}{P(B)}=\frac{P(A\cap B)}{P(B)}$
- ![[Pasted image 20251013144716.png]]
	- 사전정보(prior) + 새로 습득한 정보(likelihood) -> 사후 확률(posterior) 예측
- 몬티홀 문제 : 방을 바꾸면 이득
###### 3. Naive Bayse Theorm
- 각 단어들이 나타날 연관성까지 따지면 확률이 독립이 아니다 
	- ex) casino, money, slot ... 
- but, 수많은 단어 교집합에 대해 확률을 일일히 계산하는건 불가능 -> 독립이 아닐걸 독립이라고 단순화해 가정
- ![[Pasted image 20251013144848.png]]
###### 4. Term Document Matrix(TDM)
- 자연어 처리를 위해 문서를 단어들이 포함된 매트릭스 로 변환; 
	- 독립변수인 각 단어수를 카운트하고 타겟변수는 우측 끝. -> sparse matrix
	- ![[Pasted image 20251013144918.png]]

- dictionary 중에 불필요한 단어는 지우기 위해 딕셔너리의 키만 확보한 다음 하나씩 꺼내면서 문자가 아니면 지우고, 단어길이가 1이면 지운다.
- 여기에서 특정한 키가 특정 조건을 만족하는 것을 지우는 코드를 추가할 수 있다.
```python
list_to_remove = list(dictionary.keys())

for item in list_to_remove:
    if item.isalpha() == False: # 문자가 아니면 지움
        del dictionary[item]
    elif len(item) == 1:        # 단어의 길이가 1이면 지움
        del dictionary[item]
```
