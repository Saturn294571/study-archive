### 추가 필기
###### positive definite(양정치) matrix : 
  대칭행렬 $A \in \mathbb{R}^{n \times n}$ 에 대해, 다음을 만족시 : $\forall x \in \mathbb{R}^n \text{ and } x \neq 0, \quad x^{T}Ax > 0.$
    - positive semidefinite (non-negative definite) : 같은 조건에서, $x^{T}Ax \ge 0.$

###### Eigenvalues & Eigenvectors : 정방행렬 $A_{(n\times n)}$, 스칼라 $\lambda\in\mathbb{R}$, $x\neq\mathbf{0}$에 대해,
  $Ax = \lambda x\implies$ $\lambda$는 고유값, $x$는 고유벡터
    - $Ax - \lambda x = (A - \lambda I)x = 0$ $\implies |A - \lambda I| = 0$

###### spectral decomposition :
  $A_{(n\times n)}$의 고유값이 $\lambda_1, \lambda_2, \dots, \lambda_n$ , normalized 고유벡터가 $x_1, x_2, \dots, x_n$ 라면 :
  $A = CDC^{T} = \sum_{i=1}^n \lambda_i x_i x_i^{T}$
    - $D = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_n) = \begin{pmatrix} \lambda_1 & & 0 \\ & \lambda_2 & \\ 0 & & \ddots & \\ & & & \lambda_n \end{pmatrix}$, $C = (x_1, x_2, \dots, x_n), \quad CC^{T} = C^{T}C = I_n$ ($\because$고유벡터들은 서로가 직교, $x_i^{T}x_j = 0$)
        - (참고) $A = A \cdot CC^{T} = A(x_1, x_2, \dots, x_n)C^{T}= (\lambda_1 x_1, \lambda_2 x_2, \dots, \lambda_n x_n) C^{T}$
          $= (\lambda_1 x_1, \lambda_2 x_2, \dots, \lambda_n x_n)_{(n\times 1)}\begin{pmatrix} x_1^{T} \\ x_2^{T} \\ \vdots \\ x_n^{T} \end{pmatrix}{(1\times n)} = \sum_{i=1}^n \lambda_i x_i {x_i^{T}}_{(n\times n)} \quad \blacksquare$
            ${}^{**} |A| = \prod_{i=1}^n \lambda_i$     ${}^{**} \text{tr}(A) = \sum_{i=1}^n \lambda_i$

###### Idenpotent matrix(멱등행렬) :$A^2 = A$    ($\Downarrow$성질)
1) 멱등행렬$A$의 고유값은 $0,1$ 중 하나. :
	$A^2 = A$ and $Ax = A^2x = A \cdot Ax = A \cdot \lambda x = \lambda Ax = \lambda^2x$
	$\therefore Ax= A^2x=\lambda x = \lambda^2x\implies \lambda(1 - \lambda)x = 0, \quad x \neq 0 \rightarrow \lambda = 0 \text{ or } 1\quad \blacksquare$
2) $\text{tr}(A) = \sum_{i=1}^n \lambda_i$    ($0$이 아닌 $\lambda_i$의 수)$= \text{rank}(A)$

###### Gauss-Markov theorm
- 선형모델 $Y = X\beta + \epsilon, \quad \epsilon_i \overset{\text{iid}}{\sim} N(0, \sigma^2), \quad Y \in \mathbb{R}^n, X \in \mathbb{R}^{n \times p}, \beta,c \in \mathbb{R}^p,$
    $c^{T}\beta$의 LSE는 $\underset{\text{유일함}}{\text{unique}}$하고 BLUE($\underset{\text{최소분산}}{\text{best }}\underset{\text{선형성}}{\text{linear }} \underset{\text{불편성}}{\text{unbiased }}\text{estimator}$)이다
- ex) ${\beta} = (\beta_0, \beta_1, \beta_2)^{T}, \quad c = (c_0, c_1, c_2)^{T}$ ($\forall c_i \in \mathbb{R}$)
	$c_0 \beta_0 + c_1 \beta_1 + c_2 \beta_2 \rightarrow \hat{(c^{T}\beta)} = c^{T}\hat{\beta}^{\text{LSE}} = c^{T}(X^{T}X)^{-1}X^{T}Y$
- proof)
  1) 선형성(linearity) :$c^{T}\hat{\beta} = c^{T}(X^{T}X)^{-1}X^{T}Y = g^{T}Y \quad (Y\text{의 선형결합})\quad \square$
  2) 불편성(unbiasedness): $E(c^{T}\hat{\beta}) = E(c^{T}(X^{T}X)^{-1}X^{T}Y) = c^{T}(X^{T}X)^{-1}X^{T} E(Y) = c^{T}(X^{T}X)^{-1}X^{T} X\beta = c^{T}\beta\quad \square$
  3) 최소분산(best) : $c^{T}\beta$의 불편추정치 $d^{T}Y$가 있다고 가정하자.
	1) $E(d^{T}Y) =  d^{T}E(Y) = d^{T}X\beta = c^{T}\beta \implies X^{T}d = c \quad \text{(조건 1)}$
	2) $\quad \text{Var}(d^{T}Y) = \text{Var}(d^{T}Y - c^{T}\hat{\beta} + c^{T}\hat{\beta}) = \text{Var}(d^{T}Y - c^{T}\hat{\beta}) + \text{Var}(c^{T}\hat{\beta}) + 2\text{Cov}(d^{T}Y- c^{T}\hat{\beta}, c^{T}\hat{\beta})$
	$\because \text{Var}(d^{T}Y - c^{T}\hat{\beta}) \ge 0$,
	$\text{Var}(d^{T}Y) \ge \text{Var}(c^{T}\hat{\beta}) + 2 \underbrace{\text{Cov}(d^{T}Y, d^{T}Y - c^{T}\hat{\beta})}_{=0(*)} \implies \text{Var}(d^{T}Y) \ge \text{Var}(c^{T}\hat{\beta})\quad \square$
	- $(*) \quad \text{Cov}(c^{T}\hat{\beta}, d^{T}Y - c^{T}\hat{\beta}) = \text{Cov}(c^{T}(X^{T}X)^{-1}X^{T}Y, d^{T}Y - c^{T}(X^{T}X)^{-1}X^{T}Y)$
		  $= c^{T}(X^{T}X)^{-1}X^{T} \text{Cov}(Y, Y) (d - X(X^{T}X)^{-1}c)$ (Cov 빠져나올 때 전치됨)
		  $= \sigma^2 c^{T}(X^{T}X)^{-1}X^{T} (d - X(X^{T}X)^{-1}c)$ (Cov(Y,Y)=$\sigma^2I$)
		  $= \sigma^2 \left\{ c^{T}(X^{T}X)^{-1}\underset{=c}{X^{T}d} - c^{T}(X^{T}X)^{-1}X^{T}X(X^{T}X)^{-1}c \right\}$
		  $= \sigma^2 \left\{ c^{T}(X^{T}X)^{-1}c - c^{T}(X^{T}X)^{-1}c \right\} = 0$
	  - (참고) : $\text{Cov}(a^{T}X, b^{T}Y) = E((a^{T}X - a^{T}\mu_{X})(b^{T}Y - b^{T}\mu_{Y})^{T}) = a^{T} \text{Cov}(X, Y) b$
4) 유일성(unique) : $c^T\beta$의 또 다른 BLUE인$d^TY$가 있다고 할 때, 
   $\text{Var}(d^TY) = \text{Var}(c^T\hat{\beta}) + \text{Var}(d^TY - c^T\hat{\beta})$이고, $\text{Var}(d^TY) = \text{Var}(c^T\hat{\beta})$
   ($\because d^TY$ 또한 $c^T\beta$의 BLUE이기 때문) 
	- $\therefore \text{Var}(d^TY - c^T\hat{\beta}) = 0$    분산이 0(상수항)$\implies d^TY \overset{(*)}{=} c^T\hat{\beta}.$
	- $(*) \quad d^TY - c^T\hat{\beta} = k$; (k는 상수)$\text{If } k \neq 0, \quad 0 \neq k = E(d^TY - c^T\hat{\beta}) = E(d^TY) - E(c^T\hat{\beta}) = c^T\beta - c^T\beta = 0$
	  모순, $\therefore k=0, \quad d^TY = c^T\hat{\beta}$
