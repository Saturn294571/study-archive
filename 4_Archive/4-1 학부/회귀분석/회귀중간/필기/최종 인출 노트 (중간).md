## 1. 나의 약점 (오답노트) 🚨

- 모델에 따라 계수가 주어지지 않는다면 직접 $\hat{\beta_0},\hat{\beta_1}$를 계산해야함
- (t-val) -> CV는 $t_{\alpha/2}(df=n-p-1)$
- (t-val) = $\frac{\hat{\beta_j}-\beta_j^0}{SE(\hat{\beta_j})}$;     if $\beta_j^0=0$, $t_{\alpha/2}=\frac{\hat{\beta_j}}{SE(\hat{\beta_j})}$    (ANOVA에서 t-val로 나오는 것)
- $\hat{\theta}_j=\hat{\beta}_j\frac{s_{x_j}}{s_y}=\hat{\beta}_j\frac{\sqrt{S_{xx}/(n-1)}}{\sqrt{S_{xy}/(n-1)}}$
- (F-val) = $\frac{MSR}{MSE}$    (F-val) = $\frac{(SSE_F-SSE_R)/(p_F-p_R)}{SSE_F/(n-p_F-1)}$

## 2. Part 1: 핵심 이론 (55점)

### 가우스-마르코프 (BLUE)
- BLUE의 약자는?
    - **B**est **L**inear **U**nbiased **E**stimator (최량 선형 불편 추정량)

- "Best"의 의미는?
    - **최소 분산** (Minimum Variance). (모든 '선형', '불편' 추정량 중에서)

- "Best" 증명의 핵심 아이디어(힌트)?
    - 1. **비교:** $\text{Var}(d^T Y)$ vs $\text{Var}(c^T \hat{\beta})$
    - 2. **전개:** $\text{Var}(d^T Y) = \text{Var}(d^T Y - c^T \hat{\beta}) + \text{Var}(c^T \hat{\beta}) + 2\text{Cov}(...)$
    - 3. **핵심:** $\text{Cov}(...)$ 항이 **0**임을 증명해야 함.
    - 4. **조건:** $\text{Cov}=0$ 증명 시, $d^T Y$의 '불편성' 조건($\mathbf{X^T d = c}$)을 사용함.

### SSE 분포
- $SSE/\sigma^2 \sim \chi^2$ 증명의 최종 목표 형태는?
    - $SSE = \mathbf{\epsilon^T (I-P) \epsilon}$ 임을 보이는 것.

- 위 형태 유도의 핵심 아이디어(힌트)?
    - 1. $e = (I-P)Y$에 $Y=X\beta + \epsilon$을 대입.
    - 2. $e = (I-P)X\beta + (I-P)\epsilon$
    - 3. **$(I-P)X = 0$** ( $PX = X(X^TX)^{-1}X^T X = X$ 이므로)
    - 4. 따라서 $e = (I-P)\epsilon$ 이고, $SSE = e^T e = \epsilon^T(I-P)\epsilon$

- 왜 $\chi^2$ 분포를 따르는가 (힌트)?
    - 1. $SSE/\sigma^2$는 $\epsilon$의 2차 형식(Quadratic Form)임.
    - 2. 가운데 행렬 $(I-P)$가 **멱등 행렬(Idempotent)**임.
    - 3. (교수님이 '주어진 성질'로 사용하라 한 $G^T A G / \sigma^2 \sim \chi^2$ 정리가 적용됨)

- $SSE$의 자유도(df) 유도 (힌트)?
    - $df = \text{Rank}(I-P) = \text{Trace}(I-P) = \text{Tr}(I) - \text{Tr}(P) = n - (p+1)$

### 기타 5대 개념
- R² vs Adj.R²?
    - $R^2$는 $p$가 늘면 무조건 증가. **$Adj.R^2$ 는 불필요한 변수 추가 시 자유도(df) 페널티**를 주므로 모델 선택에 유용.

- CI vs PI?
    - * CI (신뢰구간): **평균 반응($\mu_0$)**의 구간.
    - * PI (예측구간): **개별 관측값($Y_h$)**의 구간.
    - * PI가 항상 더 넓다 (이유: 개별 오차항의 불확실성, 즉 **`+1`** 항이 분산에 추가됨).

- 잔차의 직교성?
    - * 기하학적 의미: $e \perp C(X)$ (잔차 벡터는 X의 열 공간과 직교).
    - * 행렬 표현: $\mathbf{X^T e = 0}$
    - * 결과: $\sum e_i = 0$ (절편이 있을 시), $\sum e_i x_i = 0$

- MLR 계수 (Partial) 해석?
    - "**다른 모든 변수들이 고정**되어 있을 때" $X_j$가 1단위 변할 때 $Y$의 평균에 미치는 순수 영향력.

- Full Rank 조건?
    - $X^T X$의 **역행렬이 존재**($\det \neq 0$)해야 함.
    - 이유: $X$의 열 간에 **다중공선성(Multicollinearity)**이 없어야 $\hat{\beta}$가 유일하게 결정됨.

## 3. Part 2: 핵심 계산 공식 (45점)

- (Q8) $X'X \to S_{xx}$, $S_{xy}$, $\bar{x}$, $\bar{y}$
    - $n = (1,1)$ 원소 ($=25$)
    - $\sum X_i = (1,2)$ 원소 ($=212.7$) $\to \bar{x} = \sum X_i / n$
    - $\sum X_i^2 = (2,2)$ 원소 ($=2026.35$)
    - $\sum Y_i = (X'y)_1$ ($=338.2$) $\to \bar{y} = \sum Y_i / n$
    - $\sum X_i Y_i = (X'y)_2$ ($=2913.73$)
    - $S_{xx} = \sum X_i^2 - n\bar{x}^2$ (또는 $\sum X_i^2 - (\sum X_i)^2 / n$)
    - $S_{xy} = \sum X_i Y_i - n\bar{x}\bar{y}$ (또는 $\sum X_i Y_i - (\sum X_i)(\sum Y_i) / n$)

- (Q8) SLR 추정량 공식?
    - $\hat{\beta}_1 = S_{xy} / S_{xx}$
    - $\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$

- (Q1) ANOVA 표 완성?
    - SST = $S_{yy}$
    - SSE = $MSE \times (n-p-1) = (\hat{\sigma})^2 \times (n-p-1)$
    - SSR = SST - SSE
    - $df_R = p$, $df_E = n-p-1$, $df_T = n-1$
    - $MSR = SSR / p$, $MSE = SSE / (n-p-1)$
    - $F = MSR / MSE$

- (Q5) $t$-검정 (vs 특정값 $k$)?
    - $t = \frac{\hat{\beta}_j - k}{s.e.(\hat{\beta}_j)}$
    - (s.e. 역산: $t_{val} = \hat{\beta}_j / s.e.(\hat{\beta}_j)$)

- (Q7) $t^2 = F$ 관계?
    - SLR($p=1$)에서 $H_0: \beta_1=0$ 검정 시 $t^2 = F$
    - $F$값에서 $t$값 역산 시: $t = \pm \sqrt{F}$
    - $t$의 부호는 **$\hat{\beta}_1$의 부호**를 따라감.
