# Study Archive

경제학·통계학·컴퓨터과학을 공부하며 정리한 학부 노트입니다.

<div class="grid cards" markdown>

-   **폴더 그대로 탐색**

    학기 → 과목 → 세부 주제의 구조가 왼쪽 탐색 메뉴와 URL에 반영됩니다.

-   **본문 검색**

    과목명과 노트 본문을 한글·영문으로 검색할 수 있습니다.

-   **선별 공개**

    `contents/`는 비공개 원본 보관소이며, 가져온 문서만 사이트에 포함됩니다.

</div>
