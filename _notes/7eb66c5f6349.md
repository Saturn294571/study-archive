	- ex) 사망-혼인 정비례; -> 결혼->장수?? X. 실제론 시간 따라 우연히 동시 감소

# General expression for a time series variable
- time se. var. $Y_t=$ (stat. X 부분) + (stat. O 인 부분)
	- stat. O 부분 : ARMA OK
		- stat. 조건 : $E(y_t), var(y_t)\to$일정?
	- stat. X 부분 : 걍 두면 regression에 문제 O
		- TSP(Trend Stationary Process) : 트렌 X -> stat. O
			- deterministic trend : 결정론적 설명O 변수; t에 따라 정확히 결정
			- $y_t=\alpha_0+\alpha_1 t+u_t\to\hat{\alpha_0},\hat{\alpha_1}\Rightarrow (\star)(y_t-\hat{\alpha_0}-\hat{\alpha_1} t)$ : stationary
				- stat. : $u_t$ : stat. -> $\mu_u,\sigma^2_u$ OK
				- non stat. : t에 따라 $\alpha_0+\alpha_1$ 평균 변화.
					- $E(u_t)=0$ 고려? -> t 고려시, stat. O($(\star)$ 형태 stat.)
		- DSP(Difference Stationary Process) : 차분 -> stat. O
			- stochastic trend : 확률적 추세
			- 1st order 차분 -> trend X
	- ex) real GDP : 경제성장->$Y^*\uparrow\uparrow$, 경기변동시 침체가 왜?, 어떻게 끌올?
		- $Y_t=\phi Y_{t-1}+\epsilon_t$ :
			- $|\phi|=1\to (Y_t:\text{permanent})$; 충격=AS충격
			- $|\phi|<1\to (Y_t:\text{transitory})$; 충격 =AD 충격
		- (대공황 ) 케인지언 : AD shock -> $AD\uparrow\uparrow\to Y\uparrow\uparrow$ (by 재정정책)
			- (오쇼,스태그 : $\pi\uparrow,Y\downarrow$) 새고전학파 : 합기 + AS 중요
			- 새캐인즈 : $\because$ 가격경직성, 정부역할 필. -> 정책이 AD 영향
