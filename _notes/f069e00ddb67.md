## 단원별 핵심

### MLE

- MLE : data $Y$ 고정, parameter $\theta$ 바꿔 $L(\theta|Y)=f(Y;\theta)$ max
- iid : $\ell(\theta|Y)=\sum_i\ln f(y_i;\theta)$
- FOC/score : $S(\theta)=\partial\ell(\theta)/\partial\theta,\quad S(\hat\theta)=0$
- Hessian/information matrix : likelihood curvature와 estimator variance 정보
- Normal linear model : LL max = SSR min
	- $\hat\beta_{MLE}=\hat\beta_{OLS}$
	- $\hat\sigma^2_{MLE}=SSR/n$, $\hat\sigma^2_{OLS}=SSR/(n-k)$
- Time series MLE : $y_t$ 독립 X -> joint density를 conditional density product로 분해
- AR(1) example : $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$
- Conditional MLE : initial density 생략 / exact MLE : initial density 포함
- Numerical optimization : closed-form FOC 어려우면 Newton-Raphson 등 사용
- Large sample : consistent, asymptotically normal, efficient

### GARCH

- 목적 : 수익률 평균보다 residual의 조건부 분산 $\sigma_t^2$가 어떻게 진화하는지 모형화
- 금융자료 특징 : time-varying volatility, volatility clustering, fat tail
- ARCH : $\sigma_t^2=\alpha_0+\sum_i\alpha_i\epsilon_{t-i}^2$
- GARCH : 과거 shock + 과거 volatility 자체
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- $\alpha$ : new shock effect
	- $\beta$ : volatility persistence
	- $\alpha+\beta$ : persistence
- 조건 : $\omega>0,\alpha,\beta\ge0,\alpha+\beta<1$
- 장기분산 : $E(\sigma_t^2)=\omega/(1-\alpha-\beta)$
- MLE 이유 : $\sigma_t^2$는 latent/time-varying object -> conditional PDF로 likelihood 구성
- Fat tail : conditional normal + time-varying variance -> normal mixture -> 양쪽 tail 두꺼움
- Asymmetry(light) : 기본 GARCH는 $\epsilon^2$라 sign 구분 X; EGARCH/TGARCH는 leverage effect용 확장

### VAR

- VAR : 여러 stationary time series를 vector로 묶은 AR
- 이유 : 경제 shock는 여러 변수에 동시에 전파 -> single equation보다 system 필요
- Reduced-form VAR(p) : $Y_t=c+A_1Y_{t-1}+\cdots+A_pY_{t-p}+u_t$
- VAR 자체 추정은 eq별 OLS 가능, 어려운 건 structural shock 해석
- Structural form : $B_0Y_t=b+\sum_iB_iY_{t-i}+\varepsilon_t$
- 연결 : $u_t=B_0^{-1}\varepsilon_t,\quad \Sigma_u=B_0^{-1}D(B_0^{-1})'$
- $u_t$는 contemporaneous correlation 가능 -> structural shock으로 바로 해석 X
- Identification : reduced-form information만으로 structural parameters 복원 불가 -> restriction 필요
- Cholesky : $\Sigma_u=PP'$, $u_t=P\varepsilon_t$
	- 위 변수 : 아래 변수 shock에 contemporaneously 반응 X
	- 아래 변수 : 위 변수 shock에 contemporaneously 반응 O
	- ordering = 경제적 가정
- IRF : structural shock 1회가 미래 $Y_{t+h}$에 미치는 반응 경로
- FEVD(light) : forecast error variance에서 각 shock의 기여도 직관만

### 1번. MLE와 Time Series Likelihood

다음 AR(1) 모형을 고려하라.

$$
y_t=c+\phi y_{t-1}+\epsilon_t,\qquad \epsilon_t\sim i.i.d.\ N(0,\sigma^2),\quad |\phi|<1
$$

1. MLE에서 PDF와 likelihood의 해석 차이를 설명하고, 왜 log-likelihood를 사용하는지 설명하라.
2. $y_1$을 given으로 둘 때 conditional log-likelihood를 작성하라.
3. conditional MLE와 exact MLE의 차이를 초기분포 관점에서 설명하라.
4. normal linear model에서 $\hat\beta_{MLE}=\hat\beta_{OLS}$가 되는 이유와 $\hat\sigma^2$ 추정량 차이를 설명하라.
5. Score, Hessian, information matrix가 각각 MLE에서 어떤 역할을 하는지 설명하라.

### 2번. GARCH(1,1)와 금융수익률

어떤 수익률 자료에 대해 다음 모형을 설정하였다.

$$
R_t=\mu+\epsilon_t,\qquad \epsilon_t|I_{t-1}\sim N(0,\sigma_t^2)
$$

$$
\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2
$$

1. 이 모형이 설명하려는 금융자료의 특징을 `time-varying volatility`와 `volatility clustering` 중심으로 설명하라.
2. $\omega,\alpha,\beta$의 의미와 $\omega>0,\alpha,\beta\ge0,\alpha+\beta<1$ 조건의 의미를 설명하라.
3. $\alpha+\beta$가 1에 가까울 때 volatility shock이 어떻게 지속되는지 설명하라.
4. 조건부 정규분포를 가정해도 unconditional return distribution이 fat tail을 보일 수 있는 이유를 설명하라.
5. GARCH를 OLS가 아니라 MLE로 추정하는 이유를 설명하고, 추정 절차를 간단히 쓰라.

### 3번. VAR, Identification, Cholesky, IRF

다음 structural VAR(1)을 고려하라.

$$
B_0Y_t=b+B_1Y_{t-1}+\varepsilon_t,\qquad E(\varepsilon_t\varepsilon_t')=D
$$

1. 위 structural VAR를 reduced-form VAR로 변환하고, $u_t$와 $\varepsilon_t$의 관계를 쓰라.
2. Reduced-form residual $u_t$를 structural shock으로 바로 해석할 수 없는 이유를 설명하라.
3. 왜 identification restriction이 필요한지 reduced-form information과 structural parameter의 관계로 설명하라.
4. Cholesky identification의 핵심 가정과 ordering의 경제적 의미를 설명하라.
5. IRF가 무엇을 보여주는지 설명하고, stable VAR에서 shock effect가 시간이 지나며 0으로 수렴해야 하는 이유를 설명하라. FEVD는 한 줄 직관만 덧붙여라.

## 3회차 자기채점 기준

- GARCH : volatility clustering, $\alpha+\beta$, fat tail, MLE 이유를 빠뜨리지 않았는가?

### 1-5)

Score matrix :

$S(\theta|Y)=\frac{\partial \ln L}{\partial \theta}$

L-L의 FOC 조건.

Hessian matrix :

$H(\theta|Y)=\frac{\partial^2 \ln L}{\partial\theta\partial\theta'}$

극대·극소 조건을 판정.

peak가 flat한지 sharp한지 판단,

또한 Newton–Raphson 방법에서 사용.

Information matrix :

$I(\theta)=-E[H(\theta)]$

$I(\theta)^{-1}$을 분산–공분산 행렬로 사용하며,

Cramer–Rao lower bound와 관련.

$I(\theta)$가 클수록 variation이 작으므로

$Var(\hat{\theta})$가 낮아 추정치의 효율성이 높음.

## 3회차 채점 및 오답노트

### 총평

- MLE는 많이 회복됨. 특히 score/Hessian/information matrix 설명은 좋음.
- GARCH는 직관은 잡혔지만 $\alpha,\beta$ 의미와 MLE 이유가 덜 정확함.
- VAR는 3-2를 문제와 다르게 답했고, 3-4 Cholesky가 비어 있어 큰 감점.

### 1번 오답노트

1) PDF vs likelihood / log
- PDF vs likelihood 해석은 맞음.
- log-likelihood 사용 이유 보완 : log는 단조증가라 argmax가 같고, product를 sum으로 바꿔 계산/미분이 쉬워진다.

2) Conditional LL
- 형태는 맞음. 단, AR(1) conditional LL은 $t=2,\cdots,T$ 기준으로 쓰는 것이 안전.
- 정답형 : $\ell_c=-\frac{T-1}{2}\ln(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum_{t=2}^{T}(y_t-c-\phi y_{t-1})^2$.

3) Conditional vs Exact MLE
- 뒤집힘.
- Conditional MLE : $y_1$ given으로 보고 $f(y_1;\theta)$ 생략.
- Exact MLE : stationary 초기분포 $f(y_1;\theta)$ 포함.

4) MLE vs OLS
- 맞음. 핵심은 normal LL max = SSR min.

5) Score / Hessian / Information
- 좋음. 시험장 답안으로 충분.

### 2번 오답노트

1) 설명 대상
- 방향 맞음.
- volatility clustering은 더 직접적으로 “large changes followed by large changes, small changes followed by small changes”라고 쓰면 좋음.

2) $\omega,\alpha,\beta$와 조건
- $\omega$는 절편/장기 평균분산의 numerator이지 “최소 변동성”이라고만 쓰면 애매함.
- $\alpha$ : 직전 shock size effect.
- $\beta$ : 과거 volatility persistence.
- $\omega>0,\alpha,\beta\ge0$ : $\sigma_t^2$ 음수 방지.
- $\alpha+\beta<1$ : covariance stationarity / finite unconditional variance.

3) $\alpha+\beta$
- persistence/mean reversion 설명은 맞음.
- near unit root 표현은 가능하나, GARCH에서는 $\alpha+\beta\approx1$이면 IGARCH에 가까워져 volatility shock이 거의 사라지지 않는다고 쓰는 게 더 정확.

4) Fat tail
- 핵심 방향은 맞음.
- 보완 문장 : conditional normal이라도 $\sigma_t^2$가 time-varying하므로 unconditional distribution은 여러 variance의 normal mixture가 되고, 그 결과 양쪽 tail이 정규분포보다 두꺼워진다.

5) MLE 이유
- 핵심 수정 : latent인 것은 $\epsilon_t$보다 $\sigma_t^2$.
- GARCH는 $\sigma_t^2$가 직접 관측되지 않고 recursion으로 생성되는 time-varying object라 conditional density를 이용해 likelihood를 만들고 MLE로 추정한다.
- 절차 : mean eq. 추정 -> residual -> GARCH recursion -> conditional PDF -> LL maximize.

### 3번 오답노트

1) Structural -> reduced form
- 맞음.
- 추가하면 $A_0=B_0^{-1}b,\ A_1=B_0^{-1}B_1,\ u_t=B_0^{-1}\varepsilon_t$.

2) 왜 $u_t$는 structural shock이 아닌가
- 답안이 문제와 다름.
- 정답 : $u_t$는 reduced-form residual이고 구성요소끼리 contemporaneous correlation 가능. 따라서 경제적으로 독립적인 policy/demand/supply shock으로 바로 해석할 수 없다.

3) Identification restriction
- 방향 맞음.
- 보완 : reduced-form에서 관측되는 것은 $\Sigma_u$와 reduced coefficients뿐이고, structural parameters는 더 많으므로 normalization/restriction이 필요.

4) Cholesky
- 빈칸.
- 정답형 : $\Sigma_u=PP'$에서 $P$를 lower triangular로 두고 $u_t=P\varepsilon_t$로 structural shock을 복원한다. 위 변수는 아래 변수 shock에 contemporaneously 반응하지 않고, 아래 변수는 위 변수 shock에 contemporaneously 반응 가능하다. ordering 자체가 경제적 가정.

5) IRF / stable VAR / FEVD
- IRF 직관은 부분적으로 맞음.
- 보완 : IRF는 structural shock 1회가 미래 $Y_{t+h}$에 미치는 반응 경로. stable VAR에서는 eigenvalue가 안정조건을 만족해 $A_1^h\to0$이므로 shock effect가 0으로 수렴.
- FEVD(light) : forecast error variance 중 각 structural shock이 설명하는 비중.
