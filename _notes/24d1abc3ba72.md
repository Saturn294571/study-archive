# 계량경제학 D-Day 최종 인출 노트

## 1. 약점 & 주의사항

- **F-검정 공식 (모형 비교):** 분모는 **$MSE(Full)$** 임. 분자는 **$RSS_R - RSS_{UR}$** (또는 $SSE_R - SSE_F$). (값이 음수가 나올 수 없음).
- **자유도(df) 계산:** 오차항($\hat{\sigma}^2$, t-검정, F-검정 분모)의 df는 **$n - K$** (샘플 수 - **총** 추정 계수 개수(절편 포함)).
- **다중공선성 vs OVB:** 원인과 결과를 명확히 구분.
    - **다중공선성:** $X$들 간의 문제 $\to \hat{\beta}$ 추정 불가 또는 분산 증가.
    - **OVB:** 모형 설정 오류 (중요 변수 누락) $\to \hat{\beta}$가 **편향**됨 ($E(\hat{\beta}) \neq \beta$).

---

## 2. 계량경제학 5단계 논리 흐름

- **1. 모집단 설정:** 분석 대상, 모수($\beta$), 가정(e.g., $E(e|X)=0$) 정의.
- **2. 추정량 유도:** 모수를 추정할 공식($\hat{\beta}$) 도출 (e.g., OLS 원리).
- **3. 성질 확인:** 추정량($\hat{\beta}$)이 좋은 성질(불편성, 효율성 등)을 갖는지 증명.
- **4. 분포 확인:** 추정량($\hat{\beta}$)의 확률 분포 파악 (e.g., CLT, $\chi^2$, t, F).
- **5. 가설 검정:** 분포를 이용해 모수($\beta$)에 대한 가설 검증.

---

## 3. 핵심 정의 & 개념 (말로 설명하기)

- **불편성(Unbiasedness):** 수식($E(\hat{\theta})=\theta$) 말고 의미는?
    - "**반복된 표본 추출** 하에서 추정량의 평균이 참값(모수)과 같음".
- **추정량(Estimator) vs 추정치(Estimate):** 차이는?
    - **추정량:** 공식, 함수, 확률변수 (데이터 얻기 전).
    - **추정치:** 실제 계산된 값, 상수 (데이터 얻은 후).
- **검정 통계량 조건 (2가지):**
    - 1. $H_0$ 하에서 **계산 가능**. 2. $H_0$ 하에서 **분포를 앎**.
- **F-검정 원리:** 무엇을 비교하는가?
    - **제약 모형($H_0$ 가정)과 비제약 모형의 잔차 제곱합($RSS$)**을 비교. ($H_0$가 틀리면 $RSS_R$이 $RSS_{UR}$보다 현저히 커짐).
- **Adj. $R^2$ 필요성 & 원리:**
    - $R^2$는 $K$ 증가 시 항상 증가. Adj. $R^2$는 **자유도($n-K$) 페널티**로 보정. (**절약의 원리**).

## 4. 핵심 유도 아이디어 (손으로 풀기)

- **$\hat{\mu}$ OLS 유도(Pop-EQ):**
    - $\min \sum(Y_i - \mu)^2$ $\to \frac{\partial}{\partial \mu}=0$ $\to \sum(Y_i - \hat{\mu})=0$ $\to \hat{\mu}=\bar{Y}$.
- **단순 회귀 OLS 유도:**
    - $\min \sum(Y_i - \hat{\beta}_1 - \hat{\beta}_2 X_i)^2$
    - $\frac{\partial}{\partial \hat{\beta}_1}=0 \to \sum \hat{e}_i = 0$ ($\to \hat{\beta}_1 = \bar{Y} - \hat{\beta}_2 \bar{X}$)
    - $\frac{\partial}{\partial \hat{\beta}_2}=0 \to \sum \hat{e}_i X_i = 0$ ($\to \hat{\beta}_2 = Cov/Var$ 공식 유도 가능)
- **단순 회귀 $\hat{\beta}_0$ 불편성 증명:**
    - $\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$ 공식에서 시작.
    - $E[\cdot]$ 취하고 기대값 선형성 이용 $\to E[\hat{\beta}_0] = E[\bar{Y}] - E[\hat{\beta}_1]\bar{X}$. (X는 비확률적)
    - $E[\bar{Y}] = \beta_0 + \beta_1 \bar{X}$ (모집단 평균식) 와 $E[\hat{\beta}_1]=\beta_1$ (기울기 불편성) 대입.
    - $\implies E[\hat{\beta}_0] = (\beta_0 + \beta_1 \bar{X}) - \beta_1 \bar{X} = \beta_0$.
- **단순 회귀 $\hat{\beta}_1$ 분산 유도:**
    - $\hat{\beta}_1 = \beta_1 + \sum t_i \epsilon_i$ 형태($t_i = \frac{x_i^*}{S_{xx}}$)에서 시작.
    - $\text{Var}(\hat{\beta}_1) = \text{Var}(\beta_1 + \sum t_i \epsilon_i) = \text{Var}(\sum t_i \epsilon_i)$.
    - 오차항 가정($\text{Var}(\epsilon_i)=\sigma^2$, $\text{Cov}(\epsilon_i, \epsilon_j)=0$) 이용 $\to \sum t_i^2 \text{Var}(\epsilon_i) = \sigma^2 \sum t_i^2$.
    - $\sum t_i^2 = \frac{1}{S_{xx}}$ (이전에 유도한 성질) 대입.
    - $\implies \text{Var}(\hat{\beta}_1) = \frac{\sigma^2}{S_{xx}} = \frac{\sigma^2}{\sum (X_i - \bar{X})^2}$.
- **단순 회귀 $\hat{\beta}_1$ 불편성 증명:**
    - $\hat{\beta}_1 = \beta_1 + \frac{\sum (X_i-\bar{X})e_i}{\sum (X_i-\bar{X})^1}$ 형태로 변형.
    - $E[\cdot]$ 취하고 $E[e_i|X]=0$ 가정 사용 $\to E[\hat{\beta}_1] = \beta_1$.

- **단순 회귀 $\hat{\sigma}^2$ 불편성 증명:**
    - SLR에서 $\hat{\sigma}^2 = \frac{\sum \hat{e}_i^2}{n-2}$ ($K=2$).
    - 핵심 아이디어는 MLR과 동일: $\hat{e}'\hat{e} = \epsilon^T M \epsilon$, $E[\hat{e}'\hat{e}] = \sigma^2 \text{Trace}(M) = \sigma^2 (n-2)$.
    - $\implies E[\hat{\sigma}^2] = E[\frac{\hat{e}'\hat{e}}{n-2}] = \sigma^2$.
- **단순 회귀 $\hat{\sigma}^2$ 분산 (Var), 평균:**
    - $\hat{\sigma}^2 = \frac{\sigma^2}{n-2} \left( \frac{\hat{e}'\hat{e}}{\sigma^2} \right)$    $\frac{(n-1)\hat{\sigma^2}}{\sigma^2}\sim\chi^2(n-1)\implies E(\frac{(n-1)\hat{\sigma^2}}{\sigma^2})=(n-1), E(\hat{\sigma^2})=\sigma^2$
    - $\frac{\hat{e}'\hat{e}}{\sigma^2} = \frac{\epsilon^T M \epsilon}{\sigma^2} \sim \chi^2_{n-2}$ (SSE 분포 결과 활용).
    - $\text{Var}(\chi^2_k) = 2k$ 성질 이용.
    - $\implies \text{Var}(\hat{\sigma}^2) = \left(\frac{\sigma^2}{n-2}\right)^2 \text{Var}(\chi^2_{n-2}) = \left(\frac{\sigma^2}{n-2}\right)^2 (2(n-2)) = \frac{2\sigma^4}{n-2}$.
---
- **다중 회귀 $\hat{\beta}$ OLS 유도:**
    - $\min (Y-X\beta)^T(Y-X\beta)$ $\to \frac{\partial}{\partial \beta}=0$ $\to X'X\hat{\beta}=X'Y$ (정규방정식) $\to \hat{\beta}=(X'X)^{-1}X'Y$.
- **다중 회귀 $\hat{\beta}$ 불편성 증명:**
    - $\hat{\beta} = \beta + (X'X)^{-1}X'e\quad E(\cdot)$ 양변에 취하면 끝
- **다중 회귀 $\text{Cov}(\hat{\beta})$ (분산-공분산 행렬) 유도:**
    $cov(\hat{\beta})=E[(\hat{\beta}-\beta)(\hat{\beta}-\beta)^\intercal] = \cdots = \sigma^2(X'X)^{-1}$

- **다중 회귀 $\hat{\sigma}^2$ 불편성 증명 아이디어:**
    - $\hat{e}'\hat{e} = \epsilon^T M \epsilon$ ($M=I-P$)
    - $E[\hat{e}'\hat{e}] = E[\epsilon^T M \epsilon] = \sigma^2 \text{Trace}(M) = \sigma^2 (n-K)$.
    - $E[\hat{\sigma}^2] = E[\frac{\hat{e}'\hat{e}}{n-K}] = \sigma^2$.

- $SE(\hat{\beta}_j) = \hat{\sigma}\sqrt{a_{ii}};\quad\hat{\sigma}^2=SSE/(n-k)=\frac{e'e}{n-k}$
