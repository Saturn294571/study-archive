## 10. Inventory

### Inventory Big Picture

- Inventory : 판매목적 보유 goods -> 판매 전 asset(B/S), 판매 후 COGS(I/S)
- 핵심 2문제 : quantity(몇 개 팔림/남음?) + unit cost(단가 얼마?)
- Historical cost : original purchase cost 기준, selling price/market value X
- Matching principle : revenue 인식 시점에 관련 cost도 COGS로 인식
- Cost split : $BI + Net\ purchases = COGAS = COGS + EI$
	- COGAS(cost of goods available for sale) : 팔 수 있었던 총 원가
	- COGS : 팔린 부분 -> I/S expense
	- EI(ending inventory) : 안 팔린 부분 -> B/S asset

### Purchase Cost

- Purchase cost : $invoice\ price + freight\text{-}in + insurance + taxes/duties + commissions - returns/allowances - discounts$
- Freight-in : 매입 운송비 -> inventory cost에 포함 O
- Freight-out : 판매 운송비 -> selling expense(SG&A), inventory cost X
- Purchase discount : `2/10, n/30` -> 10일 내 지급시 2% 할인, 아니면 30일 내 전액
- Purchase return/allowance : 하자/반품/가격조정 -> purchase cost 감소

### Quantity System

- Perpetual inventory system(계속기록법) : direct deduction, Inventory account 실시간 +/-
	- 고가/개별 추적 쉬운 goods에 적합
	- purchase 시 Inventory 증가, sale 시 Inventory 감소 + COGS 인식
	- 장부상 공식 : $BI + purchases - COGS = EI$
- Periodic inventory system(실지재고조사법) : indirect deduction, purchase 관련 temporary accounts 사용
	- 저가/대량 goods에 적합
	- sale 시 매출만 기록, COGS/Inventory 감소 기록 X
	- 기말 physical count로 EI 확정 -> COGS 역산
	- 공식 : $BI + Purchases + Freight\text{-}in - Purchase\ returns/allowances - Purchase\ discounts = COGAS,\quad COGS=COGAS-EI$

### Journal Entries

- Purchase on account
	- Perpetual : Dr Inventory / Cr A/P
	- Periodic : Dr Purchases / Cr A/P
- Freight-in
	- Perpetual : Dr Inventory / Cr Cash
	- Periodic : Dr Freight-in / Cr Cash
- Purchase return/allowance
	- Perpetual : Dr A/P / Cr Inventory
	- Periodic : Dr A/P / Cr Purchase returns/allowances
- Purchase discount
	- Perpetual : Dr A/P / Cr Cash, Inventory
	- Periodic : Dr A/P / Cr Cash, Purchase discounts
- Sale
	- 공통 : Dr A/R(or Cash) / Cr Sales
	- Perpetual 추가 : Dr COGS / Cr Inventory
	- Periodic : sale 시 COGS entry X -> 기말에 계산

### Cost Flow Assumption

- 문제 : 다른 단가로 여러 번 매입 -> 팔린 goods의 unit cost를 무엇으로 볼 것인가?
- Physical flow vs cost flow : 실제 물건 흐름과 회계상 원가흐름은 같을 필요 X
- Specific identification : 실제 팔린 개별 item의 실제 원가 추적
	- 자동차/부동산/고가·저빈도·비대체 goods
	- 정확하지만 대량 goods에는 비효율
- FIFO(first-in, first-out) : 먼저 산 원가 -> COGS, 나중 산 원가 -> EI
	- EI가 recent cost 반영
	- 가격상승기 : COGS 낮음 -> GP/NI 높음 -> tax 높음
	- Periodic FIFO : physical count로 EI unit 확인 -> 가장 최근 layer부터 EI 배정 -> COGS 역산
- Average cost : 평균단가 하나로 COGS/EI 배정
	- $\bar c = \dfrac{COGAS}{units\ available},\quad COGS=units\ sold \times \bar c,\quad EI=units\ left \times \bar c$
	- 강의 포인트 : 평균의 의미 위주, periodic/perpetual average 차이는 깊게 X
- LIFO : IFRS 허용 X -> 강의/시험 핵심 X
- Consistency : method는 기간 간 비교 위해 일관 사용 선호, 변경 자체는 가능

### 기말 계산 흐름

- Perpetual : 거래마다 Inventory/COGS 업데이트 -> 기말 EI는 장부 잔액 중심
- Periodic : 매입 관련 계정 모음 -> physical count로 EI 수량 확정 -> cost flow method로 EI 금액 -> $COGS=COGAS-EI$
- FIFO periodic 예 : EI 수량을 먼저 잡고 최신 매입층부터 채움
- Average periodic 예 : 전체 원가/전체 수량으로 평균단가 1개 계산
- 핵심 함의 : 같은 physical goods여도 method에 따라 COGS/EI/NI 달라짐

### 백지복원

- Inventory 왜 asset? : 아직 판매 X -> future benefit, 판매 시 revenue와 matching -> COGS
- Inventory 장의 두 축 : quantity system + cost flow assumption
- Purchase cost 구성 : invoice + 매입부대비용 - 할인/환입/에누리
- Freight-in/out 구분 : 들어올 때 원가, 나갈 때 판매비
- Perpetual vs Periodic : Inventory 직접 +/- vs Purchases temp 후 기말조정
- Sale entry 차이 : perpetual은 매출 + COGS 동시, periodic은 매출만
- Periodic COGS 복원 : $BI + net\ purchases = COGAS,\ EI\ physical\ count,\ COGS=COGAS-EI$
- FIFO 직관 : 오래된 원가가 I/S로, 최신 원가가 B/S로
- 가격상승기 FIFO 함의 : COGS↓ -> gross profit↑ -> net income↑ -> tax↑
- Average 직관 : 여러 purchase layer를 하나의 평균 원가로 섞음
