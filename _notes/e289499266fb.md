## 6.MLE
### Maximum Likelihood Estimation
- Model : $y_i=\mu+e_i$
    - OLS Sample EQ : $y_i=\hat{\mu}+\hat{e}_i$
    - obj func of OLS(SSE) : $\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}\hat{e}_i^{2}=\underset{\hat{\mu}}{\text{argmin}}\sum_{i=1}^{N}(y_i-\hat{\mu})^{2}$
    - OLS estimator $\mu$ : $\hat{\mu}=\frac{1}{N}\sum_{i=1}^N y_i$
        - $\sigma^2$ : $\hat{\sigma}^2=\frac{1}{N-1}\sum_{i=1}^N (y_i-\hat{\mu})^2(=\hat{e}_i^2)$
- Likelihood value 정의 : 특정 모수하에서, 모집단으로부터 생성된 샘플 데이터가 나올 가능도
    - ex) $f(y;\theta)=(2\pi\sigma^2)^{-1/2}\exp\{-\frac{1}{2\sigma^2}(y-\mu)^2\}\quad\theta=\{\mu,\sigma^2\}$
        - 샘플링 이전엔 y를 모름. 확변. $\mu,\sigma^2$주어졌다면, y에 대한 확률 추정 가능
    - PDF : 확률 추정은 PDF를 통해 가능
        - 1) $Pr(y>\mu)=\int_{\mu}^{\infty}f(y;\theta)dy=0.5$ 2) $Pr(10>y>4)=\int_{4}^{10}f(y;\theta)dy$
            - (joint)JPDF of $\{y_1,\cdots,y_N\}=f(y_1,\cdots, y_N;\theta)\quad \theta=\{\mu,\sigma^2\}$
            - Marginal PDF of $y_i=f(y_i;\theta)$
        - r.v. A,B가 독립 $\to f(A \cap B)=f(A)f(B)$ : $f(Y;\theta)=\prod_{i=1}^N f(y_i;\theta)\quad Y=(y_1\cdots y_N)^T$
            - if $y_i\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$, then $f(Y;\theta)=(2\pi\sigma^2)^{-N/2}\exp\{-\frac{1}{2\sigma^2}\sum_i(y_i-\mu)^2\}$
- Likelihood function : $L(\mu,\sigma^2|y_1,\cdots,y_N)=f(y_1,\cdots,y_N;\mu,\sigma^2)$
    - MLE의 목적함수는 $\underset{\mu,\sigma^2}{\text{argmax}}\ln L(\mu,\sigma^2|Y)$
        - $\ln()$ : 단조증가? -> 합성해도 해가 달라지지 X.
    - FOC of MLE : $\frac{\partial\ln L(\theta|Y)}{\partial\theta}=0$ : MLE는 FOC를 통해 모수들을 추정
- MLE example : $y_i=X_i'\beta+e_i$
    1) $y_i$ 분포 : $y_i\sim N(X_i'\beta,\sigma^2)$
    2) $f(y_i)$? ($y_i$의 pdf?) : $f(y_i;\beta,\sigma^2)=1/\sqrt{2\pi\sigma^2}\exp\{-\frac{(y_i-X_i'\beta)^2}{2\sigma^2}\}$
    3) Y의 JPDF? : $f(Y;\beta,\sigma^2)=\prod_{i=1}^N f(y_i;\beta,\sigma^2)=(2\pi\sigma^2)^{-\frac{n}{2}}\exp\{-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{2\sigma^2}\}$
    4) $L\to\ln L$ : $\ln L(\beta,\sigma^2|Y)=-\frac{n}{2}\ln 2\pi-\frac{n}{2}\ln\sigma^2-\frac{\sum_{i=1}^N (y_i-X_i'\beta)^2}{2\sigma^2}$
    5) $\frac{\partial\ln L}{\partial \theta}=0$ : $\to\hat{\beta}_{\text{MLE}}=\hat{\beta}_{\text{OLS}}\quad \text{but},\hat{\sigma^2}_{\text{MLE}}=\frac{1}{n}\sum\hat{e}_i^2$
### MLE generalization
- $\hat{\theta}_{\text{MLE}}=\underset{\theta}{\text{argmax}}\ln L(\theta|Y)$
- 랜덤 샘플링시 LL(log likelihood) : $\ln L(\theta|Y)= \ln(\prod_{i=1}^{n}f(y_i;\theta))=\sum_{i=1}^{n}\ln f(y_i;\theta)$
- FOC of MLE : $\forall \theta_i \in\theta=\{\theta_1,\cdots,\theta_k\},\quad\frac{\partial \ln L(\hat{\theta}_{MLE}|Y)}{\partial \theta_i}=0$
- score vector : $S(\theta|Y)=\frac{\partial \ln L(\theta|Y)}{\partial \theta},\quad S(\hat{\theta}_{MLE}|Y)=0$
- LL func for linear reg model : $\ln L(\theta|y,X)=-\frac{n}{2}\ln(2\pi)-\frac{n}{2}\ln(\sigma^2)-\frac{1}{2\sigma^2}(y-X\beta)'(y-X\beta)\implies\frac{\partial \ln L(\theta|y,X)}{\partial\theta}=0$
    - $\hat{\beta}_{MLE}=(X'X)^{-1}X'y=\hat{\beta}_{OLS}$
    - but, $\hat{\sigma}^2_{MLE}=\frac{1}{n}(y-X\hat{\beta}_{MLE})'(y-X\hat{\beta}_{MLE})\neq\hat{\sigma}^2_{OLS}=\frac{1}{n-k}(y-X\hat{\beta}_{OLS})'(y-X\hat{\beta}_{OLS})$
        - 단, n의 크기가 커질수록 서로간 오차가 미미해짐

### MLE for series data
- IID ts의 LL : $\ln L(\theta|y)=\sum_{t=1}^{T}\ln f(y_t;\theta)$
- 시계열의 경우 오차가 IID X. (독립X)
    - $\therefore$ 교사건 확률을 조건부 확률로 표현 : $p(A\cap B)=p(B|A)p(A);\quad P(A\cap B\cap C) = p(C|A\cap B)p(B|A)p(A)$
    - ts에선, : $f(y_T,\cdots,y_1;\theta)=\{\prod_{t=p+1}^{T}f(y_t|I_{t-1};\theta)\}\cdot f(y_p,\cdots,y_1;\theta)$
        - $I_{t}=\{y_t,\cdots,y_1\}$ : t시점의 가능한 정보
        - $y_p,\cdots,y_1$ : p개의 초기 관측치
        - $\therefore$ LL 에서 : $\ln L(\theta|y)=\sum_{t=p+1}^T \ln f(y_t|I_{t-1};\theta)+\ln f(y_p,\cdots,y_1;\theta),\quad \hat{\theta}_{MLE}= \argmax_\theta \ln L(\theta|y)$
        - hint : 과거 $I_{t-1}$로 설명된 부분 제거 -> 새 innovation만 density로 평가
### MLE for AR(1) model
- sta.한 AR(1) 모델 : $y_t=c+\phi y_{t-1}+\epsilon_t;\quad \epsilon_t\overset{IID}{\sim}N(0,\sigma^2)|\phi|<1$
    - $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$
    - conditional LL : $\ln L_c(\theta|y)=\sum_{t=2}^{T}\left[-\frac12\ln(2\pi)-\frac12\ln\sigma^2-\frac{(y_t-c-\phi y_{t-1})^2}{2\sigma^2}\right]$
    - 초기값 $y_1$ 처리 : conditional MLE는 $f(y_1)$ 생략; exact MLE는 $f(y_1;\theta)$ 포함
    - sta. hint : $|\phi|<1,\quad E(y_t)=\frac{c}{1-\phi},\quad Var(y_t)=\frac{\sigma^2}{1-\phi^2}$
### MLE for ARMA(p,q)
- ARMA(p,q) : $y_t=c+\sum_{i=1}^{p}\phi_i y_{t-i}+\epsilon_t+\sum_{j=1}^{q}\theta_j\epsilon_{t-j},\quad \epsilon_t\sim N(0,\sigma^2)$
    - 핵심 : $y_t|I_{t-1}\sim N(\mu_{t|t-1},\sigma^2)$
    - $\mu_{t|t-1}=c+\sum_i\phi_i y_{t-i}+\sum_j\theta_j\epsilon_{t-j}$
    - LL : $\ln L_c=\sum_{t=m+1}^{T}\ln f(y_t|I_{t-1};\theta),\quad m=\max(p,q)$
    - AR part : 과거 $y$ 직접 관측 O / MA part : 과거 $\epsilon$ 관측 X -> recursion/초기값 필요
    - 함의 : 식은 regression처럼 보여도 $\epsilon_{t-j}$가 모수 의존 -> closed form 보통 X
### Newton-Raphson method & numerical optimazation
- 왜 필요? : 복잡한 ML은 FOC 손풀이/closed form X -> 컴퓨터가 LL surface에서 peak search
- global vs local max
    - global max : 전체 구간 최고점
    - local max : 주어진 초기값/탐색구간 근처 최고점
    - 실증 hint : initial value/grid 바꿔보기; 말 안 되는 parameter range 주의
- Newton-Raphson : 현재점에서 gradient+curvature로 다음점 update
    - $\theta^{(k+1)}=\theta^{(k)}-\left[H(\theta^{(k)})\right]^{-1}S(\theta^{(k)})$
    - $S(\theta)=\partial\ln L/\partial\theta$ : score(기울기)
    - $H(\theta)=\partial^2\ln L/\partial\theta\partial\theta'$ : Hessian(곡률)
    - max에서 $S(\hat\theta)=0$, $H(\hat\theta)$ negative definite
- 정보행렬 : $I(\theta)=-E[H(\theta)]$
    - curvature 큼 -> peak sharp -> estimator var 작음
    - curvature 작음 -> peak flat -> estimator var 큼

### MLE asymptotic properties
- large sample에서 MLE
    1) consistent : $\hat\theta_{MLE}\overset{p}{\to}\theta_0$
    2) asym. normal : $\sqrt{n}(\hat\theta-\theta_0)\overset{d}{\to}N(0,I(\theta_0)^{-1})$
    3) asym. efficient : large sample에서 var. 작음(Cramer-Rao lower bound)
- 강의 직관 : sample↑ -> 추정분포 좁아짐; normal approx 가능; information matrix inverse가 분산
- OLS와 관계
    - classical linear normal model -> $\hat\beta_{MLE}=\hat\beta_{OLS}$
    - $\hat\sigma^2_{MLE}=SSR/n,\quad \hat\sigma^2_{OLS}=SSR/(n-k)$ -> small sample 차이, $n$ 커지면 미미

### 백지복원
- MLE : data $Y$ 고정, parameter $\theta$ 바꿔 $L(\theta|Y)=f(Y;\theta)$ max. PDF/JPDF와 수학형태 같지만 해석 방향 반대. iid면 $\ln L=\sum_i\ln f(y_i;\theta)$; ts dep. 있으면 chain rule로 $\ln L=\sum_t\ln f(y_t|I_{t-1};\theta)+initial$. AR(1)은 $y_t|I_{t-1}\sim N(c+\phi y_{t-1},\sigma^2)$라 conditional LL 구성. ARMA는 MA error가 관측 X라 recursion 필요, closed form 대개 X -> Newton-Raphson 등 numerical opt. 사용. max에서 score=0, Hessian/information matrix가 곡률 및 estimator var 정보 제공. large sample MLE : consistent, asym. normal, efficient.
