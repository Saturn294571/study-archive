	- $E(Y_t)=\mu,\quad\forall t$

	- $\text{cov}(Y_t,Y_{t-j})=\gamma_j,\quad\forall t$
- Stochastic process vs Time series data
	- Stocastic : a sequence of random variable orderd in time
	- Time series : A particular realization of stochastic process(Ex-post)
# FDL(Finite Distributed Lag) Models
- 정의 : 오늘 z의 변화가 q기에 걸쳐 y에 영향을 미침 : FDL of order q
	- ex) 면세(pe)로 인한 2년간 출생률(gfr)변화 : $gfr_t=\alpha_0+\delta_0pe_{t}+\delta_1pe_{t-1}+\delta_2pe_{t-2}+u_t$
- FDL model of order q : $y_t=\alpha_0+\delta_0z_t+\cdots+\delta_qz_{t-q}+u_t$
	- Impact propensity(IP, 즉각 효과) = $\delta_0$ : 현재의 충격을 capture
	- Long run propensity(LRP, 장기 효과) = $\delta_0+\cdots+\delta_q$ : 충격 -> 모든 기간의 효과 caputre
- 테일러 준칙 : $\text{ffrate}_t=\alpha_0+\delta_0\text{inf}_t+\cdots+\gamma_0\text{gdpgap}_{t}+\cdots+u_t$
	- (ffrate : 기준금리, gdpgap=$|\text{(잠재 GDP)-(실질 GDP)}|$)
	- Q : 이 모델에 자기자신을 추가하면?($\text{ffrate}_{t-1}$ 등) -> Lagged Dependent Variables
# Models with Lagged Dependent Variables
- $y_t=\alpha_0+\beta_0y_{t-1}+u_t$ <- AR(1)
	- 가정 : $y_t$ -> stationary; $u_t$ -> 모델의 설명력이 충분, 트렌드/패턴 X($u_t\sim N(0,\sigma^2)$)
	- 테일러 준칙에 적용 : $i_t\overset{?}{\to}\pi_t$ (오늘 이자율변화 -> 오늘 인플레 변화?)
		- 정책시차의 필요 : ${inf}_t=\beta_0+\beta_1+{inf}_{t-1}+\beta_2{unem}_{t-1}+u_t=E({inf}_{t}|I_{t-1})\quad,E(u_t|I_{t-1})=0$
		- $E({inf}_{t+1}|I_t)=\beta_0+\beta_1+{inf}_{t}+\beta_2{unem}_{t}+0\quad(\because E())$
		- 예측오차 : $\eta_{t+1}=\pi_{t+1}-E(\pi_{t+1}|I_t)$

# Finite-sample Analysis of OLS for Time Series Data
- stationary의 조건 만족?
	1) linear params
	2) No perfect corlinearity
		- 설명력 너무 $\uparrow$ X, 식별에 문제 -> $var\uparrow\uparrow\to$가설 검정 hard, 1종/2종 오류 O
	3) 0 conditional mean : $E(u_t|\mathbb{X})$ -> (엄격한 외생성); 모든 시점에 대해 공선성X
		- 깨지면? -> 내생성 문제; $if\neq0\implies$biased, 내생성 O
		- 어떻게 해결? -> consistant estimating($if\,n\to\infty,\quad then\,bias\overset{p}{\to}0$)
- 테일러 준칙에서의 0 conditional mean 예시
	- $\pi_t=\alpha_0+\delta_0r_t+\delta_1r_{t-1}+\delta_2r_{t-2}+u_t$
		- 엄외가 성립? -> 오늘의 오차가 과거-현재-미래의 금리와 무관,
		- but, 설명 X인 외부 충격 개입(전쟁 등) -> $|u_t|\uparrow\uparrow$
		- $u_t>0$면 중앙은행이 $r\uparrow\uparrow\to\pi\uparrow\uparrow$
			- $\therefore$ 오차-독립변수간 상관관계 O, 엄격한 외생성 X; 현실에선 위배 easy
- Asymptotics(점근적 성질) & Contemporaneous Exogeneity(동시대적 외생성)
	- 가정 : $cov(x_{ti},x_{tj})=0,\forall i\neq j\to E(x_tu_t)=0$ 즉, 동기간의 변수간 상관관계X면 OK
		- 만족시 consistent variable. 유한 샘->OLS X(내생성), 무한 샘 -> OLS O(동기간 외생성)
	- $\hat{\beta}=\frac{\sum_{t=1}^Tx_ty_t}{\sum_{t=1}^Tx'_tx_t}=(X'X)^{-1}X'Y\quad(X:(n\times k),Y:(T\times1))$
	- 목표 : $if\,n\to\infty,\quad then\,\hat{\beta}\overset{p}{\to}\beta$ ? (즉, $E(\hat{\beta})=\beta$ ?)
		1) $\frac{1}{n}\sum_{t=1}^Tx'_tx_t\overset{p}{\to}R\in\mathbb{R}$
		2) $\frac{1}{n}\sum_{t=1}^Tx_ty_t\overset{p}{\to}0$
			- law of iterative expectation : $if\, E(u_t|X_t)=0,\quad then\,E(u_tX_t)=E(E(u_tX_t|X_t))=E(X_t\cdot \underbrace{E(u_t|X_t))}_{=0}=0$
