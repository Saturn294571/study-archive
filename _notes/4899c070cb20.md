### 지수 성장 모형 및 로그 변환
* 기본 가정 : $E(n_t) = n_0 e^{\beta_1 t}, \quad t = 1, 2, 3, \dots$
	* 양변에 로그를 취하면, $\log E(n_t) = \log n_0 + \beta_1 t$
* 합리적인 모형(?) : $\log n_t = \log n_0 + \beta_1 t + \epsilon_t, \quad \epsilon_t \overset{\text{IID}}{\sim} N(0, \sigma^2)$
	* 그러나 이 근사 모델은 원래 모델보단 오차가 있다. : $E(\log n_t) \le \log E(n_t)$
		* \*\*젠슨의 부등식
    * $\text{If } \epsilon_t \sim N(0, \sigma^2) \text{ then}$
        * $n_t = n_0 \cdot \gamma_t \cdot e^{\beta_1 t}\implies \log n_t = \log n_0 + \beta_1 t + \epsilon_t \quad (\gamma_t = e^{\epsilon_t})$
        * 로그 정규 확률 변수 : $\gamma_t\sim N(0,\sigma^2)$
###### Jensen 부등식과 Convex Function $f(x)$
* $X \in \{X_1, X_2\}$    $P(X = X_1(\text{or } X_2)) = \lambda_1(\text{or }\lambda_2)$     $\lambda_1 + \lambda_2 = 1$
* $E(X) = \lambda_1 X_1 + (1 - \lambda_1) X_2:=X^*$ (가중평균값)
* Jensen 부등식
    * ${f(E(X)) \le E(f(X))} \implies f(\lambda_1 X_1 + (1-\lambda_1) X_2) \le \lambda_1 f(X_1) + (1-\lambda_1) f(X_2)$
    * *첨부 이미지: Pasted image 20251113155045.png*
- concave 함수 $g(X)$의 경우 :
    * $g(E(X)) \ge E(g(X))$    \* $\log x \text{는 concave}$
###### 비선형 모형의 선형화 Log Transformation
1) $y = \alpha x^\beta \implies \underbrace{\log y}_{\tilde{y}} = \log \alpha + \beta \underbrace{\log x}_{\tilde{x}} \quad (x,y > 0)$
2) $y = \alpha e^{\beta x} \implies \underbrace{\log y}_{\tilde{y}} = \log \alpha + \beta x \quad (y>0)$
3) $y = \frac{x}{\alpha x - \beta} \implies \underbrace{\frac{1}{y}}_{\tilde{y}} = \frac{\alpha x - \beta}{x} = \alpha - \beta \cdot \underbrace{\frac{1}{x}}_{\tilde{x}} \quad (x \neq 0, y \neq 0)$
	* 1), 2)에서 $x,y \to 0$ 일 때 해결법 : $\log(x(\text{or }y)+1)$

### Weighted Least Square
###### 모델의 재정의 : $Y_i =\beta_0+\beta_1X_i+\epsilon_i; \quad  \epsilon_i\sim N(0,\sigma^2X_i^2)$에 대해
- $\tilde{Y}_i =\beta_0\tilde{X}_i+\beta_1+\gamma_i;\quad \gamma_i\sim N(0,\sigma^2)$ (pr)
	- hint : $(\tilde{Y}_i=\frac{Y_i}{X_i},\tilde{X}_i=\frac{1}{X_i}\quad Var(\gamma_i)=0)$

- weighted Least square
	- $\text{SSE}(\boldsymbol{\beta}, \mathbf{w}) = \sum_{i=1}^n w_i (Y_i - \beta_0 - \beta_1 X_i)^2, \quad w_i = \frac{1}{X_i^2}.$
		- 질적 변수를 가지고 한다면 더 쉽게 가중치를 그룹으로 분해할 수 있다
			- $Var(\epsilon_i)=Var(Y_i)=V(E(Y_i))\quad V:\text{arbitary ftn}$
			- 로지스틱이나 푸아송 회귀들이 이렇게 작동함

- OLS에서의 베타 : $\hat{\beta}_{\text{OLS}} = \beta + (X^T X)^{-1} X^T \epsilon$ (pr, hint : Y 정의식 대입)
	- 베타의 평균과 잔차 : $E[(X'X)^{-1}X'\epsilon|X]=0,E(\hat{\beta})=\beta$, unbiased
	- 베타의 분산 : $\text{Var}((X^T X)^{-1} X^T \epsilon) = \sigma^2 (X^T X)^{-1} X^T V X (X^T X)^{-1},$
		- $(V = \text{diag}(X_1^2, \dots, X_n^2))$

- 2단계 처리 과정 : $w_i^{-1} = \text{Var}(\epsilon_i) = \alpha_0 + \alpha_1 X_{i1}^2$ 라고 가정하자.
	1) OLS를 사용해 최초 추정치 $\hat{\beta}_{\text{OLS}}$를 얻음
	2) 그렇게 나온 추정치를 통해 $w_i$ 추정
	3) WLS를 통해 모델을 재추정
	4) 필요하다면 2)~3) 반복
###### WLSE 증명 과정
* WLSE 목적 함수 정의
    * $L_W (\beta) = \sum_{i=1}^n w_i (Y_i - x_i^T \beta)^2$
        * ($x_i^T = (1 \quad x_{i1} \quad \cdots \quad x_{ip})$)
	* 표현 변환 (제곱근 가중치 이용)
	    * $L_W (\beta) = \sum_{i=1}^n (\sqrt{w_i} Y_i - \sqrt{w_i} x_i^T \beta)^2$ (pr)

- 행렬 $W$ 및 $\sqrt{W}$ 정의
	* $W = \begin{pmatrix} w_1 & & 0 \\ & \ddots & \\ 0 & & w_n \end{pmatrix} = \text{diag}(w_1, w_2, \dots, w_n)$
	* $W^{1/2} = \text{diag}(\sqrt{w_1}, \dots, \sqrt{w_n})$

- WLSE 목적 함수의 행렬식 표현 및 유도
	* $L_W (\beta) = (Y^* - X^* \beta)^T (Y^* - X^* \beta)$ (pr)
		* hint : $Y^* = W^{1/2} Y, X^* = W^{1/2} X$

* 최종 WLSE 추정량
    * $\hat{\beta}_{\text{WLSE}} = (X^{*T} X^*)^{-1} X^{*T} Y^* = (X^T W X)^{-1} X^T W Y$

- WLSE 추정량의 분산 ($\text{Var}(\hat{\beta}_{\text{WLSE}})$)
	* $\text{Var}(\hat{\beta}_{\text{WLSE}}) = (X'W X)^{-1} X' W \text{Var}(Y) W X (X'W X)^{-1}$
	* 동분산성 가정 : $\text{If } \text{Var}(Y) = W^{-1}$
	* 최종 분산: $\text{Var}(\hat{\beta}_{\text{WLSE}}) = (X'W X)^{-1}$
		* hint : $W^{-1}W=I$
