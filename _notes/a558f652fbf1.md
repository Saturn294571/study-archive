###### 1-1. 가설검정: $Y_i=\beta_1+\beta_2X_{2i}+\beta_3X_{3i}+\beta_4X_{4i}+\epsilon_i$ 인 경우
1) $H_0 : \beta_2 = 0, \quad H_1:\beta_2 > 0\,(\text{단측검정})$
2) $\text{if }\beta_2 >> 0 \to \text{reject }H_0$    $(\beta_2 >> 0)\to$ test statistic $\left\{\begin{matrix} H_0\text{하 계산 O}\\ \text{분포가 알려짐}\end{matrix}\right.$
	1) 계산O? : $\hat{\boldsymbol{\beta}} \sim N(\boldsymbol{\beta}, \sigma^2 (\mathbf{X}^{\intercal}\mathbf{X})^{-1})$,    $\text{Cov}(\hat{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}^{\intercal}\mathbf{X})^{-1} = \sigma^2 \begin{bmatrix} a_{11} & a_{12} & \cdots & a_{1k} \\ \vdots & \vdots & \ddots & \vdots \\ a_{k1} & a_{k2} & \cdots & a_{kk} \end{bmatrix}$
		- $\therefore \hat{\beta}_2 \sim N(\beta_2, \sigma^2 a_{22})$ ($\hat{\text{Var}}(\hat{\beta}_j)=SE(\hat{\beta}_j)=a_{jj}\hat{\beta}^2,\quad \forall a_{jj}$)
	2) 분포?
		1) $\sigma^2$ is known : $Z = \frac{\hat{\beta}_2 - \beta_2}{\sqrt{\sigma^2 a_{22}}} \sim N(0,1)$
		2) $\sigma^2$ is unknown(use $\hat{\sigma}^2$) : $T = \frac{\hat{\beta}_2 - \beta_2}{\sqrt{\hat{\sigma^2} a_{22}}}= \frac{\hat{\beta}_2 - 0}{SE(\hat{\beta}_2)}\sim t(n-4)$
###### 1-2. 가설검정 2 : 귀무가설 1개, 회귀계수 2개인 경우(콥 더글라스 함수)
- 콥-더글라스 함수 : $Y=AL^\alpha K^\beta \to lnY=lnA+\alpha (lnL)+\beta (lnK)\to Y_i = \beta_1+ \beta_2 X_{2i}+ \beta_3 X_{3i} + e_i$
1) $H_0: \beta_2 + \beta_3 = 1; \quad H_1: \beta_2 + \beta_3 \neq 1$
2) test statistic
	1) 계산 O? : $E(\hat{\beta}_2 + \hat{\beta}_3) = \beta_2 + \beta_3,\quad Var(\hat{\beta}_2 + \hat{\beta}_3) =2Cov(\hat{\beta}_2,\hat{\beta}_3)+Var(\hat{\beta}_2 )+Var(\hat{\beta}_3)$
		- $\therefore (\hat{\beta}_2 + \hat{\beta}_3) \sim N((\beta_2 + \beta_3), \sigma^2(a_{22} + a_{33} + 2a_{23}))$
	2) 분포? :
		1) $\sigma^2$ is known : $Z = \frac{(\hat{\beta}_2 + \hat{\beta}_3) - (1=\beta_2 + \beta_3)}{\sqrt{\sigma^2(a_{22} + a_{33} + 2a_{23})}} \sim N(0,1)$
		2) $\sigma^2$ is unknown(use $\hat{\sigma}^2$) : $T = \frac{(\hat{\beta}_2 + \hat{\beta}_3) - (\beta_2 + \beta_3)}{\sqrt{\hat{\sigma^2}(a_{22} + a_{33} + 2a_{23})}} \sim t(n-3)$
###### 2. 복합가설 검정
- F분포 : $A\sim\chi^2(df_A), B\sim\chi^2(df_B)\to \text{F-val}=\frac{A/df_A}{B/df_B}\sim F(df_A,df_B)$
	- 표준정규분포-t분포 간 관계
		- $(\text{t-val})\sim t_{\alpha/2}(df=) \overset{n\to\infty}{\to} Z\sim N(0,1)$
		- $(\text{t-val})^2=(\text{F-val})\sim F(df_A,df_B) \overset{n\to\infty}{\to} Z^2\sim \chi^2(1)$
- 검정 과정 : ex) $Y_i = \beta_1 + \beta_2 X_{2i} + \beta_3 X_{3i} + \beta_4 X_{4i} + e_i$
	1) $H_0: \beta_2 = \beta_3 = 0 \quad \text{vs} \quad H_1:\exists\beta_i\neq0,i\in\{2,3\}$
		- unrestricted regression : $Y_i = \hat{\beta}_1 + \hat{\beta}_2 X_{2i} + \hat{\beta}_3 X_{3i} + \hat{\beta}_4 X_{4i} + \hat{e}_i$
		- restricted regression : $Y_i = \hat{\beta}_1^* + \hat{\beta}_4^* X_{4i} + \hat{e}_i^*$
	2) 만일 H0가 사실? $\sum \hat{e}_i^2 \approx \sum \hat{e}_i^{*2}$     vs    H0가 사실이 X? $\sum \hat{e}_i^2 \ll \sum \hat{e}_i^{*2}$
		- $\left. \begin{aligned} \frac{\sum \hat{e}_i^{*2}}{\sigma^2} & \sim \chi^2(n-2) \\ \frac{\sum \hat{e}_i^2}{\sigma^2} & \sim \chi^2(n-4) \end{aligned} \right\} \quad \frac{\sum \hat{e}_i^{*2}}{\sigma^2} - \frac{\sum \hat{e}_i^2}{\sigma^2} \sim \chi^2(2)$ (full모델의 카이제곱 분포와 restricted 모델의 두 분포가 독립)
	3) $\frac{\left(\frac{\sum \hat{e}_i^{*2}}{\sigma^2} - \frac{\sum \hat{e}_i^2}{\sigma^2}\right)/2}{\frac{\sum \hat{e}_i^2}{\sigma^2}/(n-4)} \sim F(2,n-4)$
		-  $(\text{F-val}) > \text{C.V.}=F_\alpha \to \text{reject }H_0$    or     $(\text{p-val}) < \alpha \to \text{reject }H_0$
- 일반화 : j : H0에서 제약조건의 수, k: 파라미터의 수
	- $f\text{-value} = \frac{(\sum \hat{e}_i^{*2} - \sum \hat{e}_i^2)/j}{\sum \hat{e}_i^2/(n-k)} \sim F(j, n-k)$
- 주의할 실수
	- $\beta_2 \,\&\, \beta_3 = 0 \to$ t-val 2번 구함 $\frac{\hat{\beta_{2,3}}-0}{\sqrt{Var(\hat{\beta_{2,3}})}}\sim t(n-k) \to$ $\beta_{2,3}=0\,\&\,\beta_{3,2}\neq0$?; 따라서 $\beta_2=\beta_3=0$만이 OK.
	- ${\sum \hat{e}_i^{*2}} - {\sum \hat{e}_i^2}$ 를 검정통계량? -> 1) under $H_0$, 계산 O -> O; 2) under $H_0$, 분포를 know -> X;
