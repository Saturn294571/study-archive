### Correlation
###### 공분산 (Covariance) : 두 변수가 함께 어떻게 변하는지? 관계의 방향성을 나타내는 척도.****
- $COV(X,Y) = E[(X-\mu_x)(Y-\mu_y)]$,     $\hat{COV}(X,Y) = \frac{1}{n-1}S_{xy}$
###### 상관계수 (Correlation Coefficient) :
공분산을 표준화, 두 변수 간 **선형 관계**의 방향과 강도를 -1과 1 사이의 값으로 측정하기 위함.
- $\rho=\frac{COV(X,Y)}{\sigma_X\sigma_Y}$
###### 표본 피어슨 상관계수 (Sample Pearson's Correlation Coefficient) :
표본 데이터를 사용하여 모집단의 피어슨 상관계수(ρ)를 추정하는 통계량.
- $r=\frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}$    $S_{xy} = \sum_{i=1}^n (x_i-\bar{x})(y_i-\bar{y})$
- $S_{xx}$`, `$S_{yy}$`, `$S_{xy}$`, `표본(Sample)`
###### 스피어만 순위 상관계수 (Spearman's Rank Correlation Coefficient) :
데이터의 실제 값이 아닌 순위(Rank)를 이용하여 두 변수 간 단조 관계의 강도를 측정. 이상치에 강함
-  $\hat{r}_s=\frac{\text{COV}(R_X,R_Y)}{\sigma_{R_{X}}\sigma_{R_{Y}}}$
###### 켄달의 타우 (Kendall's Tau) :
모든 데이터 쌍의 순서 일치 여부(Concord./Discord.)를 기반, 두 변수 간 순서 관계의 강도를 측정.
-  $\tau=\frac{(\text{Concordant 쌍의 수}) - (\text{Discordant 쌍의 수})}{\binom{n}{2}}$
### Introduction to simple linear regression
###### 단순 선형 회귀 모델 (Simple Linear Regression Model):
하나의 독립변수(X)를 이용해 종속변수(Y)의 움직임을 설명, 예측하는 직선 관계를 모델링
-  $Y_i = \beta_0 + \beta_1 X_i + \epsilon_i \quad \text{where } \epsilon_i \sim N(0, \sigma^2) \text{ and are iid.}$
###### 모델 적합 (Fitting the Model) : SSE를 최소화하는 회귀계수($\hat{\beta}_0, \hat{\beta}_1$)를 찾는 과정.
- $\min \sum_{i=1}^n (Y_i - (\beta_0 + \beta_1 X_i))^2; \quad \hat{Y}_i = (\hat{\beta}_0 + \hat{\beta}_1 X_i)$
### Loss functions
###### Maximum Likelihood Estimator
- $\text{data: } X_1, X_2, \dots, X_n \overset{\text{iid}}{\sim} N(\mu, \sigma^2)$    $\text{pdf} :X \sim N(\mu, \sigma^2) \quad f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2\sigma^2}(x-\mu)^2\right)$
- joint pdf (모수가 주어졌을 때 데이터의 확률을 계산)
  $\quad f(x_1, x_2, \dots, x_n; \mu, \sigma^2) = \prod_{i=1}^n f(x_i) = (2\pi\sigma^2)^{-\frac{n}{2}} \exp\left(-\frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2\right)$
- Likelihood ftn (데이터가 주어졌을 때 모수에 대한 함수)
  $L(\mu, \sigma^2; x_1, \dots, x_n) = \prod_{i=1}^n f(x_i; \mu, \sigma^2) = (2\pi\sigma^2)^{-\frac{n}{2}}\exp\left(-\frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2\right)$
- Maximum Likelihood Estimator(MLE)
	- $\mu$에 관심? $\to x_1, \dots, x_n$ 이 주어졌을 때 $\mu$를 찾자 $\implies \mu^*=\underset{\mu}{\text{arg}\max}L(\mu),\;\mu^*=$MLE
###### choice of loss function
- SSE : $\text{SSE}(\mu) = \sum_{i=1}^n (Y_i - \mu)^2 \rightarrow f(\mu) = \sum_{i=1}^n (Y_i - \mu)^2$
	- $\hat{\mu} = \arg\min_{\mu} \sum_{i=1}^n (Y_i - \mu)^2= \arg\min_{\mu} f(\mu)$
	  $\frac{\partial f}{\partial \mu} = 2\sum_{i=1}^n (Y_i - \mu)(-1) = 0;\implies n\mu= \sum_{i=1}^n Y_i \Rightarrow \hat{\mu} = \frac{1}{n}\sum_{i=1}^n Y_i$
- SAD(sse보다 이상치에 둔감) : $\text{SAD}(\mu) = \sum_{i=1}^n |Y_i - \mu| = \sum_{i=1}^k (\underset{\text{k개}}{\mu - Y_{(i)}}) + \sum_{i=k+1}^n (\underset{n-k개}{Y_{(i)} - \mu})$
	- $Y_{(1)} \le Y_{(2)} \le \cdots \le Y_{(k)} \le \mu \le Y_{(k+1)} \le \cdots \le Y_{(n)}$이라면,
		- $SAD= (2k-n)\mu + \sum_{i=1}^k (-Y_{(i)}) + \sum_{i=k+1}^n Y_{(i)}$
		- n이 짝수 $\rightarrow Y_{(n/2)} \le \mu \le Y_{(n/2+1)}$    n이 홀수 $\rightarrow \mu = Y_{((n+1)/2)}$
###### Geometry of least squares

1) 열벡터(column vector) : $\underset{\sim}{x} \text{ or } \underset{\sim}{x} = (x_1, x_2, \dots, x_n)^{\intercal} = \begin{pmatrix} x_1 \\ \vdots \\ x_n \end{pmatrix}$
2) 내적 (inner product) : $\langle \underset{\sim}{x}, \underset{\sim}{y} \rangle = \underset{\sim}{x}^{\intercal}\underset{\sim}{y} = \sum_{i=1}^n x_i y_i \quad \forall \underset{\sim}{x}, \underset{\sim}{y} \in \mathbb{R}^n$
	- $\underset{\sim}{x}^{\intercal}\underset{\sim}{y} = \|\underset{\sim}{x}\|_2 \|\underset{\sim}{y}\|_2 \cos\theta, \quad \|\underset{\sim}{x}\|_2 = \left(\sum_{i=1}^n x_i^2\right)^{\frac{1}{2}} = (\underset{\sim}{x}^{\intercal}\underset{\sim}{x})^{\frac{1}{2}}$
	- $\text{if } \underset{\sim}{x}^{\intercal}\underset{\sim}{y} = 0, \text{ then } \underset{\sim}{x}$과 $\underset{\sim}{y}$ 는 직교(orthogonal)
	- 평균과의 연관 : $x^T1_n=\sum_{i=1}^n x_i = n\bar{x}$
3) 정사영 (projection) :
	1) $\underset{\sim}{x}, \underset{\sim}{y} \in \mathbb{R}^n, \quad \text{proj}_{\underset{\sim}{x}}\underset{\sim}{y} = \frac{\underset{\sim}{y}^{\intercal}\underset{\sim}{x}}{\underset{\sim}{x}^{\intercal}\underset{\sim}{x}} \underset{\sim}{x} = \underset{\sim}{z}$
	2)  $\text{proj}_{\underset{\sim}{x}}\underset{\sim}{Y} = \underset{\sim}{x}(\underset{\sim}{x}^{\intercal}\underset{\sim}{x})^{-1} (\underset{\sim}{x}^{\intercal}\underset{\sim}{Y})$
	   $\text{proj}_{X}\underset{\sim}{Y} = X(X^{\intercal}X)^{-1}X^{\intercal}\underset{\sim}{Y}$;    $X = (x_1, x_2, \dots, x_p)_{(n \times p \text{ mat.})}, Y \in \mathbb{R}^n$
	   $\langle a + x, Y \rangle = \langle a, Y \rangle + \langle x, Y \rangle$
4) 코시-슈바르츠 부등식 : $\langle x, y \rangle^2 \le \|x\|_2^2 \|y\|_2^2$
	- 벡터 간의 직교, 내적, 거리 관계를 공식적으로 정의하는 데 사용, OLS 추정량이 가장 짧은 오차 거리(최소 제곱합)를 달성한다는 것을 수학적으로 정당화
	- x,y 길이 를 1로 표준화시 내적이 cor과 같음. 그리고 코시-슈바르츠 부등식에 의해 -1<cor<1 로 존재해야 함을 보장
		-  $x^Ty=||x||\cdot||y||\cdot \cos(\theta)$    $||z_x||=||z_y||=1,\langle z_x, z_y \rangle^2 \leq 1_n\cdot1_n$

### Estimation
##### 열공간(column space) : 행렬의 열들의 선형결합으로 정의되는 공간

- $X = \begin{pmatrix} x_{11} & \cdots & x_{1p} \\ \vdots & & \vdots \\ x_{n1} & \cdots & x_{np} \end{pmatrix}_{n \times p} = (\underset{\sim}{x_1}, \underset{\sim}{x_2}, \dots, \underset{\sim}{x_p})$    $\underset{\sim}{x_j} \in \mathbb{R}^n$
- $C(X) = \{ \underset{\sim}{u}: \underset{\sim}{u} = X\underset{\sim}{a}, \underset{\sim}{a} \in \mathbb{R}^p \} \rightarrow C(X) = \text{span}(\underset{\sim}{x_1}, \dots, \underset{\sim}{x_p})$

---
**벡터 미분 (Vector Differentiation)**
- **핵심 공식/정의:** $\frac{\partial (\mathbf{x}^{\intercal}A\mathbf{x})}{\partial \mathbf{x}} = (A+A^{\intercal})\mathbf{x}$
- **핵심 의미/필요성:** 스칼라/벡터 함수를 벡터 변수로 미분 → 그래디언트(gradient)를 행렬 형태로 표현 → LSE 유도에 사용.
- **핵심 키워드:** `그래디언트(Gradient)`, `이차형식(Quadratic Form)`, `전치(Transpose)`, `대칭행렬(Symmetric Matrix)`
---
**이차형식 (Quadratic Form)**
- **핵심 공식/정의:** $\mathbf{x}^{\intercal}A\mathbf{x} = \sum_{i=1}^n \sum_{j=1}^n a_{ij}x_i x_j$
- **핵심 의미/필요성:** 변수들의 제곱항($x_i^2$) + 교차곱항($x_i x_j$)으로 구성된 다변수 2차 다항식 → 벡터/행렬 곱으로 표현.
- **핵심 키워드:** `제곱항`, `교차곱항`, `다변수 2차 다항식`
---
**최소제곱추정량 (LSE) 유도**
- **핵심 공식/정의:** $\hat{\mathbf{\beta}} = (\mathcal{X}^{\intercal}\mathcal{X})^{-1}\mathcal{X}^{\intercal}\mathbf{y}$
- **핵심 의미/필요성:** 잔차제곱합 $SSE = (\mathbf{y} - \mathcal{X}\mathbf{\beta})^{\intercal}(\mathbf{y} - \mathcal{X}\mathbf{\beta})$ → $\mathbf{\beta}$에 대해 미분 후 0으로 놓고 품 → 정규방정식($\mathcal{X}^{\intercal}\mathcal{X}\mathbf{\beta} = \mathcal{X}^{\intercal}\mathbf{y}$) 해 구하기.
- **핵심 키워드:** `잔차제곱합(SSE)`, `정규방정식(Normal Equation)`, `역행렬(Inverse)`, `Full rank(nonsingular)`
---
**LSE의 특성 (Properties of LSE)**
- **핵심 공식/정의:** $\sum e_i = 0, \quad \sum x_i e_i = 0, \quad \sum \hat{y}_i e_i = 0$
- **핵심 의미/필요성:** SSE를 각 계수로 편미분=0 조건 → 잔차($e_i$) 벡터가 상수항, 독립변수($x_i$), 예측값($\hat{y}_i$) 벡터와 각각 직교.
- **핵심 키워드:** `잔차(residual)`, `예측값(fitted value)`, `직교성(Orthogonality)`, `편미분`
---
**LSE의 기하학적 의미 (Geometric Meaning of LSE)**
- **핵심 공식/정의:** $\mathbf{e} \perp C(\mathcal{X})$
- **핵심 의미/필요성:** LSE = 관측값 벡터($\mathbf{y}$)를 설계행렬($\mathcal{X}$)의 열공간($C(\mathcal{X})$)에 정사영(projection) → 예측값 $\hat{\mathbf{y}}$ 찾기.
- **핵심 키워드:** `열공간(Column Space)`, `정사영(Orthogonal Projection)`, `직교(Perpendicular)`
---
**$\hat{\beta}_1$의 분포 (Distribution of $\hat{\beta}_1$)**
- **핵심 공식/정의:** $E(\hat{\beta}_1) = \beta_1$
- **핵심 의미/필요성:** $\hat{\beta}_1$은 $Y_i$들의 선형결합($\sum C_i Y_i$) → 기댓값이 모수 $\beta_1$과 같으므로 불편추정량.
- **핵심 키워드:** `선형결합(Linear Combination)`, `불편추정량(Unbiased Estimator)`, $C_i = \frac{x_i - \bar{x}}{S_{xx}}$
---
**가능도 함수와 추정 (Likelihood Function and Estimation)**
- **핵심 공식/정의:** $\hat{\mu}_{MLE} = \arg \max_{\mu} L(\mu)$
- **핵심 의미/필요성:** 결합확률밀도함수 → 모수($\mu$)에 대한 가능도함수로 간주 → 함수값을 최대로 만드는 모수 추정.
- **핵심 키워드:** `확률밀도함수(pdf)`, `결합확률밀도함수(joint pdf)`, `가능도함수(Likelihood function)`, `최대가능도추정량(MLE)`
