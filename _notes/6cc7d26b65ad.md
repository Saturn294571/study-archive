## 7. GARCH

### Idea
- GARCH : $R_t$의 time-varying vola.(volatility) + vola. clustering 설명 -> 조건부 분산 모형화
- 기존 : $y_t=x_t'\beta+\epsilon_t,\quad \epsilon_t\sim(0,\sigma^2)$
- GARCH : $\epsilon_t|I_{t-1}\sim(0,\sigma_t^2)$ -> 분산도 $I_{t-1}$ 따라 update
- 금융 data 특징 : time-varying vola. / vola. clustering / fat tail / asym.(asymmetry, leverage)
- 핵심 : 수익률 평균만 맞 X, 잔차 분산이 어떻게 진화?

### Conditional Moment
- $I_t$ : $t$까지 이용 가능 info. set
	- 이미 알려진 정보 -> shock X, condition
	- shock : 예상 못 한 부분
	- LIE : 큰 info. 안의 rv는 상수취급; nested info. -> smaller set wins
- 조건부 평균/분산 : $\mu_{t+1|t}=E(r_{t+1}|I_t),\quad \sigma_{t+1|t}^2=Var(r_{t+1}|I_t)$
- vola. : $\sigma_{t+1|t}$ = conditional std.
- 표준화 : $z_t=\epsilon_t/\sigma_t,\quad z_t\overset{iid}{\sim}(0,1)\Rightarrow \epsilon_t=\sigma_tz_t$
	- $\epsilon_t$ = shock size($z_t$) $\times$ vola. scale($\sigma_t$)

### Mean Eq.
- 기본 : $y_t=\mu+\epsilon_t$
- with regressor : $y_t=x_{t-1}'\beta+\epsilon_t,\quad \epsilon_t=\sigma_tz_t$
	- $x_{t-1}$ : $x_t$-$\epsilon_t$ 동시상관 회피
- mean side : ARMA/exog 가능; 관심 : residual의 $\sigma_t^2$ law of motion

### ARCH
- ARCH : Autoregressive Conditional Heteroskedasticity
	- AR : 과거 shock 사용 / C : $I_{t-1}$ 조건부 / H : 이분산
- ARCH(1) : $\sigma_t^2=\alpha_0+\alpha_1\epsilon_{t-1}^2$
	- 어제 큰 잔차 -> 오늘 큰 조건부 분산
- ARCH(p) : $\sigma_t^2=\alpha_0+\sum_{i=1}^{p}\alpha_i\epsilon_{t-i}^2$
	- 과거 $p$기 shock 크기 -> 현재 vola.
- 조건 : $\alpha_0>0,\quad \alpha_i\ge0,\quad \sum_i\alpha_i<1$
	- 앞 둘 : 분산 음수 X / 마지막 : 발산 X
- Uncond. var. : $E(\sigma_t^2)=\frac{\alpha_0}{1-\sum_i\alpha_i}$
	- 복원 hint : ARCH식 양변 $E(\cdot)$ -> conditional 변해도 장기 평균분산 O

### GARCH
- ARCH 한계 : 긴 vola. persistence 설명하려면 고차항 많이 필요
- GARCH : 과거 shock + 과거 vola. 자체
	- $GARCH(p,q):\quad \sigma_t^2=\omega+\sum_{i=1}^{q}\alpha_i\epsilon_{t-i}^2+\sum_{j=1}^{p}\beta_j\sigma_{t-j}^2$
	- ARCH term : $\epsilon_{t-i}^2$ = new shock
	- GARCH term : $\sigma_{t-j}^2$ = vola. persistence
- GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- $\alpha$ : 새 shock 영향 / $\beta$ : 과거 vola. 지속 / $\alpha+\beta$ : persistence
- 조건/장기분산 : $\omega>0,\quad \alpha,\beta\ge0,\quad \alpha+\beta<1,\quad E(\sigma_t^2)=\frac{\omega}{1-\alpha-\beta}$
	- $\alpha+\beta\approx1$ -> shock 오래 감
- 실증 기본 : GARCH(1,1)부터; high order 남발 X(noisy + 추정불안정)

### GARCH-in-Mean
- idea : high risk -> high return? vola.가 기대수익률에 직접 영향
- $y_t=x_{t-1}'\beta+\lambda g(\sigma_t^2)+\epsilon_t,\quad g\in\{\sigma_t,\sigma_t^2,\log\sigma_t^2\}$
- $\lambda>0$ : risk↑ return↑ / $\lambda<0$ : risk↑ return↓

### Asymmetric GARCH
- 기본 GARCH : $\epsilon_{t-1}^2$ -> $+5,-5$ 동일 취급
- 현실 : bad news -> good news보다 vola.↑ 가능
- EGARCH : $\log\sigma_t^2=\omega+\beta\log\sigma_{t-1}^2+\alpha(|z_{t-1}|-E|z_{t-1}|)+\gamma z_{t-1}$
	- log var. -> 양수제약 자연 처리
	- $\gamma$ : shock sign 효과; 보통 $\gamma<0$ -> negative shock가 vola.↑
- TGARCH/GJR : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\gamma I(\epsilon_{t-1}<0)\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$
	- positive shock : $\alpha$ / negative shock : $\alpha+\gamma$
	- $\gamma>0$ -> negative shock 추가효과 O

### Exogenous Vola. Factor
- 외생 factor : 금리기대, FX, 거래량, 뉴스빈도, overnight R, implied vola., 지정학 risk
- 예시 : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2+\delta z_{t-1}$
- 주의 : 변수 많이 넣기 X -> data 충분? 경제적 설명? graph상 variation?

### MLE
- vola. 직접 관측 X : $\sigma_t^2$는 residual 기반 latent object -> OLS X, MLE O
- 정규가정 : $\epsilon_t|I_{t-1}\sim N(0,\sigma_t^2)$
- log-likelihood : $\ell(\theta)=\sum_t[-\frac12\log(2\pi)-\frac12\log\sigma_t^2-\frac{\epsilon_t^2}{2\sigma_t^2}]$
- 절차 : mean eq. 설정 -> GARCH recursion으로 $\sigma_t^2$ 생성 -> conditional PDF -> LL maximize
- fat tail 강함 -> Normal 대신 Student-t 등

### Multivariate GARCH
- 1 asset : $\sigma_t^2$ scalar
- $N$ assets : $r_t\in\mathbb{R}^N,\quad \Sigma_t\in\mathbb{R}^{N\times N}$
	- 관심 : 개별 vola. + cov/corr 시간변화
- BEKK / CCC(Constant Conditional Corr.) / DCC(Dynamic Conditional Corr.)
- DCC : $\Sigma_t=D_tR_tD_t$
	- $D_t$ : cond. std. diagonal / $R_t$ : cond. corr.
	- CCC : $R$ fixed / DCC : $R_t$ time-varying

### 백지복원
- GARCH : $R_t$의 time-varying vola. + clustering 설명 -> $\sigma_t^2$ 모형화. $y_t=x_{t-1}'\beta+\epsilon_t,\ \epsilon_t=\sigma_tz_t,\ z_t\sim iid(0,1)$. ARCH : $\sigma_t^2=\alpha_0+\sum_i\alpha_i\epsilon_{t-i}^2$; GARCH(1,1) : $\sigma_t^2=\omega+\alpha\epsilon_{t-1}^2+\beta\sigma_{t-1}^2$. $\alpha$ = new shock, $\beta$ = persistence, $\alpha+\beta<1$, $E(\sigma_t^2)=\omega/(1-\alpha-\beta)$. $\sigma_t^2$ 관측 X -> conditional PDF + MLE. sign 효과 필요 -> EGARCH/TGARCH.
